MongolGPT нь Language Server Protocol (LSP) серверийн оношилгоог агентын контекстэд ашиглаж чадна. LSP нь локал ажиллагаа тул MongolGPT-ийн бүртгэл, байршуулсан арын үйлчилгээ эсвэл үйлдвэрлэлийн домэйн шаарддаггүй.

## Түргэн эхлэх

LSP анхдагчаар идэвхгүй байна. Суурилагдсан бүх LSP интеграцчиллыг идэвхжүүлэхийн тулд:

```json title="mongolgpt.json"
{
  "lsp": true
}
```

MongolGPT-г дахин эхлүүлээд дэмжигдсэн өргөтгөлтэй файл нээнэ. Тухайн хэлний серверт шаардлагатай ажиллуулах орчин эсвэл команд `PATH`-д байх ёстой.

```bash
mongolgpt debug config
```

Энэ командаар нийлүүлэгдсэн тохиргоонд `lsp` идэвхтэй эсэхийг шалгана.

Автоматаар татахыг хориглох бол MongolGPT-г эхлүүлэхээс өмнө:

```bash
export MONGOLGPT_DISABLE_LSP_DOWNLOAD=true
```

Windows PowerShell дээр:

```powershell
$env:MONGOLGPT_DISABLE_LSP_DOWNLOAD = "true"
```

Энэ тохиолдолд шаардлагатай хэлний серверийг өөрөө суулгаж, `PATH`-д нэмнэ.

## Ажиллах зарчим

LSP идэвхтэй үед MongolGPT дараах байдлаар ажиллана:

1. Нээсэн файлын өргөтгөлийг идэвхтэй сервер бүрийн `extensions` утгатай тулгана.
2. Тохирох сервер ажиллаагүй бол эхлүүлнэ.
3. Оношилгоог агентын дараагийн алхамд ашиглах боломжтой болгоно.

Хэлний сервер их санах ой ашиглах, төслийн төлөвтэй синхрончлогдохгүй байх, эсвэл агентын давталтыг удаашруулах тохиолдол бий. Төсөлд найдвартай `lint` эсвэл `typecheck` команд байвал түүнийг `AGENTS.md`-д баримтжуулах нь заримдаа илүү тогтвортой байдаг.

## Нарийвчилсан тохиргоо

Объект хэлбэр ашигласнаар тодорхой серверийг идэвхгүй болгох, суурилагдсан тохиргоог өөрчлөх, захиалгат сервер нэмэх боломжтой.

| Түлхүүр          | Төрөл         | Утга                                                    |
| ---------------- | ------------- | ------------------------------------------------------- |
| `disabled`       | Булев         | `true` бол тухайн серверийг идэвхгүй болгоно            |
| `command`        | Мөрийн массив | Сервер эхлүүлэх файл болон аргументууд                  |
| `extensions`     | Мөрийн массив | Тухайн сервер ажиллах файлын өргөтгөл                   |
| `env`            | Объект        | Серверийн процесст дамжуулах орчны хувьсагч             |
| `initialization` | Объект        | LSP `initialize` хүсэлтэд өгөх серверийн тусгай сонголт |

Нэг серверийг идэвхгүй болгох:

```json title="mongolgpt.json"
{
  "lsp": {
    "typescript": {
      "disabled": true
    }
  }
}
```

Захиалгат сервер нэмэх:

```json title="mongolgpt.json"
{
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"],
      "env": {
        "LOG_LEVEL": "info"
      },
      "initialization": {
        "preferences": {
          "importModuleSpecifierPreference": "relative"
        }
      }
    }
  }
}
```

Бүх LSP серверийг идэвхгүй болгох:

```json title="mongolgpt.json"
{
  "lsp": false
}
```

## Алдаа шийдэх

Оношилгоо харагдахгүй бол:

1. `mongolgpt debug config` гаралтад `lsp` идэвхтэй эсэхийг шалгана.
2. Файлын өргөтгөл хүснэгтэд буй утгатай яг таарч байгаа эсэхийг шалгана.
3. Шаардлагатай ажиллуулах орчин, хамаарал эсвэл хэлний серверийн командыг терминалаас ажиллуулж үзнэ.
4. `MONGOLGPT_DISABLE_LSP_DOWNLOAD` санамсаргүй тохирсон эсэхийг шалгана.
5. Тохиргоо өөрчилсний дараа MongolGPT-г дахин эхлүүлнэ.

Сервер тогтмол зогсох эсвэл их нөөц ашиглавал тухайн ID-г `disabled: true` болгож, төслийн `lint`/`typecheck` командыг ашиглана. Ерөнхий оношилгоог [алдаа шийдэх заавраас](../troubleshooting) харна уу.

---
title: Захиалгат хэрэгслүүд
description: LLM-ийн дуудаж болох MongolGPT хэрэгсэл үүсгэх.
---

Захиалгат хэрэгслүүд нь харилцан ярианы үеэр LLM-ийн дуудаж болох функцууд юм. Тэдгээр нь MongolGPT-ийн [суурилагдсан хэрэгслүүд](../tools), `read`, `write`, `bash` зэрэгтэй зэрэгцэн ажиллана.

---

## Хэрэгсэл үүсгэх

Хэрэгслүүдийг **TypeScript** эсвэл **JavaScript** файл хэлбэрээр тодорхойлно. Гэхдээ хэрэгслийн тодорхойлолтоос **ямар ч хэлээр** бичсэн скрипт дуудаж болно. **TypeScript** эсвэл **JavaScript**-ийг зөвхөн хэрэгслийн тодорхойлолтод ашиглана.

---

### Байршил

Хэрэгслүүдийг дараах байршлуудад тодорхойлж болно:

- Төслийнхөө `.mongolgpt/tools/` директорт байрлуулж, тухайн төсөлд ашиглана.
- `~/.config/mongolgpt/tools/` директорт байрлуулж, бүх төсөлд ашиглана.

---

### Бүтэц

Хэрэгсэл үүсгэх хамгийн хялбар арга нь төрлийн аюулгүй байдал болон баталгаажуулалт хангадаг `tool()` туслагчийг ашиглах явдал юм.

```ts title=".mongolgpt/tools/database.ts" {1}
import { tool } from "@mongolgpt/plugin"

export default tool({
  description: "Төслийн өгөгдлийн сангаас query хийх",
  args: {
    query: tool.schema.string().describe("Ажиллуулах SQL query"),
  },
  async execute(args) {
    // Өгөгдлийн сангийн логикийг энд бичнэ
    return `Ажиллуулсан query: ${args.query}`
  },
})
```

**файлын нэр** нь **хэрэгслийн нэр** болно. Дээрх нь `database` хэрэгслийг үүсгэдэг.

---

#### Файл бүрт олон хэрэгсэл

Та мөн нэг файлаас олон хэрэгслийг экспортлох боломжтой. Экспорт бүр **`<filename>_<exportname>`** нэртэй **тусдаа хэрэгсэл** болдог:

```ts title=".mongolgpt/tools/math.ts"
import { tool } from "@mongolgpt/plugin"

export const add = tool({
  description: "Хоёр тоо нэмэх",
  args: {
    a: tool.schema.number().describe("Эхний тоо"),
    b: tool.schema.number().describe("Хоёр дахь тоо"),
  },
  async execute(args) {
    return (args.a + args.b).toString()
  },
})

export const multiply = tool({
  description: "Хоёр тоо үржүүлэх",
  args: {
    a: tool.schema.number().describe("Эхний тоо"),
    b: tool.schema.number().describe("Хоёр дахь тоо"),
  },
  async execute(args) {
    return (args.a * args.b).toString()
  },
})
```

Ингэснээр `math_add` болон `math_multiply` гэсэн хоёр хэрэгсэл үүснэ.

---

#### Суулгасан хэрэгсэлтэй нэр давхцах

Захиалгат хэрэгслийг нэрээр нь сонгоно. Захиалгат хэрэгсэл суурилагдсан хэрэгсэлтэй ижил нэртэй бол захиалгат хэрэгсэл нь давуу эрхтэй байна.

Жишээлбэл, энэ файл нь суурилуулсан `bash` хэрэгслийг орлоно:

```ts title=".mongolgpt/tools/bash.ts"
import { tool } from "@mongolgpt/plugin"

export default tool({
  description: "Хязгаарлагдсан bash wrapper",
  args: {
    command: tool.schema.string(),
  },
  async execute(args) {
    return `blocked: ${args.command}`
  },
})
```

:::note
Суурилагдсан хэрэгслийг зориудаар орлуулахгүй бол өвөрмөц нэр сонгоно уу. Суурилагдсан хэрэгслийг идэвхгүй болгох боловч орлуулахгүй байхыг хүсвэл [зөвшөөрлийн тохиргоог](../permissions) ашиглана уу.
:::

### Аргументууд

Аргументын төрлийг тодорхойлохдоо `tool.schema` эсвэл шууд [Zod](https://zod.dev)-г ашиглаж болно.

```ts "tool.schema"
args: {
  query: tool.schema.string().describe("Ажиллуулах SQL query")
}
```

Мөн [Zod](https://zod.dev)-г шууд импортлон, энгийн объект буцааж болно:

```ts {6}
import { z } from "zod"

export default {
  description: "Хэрэгслийн тайлбар",
  args: {
    param: z.string().describe("Параметрийн тайлбар"),
  },
  async execute(args, context) {
    // Хэрэгслийн хэрэгжилт
    return "result"
  },
}
```

### Контекст

Хэрэгсэл нь одоогийн сессийн контекстийг хүлээн авна:

```ts title=".mongolgpt/tools/project.ts" {8}
import { tool } from "@mongolgpt/plugin"

export default tool({
  description: "Төслийн мэдээлэл авах",
  args: {},
  async execute(args, context) {
    // Контекстийн мэдээлэлд хандана
    const { agent, sessionID, messageID, directory, worktree } = context
    return `Agent: ${agent}, Session: ${sessionID}, Message: ${messageID}, Directory: ${directory}, Worktree: ${worktree}`
  },
})
```

Сессийн ажлын директорыг авахдаа `context.directory` ашиглана.
Git worktree-ийн үндсэн директорыг авахдаа `context.worktree` ашиглана.

## Жишээ

### Python хэрэгсэл бичих

Хэрэгслээ хүссэн хэлээрээ бичиж болно. Энд Python ашиглан хоёр тоо нэмэх жишээг үзүүлэв.

Эхлээд хэрэгслийн Python скриптийг үүсгэнэ:

```python title=".mongolgpt/tools/add.py"
import sys

a = int(sys.argv[1])
b = int(sys.argv[2])
print(a + b)
```

Дараа нь уг скриптийг дууддаг хэрэгслийн тодорхойлолтыг үүсгэнэ:

```ts title=".mongolgpt/tools/python-add.ts" {10}
import { tool } from "@mongolgpt/plugin"
import path from "path"

export default tool({
  description: "Python ашиглан хоёр тоо нэмэх",
  args: {
    a: tool.schema.number().describe("Эхний тоо"),
    b: tool.schema.number().describe("Хоёр дахь тоо"),
  },
  async execute(args, context) {
    const script = path.join(context.worktree, ".mongolgpt/tools/add.py")
    const result = await Bun.$`python3 ${script} ${args.a} ${args.b}`.text()
    return result.trim()
  },
})
```

Энд Python скриптийг ажиллуулахдаа [`Bun.$`](https://bun.com/docs/runtime/shell)-г ашиглаж байна.

Асуудлыг засахаас өмнө алдааны яг текст, MongolGPT-ийн хувилбар, үйлдлийн систем, ажиллуулсан командыг тэмдэглэж ав. API түлхүүр, токен, нууц үг, хувийн кодыг асуудлын мэдээлэл эсвэл логт бүү нийтэл.

## Шуурхай шалгалт

Дараах командууд ихэнх асуудлын шалтгааныг хурдан ялгана.

```bash
mongolgpt --version
mongolgpt --help
mongolgpt debug config
mongolgpt models
```

Илүү дэлгэрэнгүй логийг терминалд харах:

```bash
mongolgpt --print-logs --log-level DEBUG
```

1. Команд олдож байгаа эсэхийг шалга.
2. Тохиргооны алдаа байгаа эсэхийг `mongolgpt debug config`-оор шалга.
3. Үйлчилгээ үзүүлэгчийн эрх болон загварын жагсаалтыг шалга.
4. Асуудлыг хамгийн бага тохиргоотой шинэ хоосон хавтаст давтаж үз.
5. Хамгийн сүүлийн тогтвортой хувилбарыг [GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases) хуудастай харьцуул.

## Лог ба өгөгдлийн байршил

Лог файлууд:

- **macOS, Linux, WSL:** `~/.local/share/mongolgpt/log/`
- **Windows:** `%USERPROFILE%\.local\share\mongolgpt\log\`

Програмын өгөгдөл:

- **macOS, Linux, WSL:** `~/.local/share/mongolgpt/`
- **Windows:** `%USERPROFILE%\.local\share\mongolgpt\`

Энд ихэвчлэн дараах зүйлс байна.

- `auth.json`: үйлчилгээ үзүүлэгчийн API түлхүүр болон OAuth токен
- `log/`: ажилласан үеийн лог
- `project/`: сесс, мессеж, төслийн төлөв

:::caution
`auth.json` болон логт нууц мэдээлэл байж болно. Хуваалцахын өмнө API түлхүүр, токен, URL query, төслийн зам, хэрэглэгчийн нэрийг арилга.
:::

## `mongolgpt` команд олдохгүй

### Windows

Архиваас задалсан хавтаст:

```powershell
.\mongolgpt.exe --version
```

Энэ команд ажиллавал хоёртын файл зөв боловч хавтас `PATH`-д ороогүй байна. Хоёртын файлыг байнгын хавтаст байрлуулаад тэр хавтсыг хэрэглэгчийн `PATH`-д нэмнэ. Шинэ PowerShell цонх нээсний дараа дахин шалга.

```powershell
Get-Command mongolgpt -ErrorAction SilentlyContinue
```

### macOS, Linux, WSL

```bash
chmod +x mongolgpt
./mongolgpt --version
command -v mongolgpt
```

`./mongolgpt` ажиллаад `mongolgpt` ажиллахгүй бол хоёртын файл байгаа хавтсаа `PATH`-д нэмнэ.

## CLI эхлэхгүй эсвэл шууд хаагдана

1. `mongolgpt --print-logs --log-level DEBUG` ажиллуулж эхний алдааг ол.
2. `mongolgpt debug config` ажиллуулж буруу JSON, танихгүй тохируулгын түлхүүр, байхгүй файл байгаа эсэхийг шалга.
3. Төслийн `.mongolgpt/` болон глобал `~/.config/mongolgpt/` тохиргоог тус тус шалга.
4. Залгаас ашигладаг бол түр идэвхгүй болгоод дахин ажиллуулна.
5. Гүйцэтгэх файлыг зөвхөн [GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ээс дахин татаж шалгана.

## Үйлчилгээ үзүүлэгчтэй холбогдохгүй

1. TUI-д `/connect` ажиллуулж үйлчилгээ үзүүлэгчээ дахин холбоно.
2. API түлхүүрийн хугацаа дууссан, эрх цуцлагдсан, төлбөрийн үйлчилгээ идэвхгүй болсон эсэхийг үйлчилгээ үзүүлэгчийн өөрийн консол дээр шалга.
3. Байгууллагын прокси, VPN, firewall тухайн үйлчилгээ үзүүлэгчийн API-г хааж байгаа эсэхийг шалга.
4. Системийн цаг зөв эсэхийг шалга. OAuth болон гарын үсэгтэй хүсэлт буруу цагтай үед бүтэлгүйтэж болно.
5. `~/.local/share/mongolgpt/auth.json` файлыг шууд засахын оронд `/connect` эсвэл `mongolgpt auth login` ашигла.

`401` эсвэл `403` нь ихэвчлэн эрх, API түлхүүр, захиалгын асуудал. `429` нь хүсэлтийн давтамжийн хязгаар эсвэл хэрэглээний хязгаар. `5xx` нь үйлчилгээ үзүүлэгчийн талын түр алдаа байх боломжтой.

## Загвар харагдахгүй

```bash
mongolgpt models
mongolgpt models <provider-id>
```

Дараахыг шалгана.

1. Үйлчилгээ үзүүлэгч амжилттай холбогдсон эсэх.
2. Загварын ID нь яг `provider-id/model-id` хэлбэртэй эсэх.
3. `blacklist` эсвэл `whitelist` тохиргоо загварыг нуусан эсэх.
4. Тухайн бүртгэл загварт хандах эрхтэй эсэх.

Жишээ ID:

- `openai/gpt-4.1`
- `openrouter/google/gemini-2.5-flash`

Үйлчилгээ үзүүлэгч болон загварын нэрийг орчуулж өөрчилж болохгүй. Үйлчилгээ үзүүлэгчийн жагсаалт, загварын ID-г `/models` эсвэл `mongolgpt models`-оос яг хэвээр нь хуулна.

## `ProviderInitError`

Энэ алдаа нь ихэвчлэн үйлчилгээ үзүүлэгчийн буруу `baseURL`, дутуу орчны хувьсагч, буруу загварын ID эсвэл залгаасын эхлүүлэлтийн алдааг заана.

1. [Үйлчилгээ үзүүлэгч тохируулах зааврыг](../providers) дахин шалга.
2. `mongolgpt debug config` гаралтаас аль тохируулгын файл утга өгснийг хар.
3. Захиалгат `baseURL` болон проксиг түр авч дахин турш.
4. Залгаасуудыг түр идэвхгүй болгоно.
5. `/connect` тушаалаар үйлчилгээ үзүүлэгчээ дахин холбо.

Бүх програмын өгөгдлийг шууд устгах хэрэггүй. Эхлээд `auth.json` болон тохируулгын файлаа тусдаа нөөц хуулбар болгон хуулж, аль нэг өөрчлөлтийг нэг удаад турш.

## `AI_APICallError`

Алдааны төлөв болон үйлчилгээ үзүүлэгчийн хариу хэсгийг шалгана.

- **Хугацаа хэтэрсэн:** сүлжээ, прокси, VPN, үйлчилгээ үзүүлэгчийн төлөвийг шалгаад дахин оролд.
- **Контекстийн урт:** сануулга, хавсаргасан файл, өмнөх сессийн хэмжээг багасга.
- **Дэмжигдээгүй параметр:** загварт тохироогүй reasoning, temperature, output сонголтыг авч үз.
- **Багц/түр хадгалалт:** MongolGPT-ийг бүрэн хаагаад түр хадгалалтын хавтсыг нөөц хуулбарын нэрээр шилжүүлж дахин эхлүүл.

macOS, Linux, WSL дээр:

```bash
mv ~/.cache/mongolgpt ~/.cache/mongolgpt.backup-$(date +%Y%m%d-%H%M%S)
```

Windows PowerShell дээр:

```powershell
Rename-Item "$env:USERPROFILE\.cache\mongolgpt" "mongolgpt.backup-$(Get-Date -Format yyyyMMdd-HHmmss)"
```

Хавтас байхгүй бол энэ алхмыг алгас. Нөөц хуулбарыг асуудал шийдэгдсэний дараа, хэрэгтэй өгөгдөлгүйг баталгаажуулж байж устгана.

## Ширээний програм

### Нээгдэхгүй эсвэл хоосон цонх харагдана

1. Програмыг бүрэн хааж дахин нээ.
2. Task Manager эсвэл Activity Monitor-д үлдсэн MongolGPT процесс байгаа эсэхийг шалга.
3. Windows дээр Microsoft Edge WebView2 Runtime суусан, шинэ эсэхийг шалга.
4. Хувилбарын файлыг [албан ёсны хувилбарын хуудаснаас](https://github.com/sergei10a-rgb/mongolgpt/releases) авсан эсэхээ шалга.
5. Алдааны дэлгэц байгаа бол **Дахин эхлүүлэх** дээр дарж, нууц мэдээллээ арилгасан алдааны текстийг хадгал.

### Сервертэй холбогдохгүй

Ширээний програм локал sidecar сервер эхлүүлэх эсвэл өмнө тохируулсан серверийн URL-д холбогдож болно.

1. Сервер сонгогчоос **Үндсэн сервер** утгыг цэвэрлэж локал горимд дахин оролд.
2. `mongolgpt.json(c)` доторх `server.port`, `server.hostname`-ийг түр авч шалга.
3. `MONGOLGPT_PORT` орчны хувьсагч сул порт зааж байгаа эсэхийг шалга.
4. Firewall дотоод холболтыг хаагаагүй эсэхийг шалга.

### Залгааснаас болж гацна

Глобал тохируулгын `plugin` жагсаалтыг түр хоосолно.

```jsonc title="mongolgpt.jsonc"
{
  "plugin": [],
}
```

Локал залгаасын хавтаснуудыг түр өөр нэртэй болгоод програмыг дахин эхлүүлнэ.

- **macOS, Linux, WSL:** `~/.config/mongolgpt/plugins/`
- **Windows:** `%USERPROFILE%\.config\mongolgpt\plugins\`
- **Төсөл:** `<project>/.mongolgpt/plugins/`

Ажиллаж эхэлбэл залгаасуудыг нэг нэгээр нь буцааж идэвхжүүлэн асуудалтайг нь олно.

### Ширээний төлөвийг дахин тохируулах

Энэ бол хамгийн сүүлийн алхам. Эхлээд програмыг бүрэн хааж, файлуудыг устгахын оронд нөөц хуулбарын хавтас руу зөөнө.

- `mongolgpt.settings.dat`: үндсэн серверийн URL зэрэг тохиргоо
- `mongolgpt.global.dat`: глобал UI төлөв
- `mongolgpt.workspace.*.dat`: workspace бүрийн UI төлөв

Эдгээр файл үйлдлийн системийн програмын өгөгдлийн хавтаст байрлана. Дахин тохируулснаар сүүлийн сервер, таб, ажлын орчны төлөв алдагдаж болно; төслийн эх кодыг устгах ёсгүй.

### Мэдэгдэл харагдахгүй

Системийн мэдэгдэл харагдахын тулд үйлдлийн системийн мэдэгдлийн тохиргоонд MongolGPT зөвшөөрөгдсөн, мөн програмын цонх идэвхгүй байх ёстой. Эхлээд үйлдлийн системийн мэдэгдлийн тохиргооноос MongolGPT-г зөвшөөрч, дараа нь цонхноос гарч турш.

## Вэб сервер

### `EADDRINUSE`

Сонгосон портыг өөр процесс ашиглаж байна. Өөр порт сонго.

```bash
mongolgpt web --port 4097
```

### `401 Unauthorized`

`MONGOLGPT_SERVER_USERNAME`, `MONGOLGPT_SERVER_PASSWORD` утгаа серверийг эхлүүлсэн терминалын сесст тохируулсан эсэхийг шалга. Нууц үгийг URL, shell-ийн түүх, асуудлын бүртгэлд бүү оруул.

### Сүлжээнээс холбогдохгүй

1. Сервер `--hostname 0.0.0.0` сонголттой ажиллаж байгаа эсэхийг шалга.
2. Нууц үг тохируулсан эсэхийг шалга.
3. Firewall дээр зөвхөн хэрэгтэй дотоод сүлжээний хүрээнд портоо нээ.
4. Интернетээс хандах бол HTTPS урвуу прокси эсвэл VPN ашигла.

[Вэб интерфэйсийн аюулгүй тохиргоог](../web) үзнэ үү.

## Linux дээр хуулах, буулгах үйлдэл ажиллахгүй

X11 дээр `xclip` эсвэл `xsel`, Wayland дээр `wl-clipboard` суулгана.

```bash
# X11
sudo apt install xclip

# Wayland
sudo apt install wl-clipboard
```

Толгойгүй орчинд түр санах ой хэрэгтэй бол виртуал X сервер ашиглаж болно.

```bash
sudo apt install xvfb
Xvfb :99 -screen 0 1024x768x24 > /dev/null 2>&1 &
export DISPLAY=:99.0
```

## Windows болон WSL

Windows дээр файл унших удаан, бүрхүүлийн команд зөрөх, зөвшөөрлийн асуудал гарвал [WSL зааврыг](../windows-wsl) ашигла. Төслөө `/mnt/c/...` биш, WSL-ийн `~/projects/...` хавтаст байрлуулах нь ихэнх тохиолдолд хурдан.

## Устгах

CLI өөрийн суулгах аргыг таньж, устгах файлуудыг баталгаажуулахын өмнө харуулна.

```bash
mongolgpt uninstall
```

Тохиргоо эсвэл програмын өгөгдлөө хадгалах сонголтыг [CLI лавлагаанаас](../cli#uninstall) шалга. Ширээний програмыг үйлдлийн системийн Apps эсвэл Applications хэсгээс устгана.

## Түгээмэл асуулт

<details>
<summary>MongolGPT бүртгэл заавал хэрэгтэй юу?</summary>

Free Auto, багц, хэрэглээний хязгаар болон төхөөрөмж хооронд хуваалцах ажлын орчин ашиглахад MongolGPT бүртгэл хэрэгтэй. Өөрийн API түлхүүр болон локал загварын нууц мэдээлэл тусдаа хадгалагдана. Үйлчилгээний сервер идэвхжсэн хувилбарт CLI-аас `mongolgpt account login` тушаалаар нэвтэрнэ. [Бүртгэл ба багцын зааврыг](../account) үзнэ үү.

</details>

<details>
<summary>MongolGPT-ийг хаанаас татах вэ?</summary>

Зөвхөн [GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases) хуудас болон төслийн [GitHub санг](https://github.com/sergei10a-rgb/mongolgpt) ашигла. Танихгүй домэйнээс binary, installer, install script бүү ажиллуул.

</details>

<details>
<summary>`https://your-domain.example` ажиллахгүй байна. Яагаад?</summary>

Энэ нь `.env.example` доторх байршуулалтын жишээ утга бөгөөд бодит үйлчилгээ биш. Хөгжүүлэгч өөрийн Cloudflare орчны бодит URL-аар солино. Энгийн хэрэглэгч URL-ийг гараар тохируулахгүй; Desktop болон CLI нь хувилбарын сувгийн үйлчилгээний URL-ийг сонгоно.

</details>

<details>
<summary>Free Auto, төлбөртэй багц эсвэл нийтийн хуваалцах үйлчилгээ үйлдвэрлэлд нээгдсэн үү?</summary>

Нэгдсэн нэвтрэлт, Free Auto, хэрэглээний хязгаар болон QPay/Bonum төлбөрийн код хөгжүүлэлтийн орчинд туршигдаж байна. Хувилбарын тэмдэглэлд нийтэд нээснийг албан ёсоор зарлаж, бүртгэлийн самбарт хүчинтэй нөхцөл нийтлэгдэх хүртэл бодит төлбөрийн мэдээлэл бүү оруул. Энэ хооронд CLI/TUI, локал вэб, ширээний програм, BYOK үйлчилгээ үзүүлэгч, локал загвар, MCP болон LSP боломжуудыг ашиглаж болно. [Одоогийн төлөвийг](../account) үзнэ үү.

</details>

<details>
<summary>Вэб интерфэйсийг интернет рүү шууд нээж болох уу?</summary>

Зөвлөдөггүй. `MONGOLGPT_SERVER_PASSWORD`, HTTPS урвуу прокси, firewall, VPN эсвэл SSH tunnel ашигла. Нууц үггүй `0.0.0.0` сервер нь сесс болон төслийн мэдээллийг эрсдэлд оруулна.

</details>

<details>
<summary>Сесс болон API түлхүүр хаана хадгалагддаг вэ?</summary>

CLI-ийн локал өгөгдөл `~/.local/share/mongolgpt/` эсвэл Windows дээр `%USERPROFILE%\.local\share\mongolgpt\` дотор хадгалагдана. Хүсэлт болон хавсаргасан агуулга сонгосон AI үйлчилгээ үзүүлэгч рүү илгээгдэж болно; үйлчилгээ үзүүлэгчийн нууцлал, хадгалалтын хугацааны бодлогыг тусад нь шалга.

</details>

<details>
<summary>Тохиргооны аль файл хэрэглэгдэж байгааг яаж мэдэх вэ?</summary>

`mongolgpt debug config` ажиллуул. Энэ нь нийлүүлэгдсэн тохиргоог харуулж, төсөл, глобал болон орчны утгуудын зөрчлийг оношлоход тусална.

</details>

## Тусламж авах

Шинэ хүсэлт нээхийн өмнө [MongolGPT Тусламж](https://mgpt.mn/support) хэсэг дэх өөрийн хүсэлтүүдийг шалгана. Шинэ хүсэлтэд дараах мэдээллийг оруулна.

- `mongolgpt --version` гаралт
- Үйлдлийн систем, архитектур
- CLI, ширээний програм, вэбийн аль нь болох
- Давтах хамгийн богино алхам
- Хүлээсэн ба бодит үр дүн
- Нууц мэдээллээ арилгасан логийн холбогдох хэсэг

API түлхүүр, токен, нууц үг, хувийн репозиторын кодыг хэзээ ч нийтэлж болохгүй.

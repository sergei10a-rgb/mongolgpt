`mongolgpt serve` команд нь хэрэглэгчийн интерфэйсгүй HTTP сервер ажиллуулна. Энэ сервер MongolGPT-ийн клиентүүд ашиглах OpenAPI төгсгөлийн цэгийг нээнэ.

---

### Хэрэглээ

```bash
mongolgpt serve [--port <number>] [--hostname <string>] [--cors <origin>]
```

#### Сонголтууд

| Сонголт         | Тайлбар                              | Өгөгдмөл утга     |
| --------------- | ------------------------------------ | ----------------- |
| `--port`        | Серверийн сонсох порт                | `4096`            |
| `--hostname`    | Серверийн сонсох хостын нэр          | `127.0.0.1`       |
| `--mdns`        | mDNS-ээр илрүүлэхийг идэвхжүүлэх     | `false`           |
| `--mdns-domain` | mDNS үйлчилгээний домэйн нэр         | `mongolgpt.local` |
| `--cors`        | CORS-д зөвшөөрөх нэмэлт эх үүсвэрүүд | `[]`              |

`--cors` сонголтыг олон удаа өгч болно:

```bash
mongolgpt serve --cors http://localhost:5173 --cors https://app.example.com
```

---

### Нэвтрэлтийн хамгаалалт

Серверийг HTTP Basic Authentication-аар хамгаалахын тулд `MONGOLGPT_SERVER_PASSWORD` орчны хувьсагчийг тохируулна. Хэрэглэгчийн нэрийн өгөгдмөл утга нь `mongolgpt`; үүнийг өөрчлөх бол `MONGOLGPT_SERVER_USERNAME` орчны хувьсагчийг тохируулна. Энэ хамгаалалт `mongolgpt serve` болон `mongolgpt web` командын аль алинд үйлчилнэ.

```bash
MONGOLGPT_SERVER_PASSWORD=your-password mongolgpt serve
```

### Ажиллах зарчим

`mongolgpt`-г ажиллуулахад TUI болон түүний дотоод сервер зэрэг эхэлнэ. TUI нь сервертэй харилцах клиент юм. Сервер OpenAPI 3.1 тодорхойлолтыг нийтлэх бөгөөд уг тодорхойлолтоос [SDK](../sdk)-г үүсгэдэг.

:::tip
MongolGPT-тэй программаас API-аар харилцах бол тусдаа `mongolgpt serve` сервер ажиллуулна.
:::

Энэ бүтэц нь TUI, вэб клиент, IDE өргөтгөл болон бусад интеграцыг нэг серверийн API-аар ажиллуулах боломж олгоно.

Бие даасан сервер эхлүүлэхийн тулд `mongolgpt serve`-г ажиллуулна. TUI аль хэдийн ажиллаж байсан ч энэ команд тусдаа шинэ сервер эхлүүлнэ.

---

#### Ажиллаж буй сервертэй холбогдох

TUI-г эхлүүлэх бүрд санамсаргүй порт болон хостын нэр сонгогдоно. Тогтмол утга ашиглах бол `--hostname` болон `--port` [сонголтуудыг](../cli) өгнө. Дараа нь тэдгээр утгаар серверт холбогдоно.

[`/tui`](#tui) төгсгөлийн цэгүүдээр TUI-г серверийн API-аар удирдаж болно. Жишээлбэл, хүсэлтийн талбарыг урьдчилан бөглөх эсвэл хүсэлтийг шууд ажиллуулах боломжтой. MongolGPT-ийн [IDE](../ide) залгаасууд энэ аргыг ашигладаг.

## OpenAPI тодорхойлолт

Сервер OpenAPI 3.1 тодорхойлолтыг дараах хаягаар нийтэлнэ:

```
http://<hostname>:<port>/doc
```

Жишээ нь `http://localhost:4096/doc`. Энэ тодорхойлолтыг клиент үүсгэх, хүсэлт болон хариултын төрлийг шалгахад ашиглана. Мөн Swagger Explorer-оор үзэж болно.

| Арга  | Зам                      | Тайлбар                               | Хариулт                                                                                            |

| `GET` | `/file/status`           | Хяналтад буй файлуудын төлөвийг авах  | <a href={typesUrl}><code>File[]</code></a>                                                         |

#### `/find/file` асуулгын параметрүүд

- `query` (заавал) — ойролцоо тохирлоор хайх текст
- `type` (заавал биш) — үр дүнг зөвхөн `"file"` эсвэл `"directory"` төрлөөр хязгаарлах
- `directory` (заавал биш) — хайлтад ашиглах төслийн үндсэн санг өөрөөр заах
- `limit` (заавал биш) — буцаах үр дүнгийн дээд тоо (1–200)
- `dirs` (заавал биш) — хуучин хувилбартай нийцүүлэх сонголт (`"false"` үед зөвхөн файл буцаана)

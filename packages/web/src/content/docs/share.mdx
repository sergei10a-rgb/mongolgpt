## Одоогийн төлөв

**Нийтийн хуваалцах холбоос үйлдвэрлэлийн орчинд одоогоор идэвхжээгүй.** `/share` болон `/unshare` командын клиент талын интерфэйс байж болох ч хуваалцах үйлчилгээний эрхийн шалгалт, хадгалах хугацаа болон устгалын урсгал бүрэн баталгаажаагүй орчинд нийтэд нээлттэй URL үүсгэх боломж гэж үзэж болохгүй.

:::caution
Танихгүй хуваалцах домэйнд сесс, эх код, API түлхүүр, нэвтрэх эсвэл төлбөрийн мэдээлэл бүү илгээ. CLI, TUI, локал вэб, ширээний програм болон BYOK үйлчилгээ үзүүлэгч ашиглахад хуваалцах үйлчилгээ хэрэггүй.
:::

Нээлтийн тохиргоонд хуваалцах боломжийг илэрхий унтраана:

```json title="mongolgpt.json"
{
  "share": "disabled"
}
```

## Одоогоор сесс дамжуулах

Нийтийн холбоосын оронд сессийг локал файл болгон экспортлоно.

TUI-д Markdown экспорт нээх:

```txt
/export
```

CLI-аас JSON экспортлох:

```bash
mongolgpt export [sessionID] > session.json
```

Файлыг бусдад өгөхийн өмнө промпт, хэрэгслийн гаралт, файлын ялгаа, файлын зам, нууц утга, токен болон хэрэглэгчийн өгөгдөл байгаа эсэхийг шалгаж цэвэрлэнэ. Дараа нь байгууллагын баталсан файл дамжуулах сувгийг ашиглана.

## Цаашдын нийтэд хуваалцах үйлчилгээ

Хуваалцах сервер тал бүрэн баталгаажиж, хувилбарын тэмдэглэлд нийтэд хуваалцах дэмжлэгийг идэвхжүүлсэн үед л репозиторын `.env.example` доторх `MONGOLGPT_PUBLIC_URL`, `MONGOLGPT_API_URL`, `MONGOLGPT_SHARE_URL` зэрэг утгыг өөрийн эзэмшлийн нийтэд ашиглах URL-аар тохируулна. Баталгаажаагүй орчинд:

```dotenv
MONGOLGPT_ENABLE_HOSTED_SERVICES=false
```

`.env.example` доторх `https://your-domain.example` нь жишээ утга бөгөөд ажилладаг үйлчилгээ биш. Сервер талыг идэвхжүүлэхээс өмнө танин баталгаажуулалт, эрхийн шалгалт, TLS, хадгалах хугацаа, устгал, урвуулан ашиглахаас хамгаалалт, аудитын бүртгэл болон ослын хариу ажиллагааг баталгаажуулах шаардлагатай.

Байгууллагын үндсэн тохиргоог [байгууллагын хэрэглээ](../enterprise), локал экспортын командуудыг [CLI](../cli#export) болон [TUI](../tui)-ийн заавраас харна уу.

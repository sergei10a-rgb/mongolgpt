---
title: Захиалгат командууд
description: Давтагддаг ажилд зориулсан захиалгат команд үүсгэх.
---

Захиалгат командууд нь TUI-д тухайн командыг ажиллуулах үед гүйцэтгэх зааврыг тодорхойлох боломжийг олгоно.

```bash frame="none"
/my-command
```

Захиалгат команд нь `/init`, `/undo`, `/redo`, `/share`, `/help` зэрэг суурилагдсан командаас тусдаа. [TUI командуудыг](../tui#командууд) харна уу.

---

## Командын файл үүсгэх

Захиалгат команд тодорхойлохын тулд `commands/` директорт Markdown файл үүсгэнэ.

`.mongolgpt/commands/test.md` үүсгэх:

```md title=".mongolgpt/commands/test.md"
---
description: Тестийг хамралтын тайлантай ажиллуулах
agent: build
model: anthropic/claude-3-5-sonnet-20241022
---

Бүх тестийг хамралтын тайлантай ажиллуулж, унасан тестүүдийг харуул.
Унасан тестүүдэд төвлөрч засвар санал болго.
```

Frontmatter нь командын шинж чанарыг тодорхойлно. Үлдсэн агуулга нь командын загвар болно.

`/` гэж бичээд дараа нь командын нэрийг бичнэ үү.

```bash frame="none"
"/test"
```

---

## Тохируулах

Та захиалгат командуудыг MongolGPT-ийн тохиргоонд тодорхойлох эсвэл `commands/` директорт Markdown файл үүсгэх замаар нэмж болно.

---

### JSON

MongolGPT-ийн [тохиргоо](../config) дахь `command` сонголтыг ашиглана уу:

```json title="mongolgpt.jsonc" {4-12}
{
  "command": {
    // Энэ нь командын нэр болно
    "test": {
      // LLM-д илгээх хүсэлт
      "template": "Бүх тестийг хамралтын тайлантай ажиллуулж, унасан тестүүдийг харуул.\nУнасан тестүүдэд төвлөрч засвар санал болго.",
      // TUI-д харагдах тайлбар
      "description": "Тестийг хамралтын тайлантай ажиллуулах",
      "agent": "build",
      "model": "anthropic/claude-3-5-sonnet-20241022"
    }
  }
}
```

Одоо та энэ командыг TUI дээр ажиллуулж болно:

```bash frame="none"
/test
```

---

### Тэмдэглэгээ

Та мөн Markdown файл ашиглан команд тодорхойлж болно. Файлуудаа дараах байршлуудын аль нэгэнд байрлуулна:

- Глобал: `~/.config/mongolgpt/commands/`
- Төсөл тус бүр: `.mongolgpt/commands/`

```markdown title="~/.config/mongolgpt/commands/test.md"
---
description: Тестийг хамралтын тайлантай ажиллуулах
agent: build
model: anthropic/claude-3-5-sonnet-20241022
---

Бүх тестийг хамралтын тайлантай ажиллуулж, унасан тестүүдийг харуул.
Унасан тестүүдэд төвлөрч засвар санал болго.
```

Markdown файлын нэр нь командын нэр болно. Жишээлбэл, `test.md` файлыг үүсгэсний дараа:

```bash frame="none"
/test
```

## Командын загварын тохиргоо

Захиалгат командын загварууд нь хэд хэдэн тусгай орлуулагч болон синтаксийг дэмждэг.

---

### Аргументууд

`$ARGUMENTS` орлуулагчийг ашиглан команд руу аргумент дамжуулна.

```md title=".mongolgpt/commands/component.md"
---
description: Шинэ компонент үүсгэх
---

TypeScript дэмжлэгтэй `$ARGUMENTS` нэртэй React компонент үүсгэ.
Зөв type болон үндсэн бүтцийг оруул.
```

Аргументтай командыг ажиллуулна уу:

```bash frame="none"
/component Button
```

Энэ үед `$ARGUMENTS` нь `Button`-оор солигдоно.

Мөн байрлалаар нь зааж, аргумент бүрд тусад нь хандаж болно:

- `$1` - Эхний аргумент
- `$2` - Хоёр дахь аргумент
- `$3` - Гурав дахь аргумент
- Гэх мэт...

Жишээ нь:

```md title=".mongolgpt/commands/create-file.md"
---
description: Агуулгатай шинэ файл үүсгэх
---

`$2` хавтаст `$1` нэртэй файл үүсгэ.
Дараах агуулгыг бич: `$3`
```

Командыг ажиллуулна уу:

```bash frame="none"
/create-file config.json src "{ \"key\": \"value\" }"
```

Энэ нь орлоно:

- `$1`, `config.json`
- `$2`, `src`
- `$3`, `{ "key": "value" }`

---

### Бүрхүүлийн гаралт

_!`command`_ ашиглан [Bash командын](../tui#bash-командууд) гаралтыг загварын оролтод оруулна.

Жишээлбэл, тестийн хамрах хүрээг шинжилдэг захиалгат командыг үүсгэхийн тулд:

```md title=".mongolgpt/commands/analyze-coverage.md"
---
description: Тестийн хамралтыг шинжлэх
---

Одоогийн тестийн үр дүн:
!`npm test`

Эдгээр үр дүнд тулгуурлан тестийн хамралтыг нэмэгдүүлэх сайжруулалт санал болго.
```

Эсвэл сүүлийн үеийн өөрчлөлтүүдийг шалгахын тулд:

```md title=".mongolgpt/commands/review-changes.md"
---
description: Сүүлийн өөрчлөлтийг шалгах
---

Сүүлийн Git commit-ууд:
!`git log --oneline -10`

Эдгээр өөрчлөлтийг шалгаж сайжруулалт санал болго.
```

Командууд нь төслийн үндсэн директорт ажиллах бөгөөд гаралт нь загварын оролтын нэг хэсэг болно.

---

### Файлын лавлагаа

Файлыг `@` тэмдэг, дараа нь файлын нэрээр зааж, командын оролтод оруулна.

```md title=".mongolgpt/commands/review-component.md"
---
description: Компонент шалгах
---

`@src/components/Button.tsx` дахь компонентыг шалга.
Гүйцэтгэлийн асуудал байгаа эсэхийг шалгаж сайжруулалт санал болго.
```

Файлын агуулгыг загварын оролтод автоматаар оруулна.

## Сонголт

Тохиргооны сонголтуудыг нарийвчлан авч үзье.

---

### Командын загвар

`template` сонголт нь командыг ажиллуулах үед LLM-д илгээх зааврыг тодорхойлно.

```json title="mongolgpt.json"
{
  "command": {
    "test": {
      "template": "Бүх тестийг хамралтын тайлантай ажиллуулаад алдааг харуул.\nУнасан тестүүдэд төвлөрч, засах санал өг."
    }
  }
}
```

Энэ нь **шаардлагатай** тохиргооны сонголт юм.

---

### Тодорхойлолт

`description` сонголтоор командын үүргийг товч тайлбарлана.

```json title="mongolgpt.json"
{
  "command": {
    "test": {
      "description": "Тестүүдийг хамралтын тайлантай ажиллуулах"
    }
  }
}
```

Команд бичих үед энэ тайлбар TUI-д харагдана.

---

### Агент

`agent` тохиргоог ашиглан энэ командыг аль [агент](../agents) гүйцэтгэхийг сонгоно.
Хэрэв сонгосон агент нь [дэд агент](../agents/#дэд-агентууд) бол команд анхдагчаар дэд агентын дуудлага үүсгэнэ.
Энэ үйлдлийг идэвхгүй болгохын тулд `subtask`-г `false` гэж тохируулна уу.

```json title="mongolgpt.json"
{
  "command": {
    "review": {
      "agent": "plan"
    }
  }
}
```

Энэ тохиргоо **заавал биш**. Заагаагүй бол одоогийн агентын өгөгдмөл тохиргоог ашиглана.

---

### Дэд даалгавар

[Дэд агент](../agents/#дэд-агентууд) дуудахыг албадах бол `subtask` логик утгыг ашиглана.
Команд үндсэн контекстийг өөрчлөхгүйгээр ажиллах ёстой үед энэ тохиргоо хэрэгтэй.
`mode` тохиргоог `primary` болгосон байсан ч мөн адил.

```json title="mongolgpt.json"
{
  "command": {
    "analyze": {
      "subtask": true
    }
  }
}
```

Энэ нь **заавал биш** тохиргооны сонголт юм.

---

### Загвар

Энэ командын өгөгдмөл загварыг өөрчлөхийн тулд `model` тохиргоог ашиглана.

```json title="mongolgpt.json"
{
  "command": {
    "analyze": {
      "model": "anthropic/claude-3-5-sonnet-20241022"
    }
  }
}
```

Энэ нь **заавал биш** тохиргооны сонголт юм.

---

## Суурилагдсан командууд

MongolGPT нь `/init`, `/undo`, `/redo`, `/share`, `/help` зэрэг суурилагдсан командтай. [TUI командуудыг](../tui#командууд) харна уу.

:::note
Захиалгат командууд нь суурилагдсан командуудыг дарж болно.
:::

Ижил нэртэй захиалгат команд тодорхойлбол тэр нь суурилагдсан командыг орлоно.

MongolGPT-ийн экосистемийн хуудсанд одоогоор зөвхөн баталгаажсан интеграцийн төрлүүдийг харуулж байна. Албан ёсны зах зээл болон багцын бүртгэл бэлэн болоогүй тул энд гуравдагч талын дахин брэндчилсэн багцын жагсаалт тавихгүй.

## Баталгаатай интеграцийн төрлүүд

| Төрөл              | Одоогийн төлөв                                                                                                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MCP сервер         | `mongolgpt compat import plan/apply` команд болон ширээний програмын интеграцийн хөтчөөр Claude JSON/JSONC, Codex TOML, Goose/Hermes YAML, команд, дотоод зам, URL-ийг танина |
| Агентын ур чадвар  | Claude, Codex, Goose хэлбэрийн ур чадварын хавтас болон тохиргоог таних суурь импортлогчтой                                                                                   |
| Залгаас            | Дотоод залгаасын файл болон хувийн npm багцыг тохиргоонд зааж ажиллуулна                                                                                                      |
| Үйлчилгээ үзүүлэгч | BYOK болон дотоод үйлчилгээ үзүүлэгчийн тохируулгыг дэмжинэ; MongolGPT бүртгэл ба Free Auto нь байршуулсан үйлчилгээ идэвхтэй хөгжүүлэлт/хувилбарын сувагт ажиллана           |

## Импортын урсгал

```bash
mongolgpt compat import plan "npx -y @modelcontextprotocol/server-filesystem C:\\Users\\me"
mongolgpt compat import apply "npx -y @modelcontextprotocol/server-filesystem C:\\Users\\me"
```

Desktop дээр `Тохиргоо -> Интеграц` хэсгээс тушаал, зам, URL эсвэл тохируулга оруулаад шалгах болон нэмэх боломжтой.

Codex-ийн `.codex/config.toml`, Goose-ийн `.config/goose/config.yaml`, Hermes-ийн `.hermes/config.yaml` хавтас эсвэл файлыг шууд заахад MCP холболтын дэмжигдэх тохиргоог MongolGPT хэлбэрт автоматаар хөрвүүлнэ. MongolGPT-д ижил утгатай талбар байхгүй бол `plan` үр дүнд алгассан талбарын нэрийг анхааруулгаар харуулна. Эхлээд `plan` ажиллуулж илэрсэн өөрчлөлтийг шалгаад, дараа нь `apply` ашиглана.

## Нийтлэхээс өмнөх дүрэм

- Нийтлэгдээгүй npm/Homebrew/AUR/Chocolatey/Scoop багцыг албан ёсны суулгац гэж харуулахгүй.
- Гуравдагч талын залгаасыг MongolGPT нэрээр дахин брэндчилж, бодитоор байхгүй URL эсвэл багц руу заахгүй.
- Шинэ интеграц нэмэхдээ эхлээд импортлогч эсвэл холбогчоор шалгана. Албан ёсны бүртгэл эсвэл marketplace-д нийтлэгдсэний дараа л баримт бичигт багц суулгах команд нэмнэ.

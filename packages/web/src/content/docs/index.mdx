[**MongolGPT**](/) бол терминал, ширээний програм, IDE, вэб интерфэйсээр ашиглах боломжтой AI кодын агент юм. Эх код, албан ёсны хувилбар, татах файлуудыг зөвхөн [GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases) болон төслийн [GitHub сангаас](https://github.com/sergei10a-rgb/mongolgpt) авна.

## Одоогийн дэмжлэгийн хүрээ

MongolGPT нь локал кодын агентын боломжуудаа хадгалж, Вэб, ширээний програм болон CLI-д нэг бүртгэл ашиглах үйлчилгээний бүтэц рүү хөгжиж байна.

| Төлөв                         | Боломж                                                                                                |
| ----------------------------- | ----------------------------------------------------------------------------------------------------- |
| Дэмжигдэнэ                    | [CLI](./cli) болон [TUI](./tui)                                                                       |
| Дэмжигдэнэ                    | [`mongolgpt web`](./web)-ээр ажиллах локал вэб интерфэйс                                              |
| Дэмжигдэнэ                    | GitHub Releases-д файл нь нийтлэгдсэн [Windows-ийн ширээний програм](./desktop)                       |
| Дэмжигдэнэ                    | Өөрийн API түлхүүр эсвэл OAuth эрх ашиглах [өөрийн түлхүүртэй үйлчилгээ үзүүлэгч (BYOK)](./providers) |
| Дэмжигдэнэ                    | Ширээний програм болон CLI дээр Ollama, LM Studio зэрэг локал загвар                                  |
| Дэмжигдэнэ                    | [MCP](./mcp-servers) болон [LSP](./lsp) холболт                                                       |
| Хөгжүүлэлтийн туршилт         | Нэгдсэн бүртгэл, OAuth, [Free Auto болон багц](./account)                                             |
| Үйлдвэрлэлийн орчинд идэвхгүй | Basic/Pro/Max бодит төлбөр, QPay/Bonum-ийн төлбөр хүлээн авах эрх, олон нийтэд хуваалцах боломж       |

:::caution[Хөгжүүлэлт ба үйлдвэрлэлийн орчныг ялгана уу]
Нэгдсэн нэвтрэлт, загварын гарц, хэрэглээний хязгаар болон төлбөрийн сервер талын код хөгжүүлэлтийн орчинд туршигдаж байна. Үйлдвэрлэлийн нээлтийг хувилбарын тэмдэглэлд албан ёсоор зарлахаас өмнө бодит төлбөрийн мэдээлэл бүү оруул. `*.dev.mgpt.mn` нь туршилтын орчин бөгөөд үйлдвэрлэлийн үйлчилгээ биш.
:::

## Аль хувилбарыг сонгох вэ?

- **Windows-ийн ширээний програм** хэрэгтэй бол [ширээний програмын зааврыг](./desktop) дагана.
- **Терминалын CLI** хэрэгтэй бол [суулгах заавраас](./install) үйлдлийн систем, процессортоо тохирох файлыг сонгоно.
- **Хөгжүүлэлт хийх** эсвэл бэлэн файл байхгүй платформ дээр ажиллуулах бол эх кодоос ажиллуулна.

:::caution
Татах файлын нэр, хувилбар бүрд өөр байж болно. Хувилбарын тайлбар болон файлын жагсаалтыг шалгаж, танихгүй домэйн эсвэл гуравдагч талын толин сайтаас суулгагч бүү тат.
:::

## Ширээний програм суулгах

Шинэ хэрэглэгчид зурагтай, алдаа оношлох холбоостой [ширээний програмын бүрэн зааврыг](./desktop) ашиглахыг зөвлөж байна.

1. [MongolGPT Releases](https://github.com/sergei10a-rgb/mongolgpt/releases) хуудсыг нээнэ.
2. Хамгийн сүүлийн тогтвортой хувилбарыг сонгоно.
3. `mongolgpt-desktop-win-x64.exe` файл тухайн хувилбарт байвал татаж ажиллуулна.
4. Суулгасны дараа MongolGPT-ийг нээгээд төслийн хавтсаа сонгоно.
5. **Үйлчилгээ үзүүлэгч холбох** хэсгээс ашиглах загварын эх үүсвэрээ сонгоно.

Хэрэв Windows SmartScreen анхааруулга үзүүлбэл хувилбарын URL нь `github.com/sergei10a-rgb/mongolgpt/releases` мөн эсэхийг дахин шалга. Хувилбарын тайлбарт гарын үсэггүй бүтээлт гэж тэмдэглэсэн бол байгууллагынхаа аюулгүй байдлын бодлогыг дагана.

Ширээний програм нээгдэхгүй, хоосон цонх харуулах, сервертэй холбогдохгүй байвал [алдаа оношлох зааврын ширээний програмын хэсгийг](./troubleshooting#ширээний-програм) үзнэ үү.

## CLI суулгах

Үйлдлийн систем тус бүрийн алхам болон checksum шалгалтыг [суулгах гарын авлагаас](./install) харна уу.

1. [MongolGPT Releases](https://github.com/sergei10a-rgb/mongolgpt/releases) хуудсаас платформдоо тохирох архивыг татна.
2. Архивыг задлахад `mongolgpt` эсвэл Windows дээр `mongolgpt.exe` файл гарна.
3. Файлыг `PATH`-д бүртгэлтэй хавтас руу байрлуулах эсвэл тухайн хавтсаас шууд ажиллуулна.
4. Суулгалтыг шалгана.

```bash
mongolgpt --version
```

macOS болон Linux дээр ажиллуулах эрх шаардлагатай бол:

```bash
chmod +x mongolgpt
./mongolgpt --version
```

Windows PowerShell дээр:

```powershell
.\mongolgpt.exe --version
```

Багцын менежерийн командыг хувилбарын тайлбарт албан ёсоор дурдсан үед л ашиглаарай. Баталгаатай үндсэн татах суваг нь GitHub Releases юм.

## Эх кодоос ажиллуулах

Энэ арга нь Bun болон Git суулгасан хөгжүүлэлтийн орчинд зориулагдсан.

```bash
git clone https://github.com/sergei10a-rgb/mongolgpt
cd mongolgpt
bun install
bun run dev
```

Ширээний програмыг хөгжүүлэлтийн горимоор ажиллуулах:

```bash
bun run dev:desktop
```

Windows суулгагч үүсгэх:

```powershell
$env:MONGOLGPT_CHANNEL="prod"
bun --cwd packages/desktop run package:win
```

Үүссэн файл `packages/desktop/dist/` хавтаст байрлана.

## Анхны ажиллагаа

CLI-г төслийнхөө хавтсаас эхлүүлнэ.

```bash
cd path/to/project
mongolgpt
```

Серверт байршуулсан үйлчилгээ идэвхтэй хувилбар дээр эхлээд MongolGPT бүртгэлээр нэвтэрнэ:

```bash
mongolgpt account login
```

Дараа нь:

1. `/connect` командаар үйлчилгээ үзүүлэгчээ сонгож API түлхүүр эсвэл тухайн үйлчилгээний нэвтрэх аргыг тохируулна.
2. `/models` командаар ашиглах боломжтой загваруудаа шалгана.
3. Загвараа сонгоод хийх ажлаа монгол эсвэл өөрийн хүссэн хэлээр тодорхой бичнэ.
4. Файл өөрчлөх, команд ажиллуулах зөвшөөрлийн хүсэлтийг уншаад зөвшөөрөх эсэхээ шийднэ.

```txt
/connect
/models
Энэ төслийн тест яагаад унаж байгааг шалгаад зас.
```

MongolGPT бүртгэл нь Free Auto, багц, хэрэглээний хязгаар болон төхөөрөмж хооронд хуваалцах ажлын талбарын эрхэд хэрэглэгдэнэ. OpenAI, Anthropic, Google, OpenRouter болон бусад үйлчилгээ үзүүлэгчийг өөрийн API түлхүүр эсвэл тухайн үйлчилгээний OAuth эрхээр нэмж болно. Ollama, LM Studio зэрэг локал загварын хүсэлт хэрэглэгчийн төхөөрөмжөөс гарна. Дэлгэрэнгүйг [бүртгэл ба багцын](./account) болон [үйлчилгээ үзүүлэгчдийн](./providers) заавраас үзнэ үү.

## Домэйн болон байршуулалт

Энгийн хэрэглэгч домэйн, DNS эсвэл байршуулалт тохируулахгүй. Ширээний програм болон CLI нь суулгасан хувилбарын сувагт тохирох MongolGPT үйлчилгээний URL-ийг өөрөө сонгоно. Локал болон BYOK ажиллагаа хэрэглэгчийн төхөөрөмж дээр үргэлжилнэ.

MongolGPT-ийг өөрөө хөгжүүлж байршуулж байгаа тохиолдолд `.env.example` доторх `https://your-domain.example` утгуудыг өөрийн Cloudflare орчны бодит URL-аар солино. Орлуулах жишиг хаяг нь ажилладаг үйлчилгээ биш. Нэвтрэлт/API-ийн эрүүл мэндийн шалгалт баталгаажаагүй орчинд `MONGOLGPT_ENABLE_HOSTED_SERVICES`-ийг идэвхжүүлэхгүй.

Энэ хуудас нь хамгийн их асуудаг асуултад товч хариулна. Алдааны дэлгэрэнгүй оношилгоог [алдаа оношлох заавар](../troubleshooting), суулгалтыг [Windows ба WSL](../windows-wsl), тохиргоог [тохиргоо](../config) хуудаснаас үзнэ үү.

## MongolGPT гэж юу вэ?

MongolGPT нь Монгол хэлний үндсэн интерфэйстэй AI код бичих агент. Вэб, Windows-ийн ширээний програм, CLI нь нэг MongolGPT бүртгэлийн үйлчилгээнд холбогдох архитектуртай; үйлдвэрлэлийн OAuth-ийн бодит эхнээс нь дуусталх баталгаажуулалт дууссаны дараа нийтэд нээнэ. Кодын хууль ёсны эх үүсвэр, гуравдагч талын лицензийг [экосистем](../ecosystem) болон репозиторийн эрхийн тэмдэглэлээс үзнэ үү.

## Яаж бүртгүүлж, нэвтрэх вэ?

Вэб дээр GitHub эсвэл Google OAuth-оор нэвтэрнэ. Амжилттай бүртгүүлсний дараа ижил бүртгэлээ ширээний програм болон CLI-д ашиглана. Нууц үгийн тусдаа MongolGPT бүртгэл байхгүй.

CLI-ийн хөтчийн нэвтрэлт дэмжигдэнэ. Харин албан ёсны байршуулсан орчинд төхөөрөмжийн кодоор нэвтрэх урсгал одоогоор идэвхжээгүй тул терминал дээрх төхөөрөмжийн кодын зааврыг ажиллаж байгаа боломж гэж бүү тооцоорой. Нэвтрэлт гацвал [бүртгэл](../account) болон [алдаа оношлох](../troubleshooting) хуудсыг үзнэ үү.

## Веб дээр локал төсөл ажиллах уу?

Вэб хөтөч өөрийн компьютерийн файлд шууд хүрэхгүй. Дотоод репозитор, терминал, Git болон дотоод загвар ашиглахын тулд аюулгүй дотоод гүүр эсвэл ширээний програм/CLI хэрэгтэй. Өөрийн компьютерт ажиллуулж буй вэб клиентэд `mongolgpt serve --port 4096` ажиллуулах заавар хэвийн. Харин албан ёсны `app.mgpt.mn` эсвэл түүний хөгжүүлэлтийн орчин нэвтрэх дэлгэцийн оронд энэ зааврыг харуулбал байршуулсан ажиллах орчны тохиргоо буруу гэсэн үг тул [алдаа оношлох](../troubleshooting) зааврыг дагана уу. [Вэб](../web), [CLI](../cli), [дотоод загварын үйлчилгээ үзүүлэгч](../providers) хуудсуудыг үзнэ үү.

## Ямар загвар ашиглаж болох вэ?

OpenRouter, NVIDIA NIM, OpenAI-тай нийцтэй API хаяг, өөрийн API түлхүүр болон дотоод үйлчилгээ үзүүлэгчийг тохируулж болно. Ширээний програмын Ollama, LM Studio түргэн тохиргоо нь loopback API хаягийг бөглөдөг; хэрэглэгч тухайн серверт ачаалсан загварын ID-г нэмж сонгоно. Загвар бүрийн tool calling, контекстийн хэмжээ болон OpenAI compatibility нь тухайн загвар, серверийн хувилбараас хамаарна.

Free Auto-ийн бодлого, үйлчилгээ үзүүлэгчийн эрх, үнэ болон хүсэлтийн давтамжийн хязгаар нь тухайн үйлчилгээ үзүүлэгчийн нөхцөлөөс хамаарна. OpenRouter free-ээс NVIDIA руу нөөц үйлчилгээ рүү шилжих ажиллагааг интерфэйсийн тайлбар дангаараа баталгаажуулахгүй; зөвхөн үйлдвэрлэлийн тохиргоо, үйлчилгээ үзүүлэгчийн эрүүл мэнд, хэрэглээний хязгаар бодитоор батлагдсан үед ажиллана. [Үйлчилгээ үзүүлэгчид](../providers) хуудсыг үзнэ үү.

## Миний токен эсвэл хэрэглээний хязгаар дуусвал яах вэ?

Free, Basic, Pro, Max төлөвлөгөө нь токен, өртөг болон хугацааны хязгаартай. Хязгаарт хүрвэл хүсэлтийг зөвшөөрөлгүйгээр үргэлжлүүлэхгүй, аюулгүй хаалттай төлөвөөр зогсоох эсвэл дахин оролдох хугацааг заана. Дахин оролдох нь хэрэглээний хязгаарыг тойрох арга биш. Төлөвлөгөө, хэрэглээний дэлгэрэнгүйг [төлбөр ба хэрэглээ](../billing) хуудаснаас үзнэ үү.

## Төлбөрийн талаар хаанаас харах вэ?

MongolGPT нь QPay болон Bonum-д зориулсан нэхэмжлэл, буцах дуудлагын шалгалт, давхар буцах дуудлагаас хамгаалах бүртгэл, хугацаа дуусах урсгалтай. Туршилтын орчин болон бодит төлбөр тусдаа: бодит мөнгө татахын өмнө төлбөр хүлээн авагч байгууллагын (`merchant`) тохиргоо, үйлдвэрлэлийн зөвшөөрөл, урьдчилсан шалгалт шаардлагатай. [Төлбөр ба хэрэглээ](../billing)-г уншина уу.

## Асуудлаа яаж мэдэгдэх вэ?

Эхлээд [алдаа оношлох ба түгээмэл асуулт](../troubleshooting)-ыг шалгаад хувилбар, үйлдлийн систем, тушаал, нууц мэдээлэлгүй бүртгэлийн хэсгээ бэлдэнэ. API түлхүүр, OAuth код, сессийн токеноо асуудлын бүртгэл, дэлгэцийн зураг, чатанд бүү оруул. Шийдэгдэхгүй бол репозиторийн GitHub Issues дээр давхардсан асуудлыг хайж байгаад мэдээлнэ.

Энэ хуудас нь хамгийн их асуудаг асуултад товч хариулна. Алдааны дэлгэрэнгүй оношилгоог [алдаа оношлох заавар](./troubleshooting), суулгалтыг [Windows ба WSL](./windows-wsl), тохиргоог [тохиргоо](./config) хуудаснаас үзнэ үү.

## MongolGPT гэж юу вэ?

MongolGPT нь Монгол хэлний үндсэн интерфэйстэй AI код бичих агент. Вэб, Windows-ийн ширээний програм, CLI нь нэг MongolGPT бүртгэлийн үйлчилгээнд холбогдох архитектуртай; үйлдвэрлэлийн OAuth-ийн бодит end-to-end баталгаажуулалт дууссаны дараа нийтэд нээнэ. Кодын хууль ёсны эх үүсвэр, гуравдагч талын лицензийг [экосистем](./ecosystem) болон репозиторийн attribution-оос үзнэ үү.

## Яаж бүртгүүлж, нэвтрэх вэ?

Вэб дээр GitHub эсвэл Google OAuth-оор нэвтэрнэ. Амжилттай бүртгүүлсний дараа ижил бүртгэлээ ширээний програм болон CLI-д ашиглана. Нууц үгийн тусдаа MongolGPT бүртгэл байхгүй.

CLI-ийн хөтчийн нэвтрэлт дэмжигдэнэ. Харин албан ёсны байршуулсан орчинд device-code grant одоогоор идэвхжээгүй тул terminal дээрх device code зааврыг ажиллаж байгаа боломж гэж бүү тооцоорой. Нэвтрэлт гацвал [бүртгэл](./account) болон [алдаа оношлох](./troubleshooting) хуудсыг үзнэ үү.

## Веб дээр локал төсөл ажиллах уу?

Вэб хөтөч өөрийн компьютерийн файлд шууд хүрэхгүй. Локал репозитор, терминал, Git болон локал загвар ашиглахын тулд аюулгүй локал гүүр эсвэл ширээний програм/CLI хэрэгтэй. Өөрийн компьютерт ажиллуулж буй вэб клиентэд `mongolgpt serve --port 4096` ажиллуулах заавар хэвийн. Харин албан ёсны `app.mgpt.mn` эсвэл түүний dev орчин нэвтрэх дэлгэцийн оронд энэ зааврыг харуулбал байршуулсан runtime-ийн тохиргоо буруу гэсэн үг тул [алдаа оношлох](./troubleshooting) зааврыг дагана уу. [Вэб](./web), [CLI](./cli), [локал загварын үйлчилгээ үзүүлэгч](./providers) хуудсуудыг үзнэ үү.

## Ямар загвар ашиглаж болох вэ?

OpenRouter, NVIDIA NIM, OpenAI-compatible endpoint, өөрийн API key болон локал үйлчилгээ үзүүлэгчийг тохируулж болно. Ollama, LM Studio зэрэг нь ерөнхий OpenAI-compatible холболтоор ажиллах боломжтой боловч бүх хувилбар, endpoint-ийн end-to-end дэмжлэгийг тусад нь шалгах шаардлагатай.

Free Auto-ийн бодлого, үйлчилгээ үзүүлэгчийн эрх, үнэ болон rate limit нь тухайн үйлчилгээ үзүүлэгчийн нөхцөлөөс хамаарна. OpenRouter free-ээс NVIDIA руу fallback хийхийг UI-ийн тайлбар дангаараа баталгаажуулахгүй; зөвхөн үйлдвэрлэлийн тохиргоо, үйлчилгээ үзүүлэгчийн эрүүл мэнд, quota бодитоор батлагдсан үед ажиллана. [Үйлчилгээ үзүүлэгчид](./providers) хуудсыг үзнэ үү.

## Миний токен эсвэл quota дуусвал яах вэ?

Free, Basic, Pro, Max төлөвлөгөө нь токен, өртөг болон хугацааны хязгаартай. Хязгаарт хүрвэл хүсэлт fail-closed байдлаар зогсох эсвэл дахин оролдох хугацааг заана. Дахин оролдох нь quota-г тойрох арга биш. Төлөвлөгөө, хэрэглээний дэлгэрэнгүйг [төлбөр ба хэрэглээ](./billing) хуудаснаас үзнэ үү.

## Төлбөрийн талаар хаанаас харах вэ?

MongolGPT нь QPay болон Bonum-д зориулсан нэхэмжлэл, callback шалгалт, давхар callback-оос хамгаалах бүртгэл, хугацаа дуусах урсгалтай. Sandbox болон бодит төлбөр тусдаа: бодит мөнгө татахын өмнө merchant тохиргоо, үйлдвэрлэлийн зөвшөөрөл, урьдчилсан шалгалт шаардлагатай. [Төлбөр ба хэрэглээ](./billing)-г уншина уу.

## Асуудлаа яаж мэдэгдэх вэ?

Эхлээд [алдаа оношлох ба түгээмэл асуулт](./troubleshooting)-ыг шалгаад хувилбар, үйлдлийн систем, команд, нууц мэдээлэлгүй логийн хэсгээ бэлдэнэ. API key, OAuth code, session token-оо issue, screenshot, чатанд бүү оруул. Шийдэгдэхгүй бол репозиторийн GitHub Issues дээр давхардсан асуудлыг хайж байгаад мэдээлнэ.

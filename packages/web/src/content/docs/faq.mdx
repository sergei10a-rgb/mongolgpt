Энэ хуудас нь хамгийн их асуудаг асуултыг товч хариулна. Алдааны дэлгэрэнгүй оношилгоог [алдаа оношлох заавар](./troubleshooting), суулгалтыг [Windows ба WSL](./windows-wsl), тохиргоог [тохиргоо](./config) хуудаснаас үзнэ үү.

## MongolGPT гэж юу вэ?

MongolGPT нь Монгол хэлний үндсэн интерфэйстэй AI coding agent. Web, Windows Desktop, CLI нь нэг MongolGPT аккаунтын үйлчилгээнд холбогдох архитектуртай; production OAuth-ийн live end-to-end баталгаажуулалт дууссаны дараа нийтэд нээнэ. Кодын хууль ёсны эх үүсвэр, гуравдагч талын лицензийг [экосистем](./ecosystem) болон repository-ийн attribution-оос үзнэ үү.

## Яаж бүртгүүлж, нэвтрэх вэ?

Web дээр GitHub эсвэл Google OAuth-оор нэвтэрнэ. Амжилттай бүртгүүлсний дараа ижил аккаунтаа Desktop болон CLI-д ашиглана. Нууц үгийн тусдаа MongolGPT бүртгэл байхгүй.

CLI-ийн браузер нэвтрэлт нь дэмжигдэнэ. Харин албан ёсны hosted орчинд device-code grant одоогоор идэвхжээгүй тул terminal дээрх device code зааврыг ажиллаж байгаа боломж гэж бүү тооцоорой. Нэвтрэлт гацвал [аккаунт](./account) болон [алдаа оношлох](./troubleshooting) хуудсыг үзнэ үү.

## Web дээр локал төсөл ажиллах уу?

Веб хөтөч өөрийн компьютерийн файлд шууд хүрэхгүй. Локал репозитор, терминал, Git болон локал загвар ашиглахын тулд аюулгүй локал гүүр эсвэл Desktop/CLI хэрэгтэй. Өөрийн компьютерт ажиллуулж буй веб клиентэд `mongolgpt serve --port 4096` ажиллуулах заавар хэвийн. Харин албан ёсны `app.mgpt.mn` эсвэл түүний dev орчин нэвтрэх дэлгэцийн оронд энэ зааврыг харуулбал байршуулсан runtime-ийн тохиргоо буруу гэсэн үг тул [алдаа оношлох](./troubleshooting) зааврыг дагана уу. [Веб](./web), [CLI](./cli), [локал загварын үйлчилгээ үзүүлэгч](./providers) хуудсуудыг үзнэ үү.

## Ямар загвар ашиглаж болох вэ?

OpenRouter, NVIDIA NIM, OpenAI-compatible endpoint, өөрийн API key болон local provider-ийг тохируулж болно. Ollama, LM Studio зэрэг нь generic OpenAI-compatible холболтоор ажиллах боломжтой боловч бүх хувилбар, endpoint-ийн end-to-end дэмжлэгийг тусад нь шалгах шаардлагатай.

Free Auto-ийн бодлого, provider-ийн эрх, үнэ болон rate limit нь тухайн provider-ийн нөхцөлөөс хамаарна. OpenRouter free-ээс NVIDIA руу fallback хийхийг UI-ийн тайлбар дангаараа баталгаажуулахгүй; зөвхөн production тохиргоо, provider health, quota бодитоор батлагдсан үед ажиллана. [Providers](./providers) хуудсыг үзнэ үү.

## Миний token эсвэл quota дуусвал яах вэ?

Free, Basic, Pro, Max төлөвлөгөө нь token, cost болон хугацааны хязгаартай. Хязгаарт хүрвэл хүсэлт fail-closed байдлаар зогсох эсвэл дахин оролдох хугацааг заана. Дахин оролдох нь quota-г тойрох арга биш. Төлөвлөгөө, хэрэглээний дэлгэрэнгүйг [төлбөр ба хэрэглээ](./billing) хуудаснаас үзнэ үү.

## Төлбөрийн талаар хаанаас харах вэ?

MongolGPT нь QPay болон Bonum-д зориулсан invoice, callback шалгалт, давхар callback-оос хамгаалах бүртгэл, expiry урсгалтай. Sandbox болон бодит төлбөр тусдаа: бодит мөнгө татахын өмнө merchant тохиргоо, production зөвшөөрөл, preflight шаардлагатай. [Төлбөр ба хэрэглээ](./billing)-г уншина уу.

## Асуудлаа яаж мэдэгдэх вэ?

Эхлээд [алдаа оношлох ба FAQ](./troubleshooting)-г шалгаад хувилбар, үйлдлийн систем, команд, нууц мэдээлэлгүй log-ийн хэсгээ бэлдэнэ. API key, OAuth code, session token-оо issue, screenshot, чатанд бүү оруул. Шийдэгдэхгүй бол repository-ийн GitHub Issues дээр давхардсан асуудлыг хайж байгаад мэдээлнэ.

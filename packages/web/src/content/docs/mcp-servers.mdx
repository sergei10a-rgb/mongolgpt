---

Та _Загварын контекст протокол_ буюу MCP ашиглан MongolGPT-д гадаад хэрэгсэл нэмж болно. MongolGPT нь локал болон алсын серверийг дэмждэг.

Нэмсний дараа MCP хэрэгслүүд нь суурилагдсан хэрэгслүүдийн хамт LLM-д автоматаар ашиглах боломжтой болно.

---

#### Анхааруулга

MCP сервер ашиглах бүрд контекстийн хэмжээ нэмэгдэнэ. Олон хэрэгсэл идэвхжүүлбэл энэ хэмжээ хурдан өсөх тул ашиглах MCP серверээ сонгохдоо болгоомжтой байхыг зөвлөж байна.

:::tip
MCP серверүүд контекстийн хэмжээг нэмдэг тул идэвхжүүлэх серверээ болгоомжтой сонгоно уу.
:::

GitHub MCP сервер зэрэг зарим сервер олон токен нэмдэг тул контекстийн хязгаарыг амархан хэтрүүлж болно.

---

## Идэвхжүүлэх

Та MCP серверүүдийг [MongolGPT тохиргооны](../config) `mcp` хэсэгт тодорхойлно. MCP бүрд давхардаагүй нэр өгвөл хүсэлт дотор тухайн нэрээр нь дуудаж болно.

```jsonc title="mongolgpt.jsonc" {6}
{
  "mcp": {
    "name-of-mcp-server": {
      // ...
      "enabled": true,
    },
    "name-of-other-mcp-server": {
      // ...
    },
  },
}
```

Мөн `enabled`-г `false` болгож серверийг идэвхгүй болгож болно. Ингэснээр серверийг тохиргооноос хасалгүйгээр түр идэвхгүй байлгана.

---

### Алсын өгөгдмөл тохиргоог хүчингүй болгох

Байгууллага `.well-known/mongolgpt` төгсгөлийн цэгээр дамжуулан өгөгдмөл MCP серверүүдийг өгч болно. Эдгээр сервер анхдагчаар идэвхгүй байж болох бөгөөд хэрэглэгч өөрт хэрэгтэй серверээ сонгон идэвхжүүлнэ.

Байгууллагын алсын тохиргоонд байгаа тодорхой серверийг идэвхжүүлэхийн тулд локал тохиргоондоо `enabled: true` гэж нэмнэ үү:

```json title="mongolgpt.json"
{
  "mcp": {
    "jira": {
      "type": "remote",
      "url": "https://jira.example.com/mcp",
      "enabled": true
    }
  }
}
```

Локал тохиргооны утга алсын өгөгдмөл утгыг дарна. [Тохиргооны тэргүүлэх дарааллыг](../config#тэргүүлэх-дараалал) харна уу.

## Локал сервер

MCP объектын `type` талбарыг `"local"` болгож локал MCP сервер нэмнэ.

```jsonc title="mongolgpt.jsonc" {15}
{
  "mcp": {
    "my-local-mcp-server": {
      "type": "local",
      // Эсвэл ["bun", "x", "my-mcp-command"]
      "command": ["npx", "-y", "my-mcp-command"],
      "enabled": true,
      "environment": {
        "MY_ENV_VAR": "my_env_var_value",
      },
    },
  },
}
```

Энэ нь локал MCP серверийг хэрхэн эхлүүлэхийг заана. Мөн орчны хувьсагчдыг тохируулж болно.

Жишээлбэл, тестийн [`@modelcontextprotocol/server-everything`](https://www.npmjs.com/package/@modelcontextprotocol/server-everything) MCP серверийг дараах байдлаар нэмнэ.

```jsonc title="mongolgpt.jsonc"
{
  "mcp": {
    "mcp_everything": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
    },
  },
}
```

Үүнийг ашиглахын тулд хүсэлтдээ `mcp_everything хэрэгслийг ашигла` гэж зааж болно.

```txt "mcp_everything"
mcp_everything хэрэгслээр 3 ба 4-ийг нэм
```

---

#### Сонголтууд

Локал MCP серверийн тохиргооны сонголтууд:

| Сонголт       | Төрөл   | Шаардлагатай | Тодорхойлолт                                                                           |
| ------------- | ------- | ------------ | -------------------------------------------------------------------------------------- |
| `type`        | Мөр     | Тийм         | MCP серверийн холболтын төрөл нь `"local"` байх ёстой.                                 |
| `command`     | Массив  | Тийм         | MCP серверийг ажиллуулах тушаал ба аргументууд.                                        |
| `cwd`         | Мөр     |              | MCP серверийн процессын ажлын лавлах. Харьцангуй замууд нь ажлын талбараас шийдэгддэг. |
| `environment` | Объект  |              | Серверийг ажиллуулах үед тохируулах орчны хувьсагчид.                                  |
| `enabled`     | Булев   |              | Эхлэх үед MCP серверийг идэвхжүүлэх эсвэл идэвхгүй болгох.                             |
| `timeout`     | Тоо     |              | Хэрэгслийн жагсаалт татах хүлээлтийн хугацаа (мс). Өгөгдмөл нь 5000 (5 секунд).         |

---

## Алсын сервер

`type`-г `"remote"` болгож алсын MCP серверүүдийг нэмнэ үү.

```json title="mongolgpt.json"
{
  "mcp": {
    "my-remote-mcp": {
      "type": "remote",
      "url": "https://my-mcp-server.com",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer MY_API_KEY"
      }
    }
  }
}
```

`url` нь алсын MCP серверийн URL. `headers` сонголтоор хүсэлтийн толгой хэсгүүдийг дамжуулж болно.

---

#### Сонголтууд

| Сонголт   | Төрөл   | Шаардлагатай | Тодорхойлолт                                                                         |
| --------- | ------- | ------------ | ------------------------------------------------------------------------------------ |
| `type`    | Мөр     | Тийм         | MCP серверийн холболтын төрөл нь `"remote"` байх ёстой.                              |
| `url`     | Мөр     | Тийм         | Алсын MCP серверийн URL.                                                             |
| `enabled` | Булев   |              | Эхлэх үед MCP серверийг идэвхжүүлэх эсвэл идэвхгүй болгох.                           |
| `headers` | Объект  |              | Хүсэлтийн хамт илгээх толгой хэсэг.                                                  |
| `oauth`   | Объект  |              | OAuth баталгаажуулалтын тохиргоо. Доорх [OAuth](#oauth) хэсгийг үзнэ үү.             |
| `timeout` | Тоо     |              | Хэрэгслийн жагсаалт татах хүлээлтийн хугацаа (мс). Өгөгдмөл нь 5000 (5 секунд).       |

## OAuth

MongolGPT алсын MCP серверийн OAuth баталгаажуулалтыг автоматаар зохицуулдаг. Сервер баталгаажуулалт шаардах үед MongolGPT:

1. 401 хариултыг илрүүлж, OAuth урсгалыг эхлүүлнэ
2. Сервер дэмждэг бол **Динамик клиент бүртгэл (RFC 7591)** ашиглана.
3. Дараагийн хүсэлтүүдэд ашиглах токеныг найдвартай хадгална.

---

### Автомат

Ихэнх OAuth-идэвхжүүлсэн MCP серверүүдийн хувьд тусгай тохиргоо хийх шаардлагагүй. Зүгээр л алсын серверийг тохируулна уу:

```json title="mongolgpt.json"
{
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp"
    }
  }
}
```

Сервер баталгаажуулалт шаардвал тухайн серверийг анх ашиглах үед MongolGPT нэвтрэхийг сануулна. Эсвэл `mongolgpt mcp auth <server-name>` ажиллуулж [баталгаажуулах урсгалыг гараар эхлүүлж болно](#баталгаажуулж-байна).

---

### Урьдчилан бүртгэсэн

Хэрэв танд MCP сервер үйлчилгээ үзүүлэгчээс үйлчлүүлэгчийн итгэмжлэл байгаа бол та тэдгээрийг тохируулж болно:

```json title="mongolgpt.json" {7-11}
{
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": {
        "clientId": "{env:MY_MCP_CLIENT_ID}",
        "clientSecret": "{env:MY_MCP_CLIENT_SECRET}",
        "scope": "tools:read tools:execute"
      }
    }
  }
}
```

---

### Баталгаажуулж байна

Та баталгаажуулалтыг гараар эхлүүлэх эсвэл итгэмжлэлийг удирдах боломжтой.

Тодорхой MCP серверт баталгаажуулах:

```bash
mongolgpt mcp auth my-oauth-server
```

Бүх MCP сервер болон тэдгээрийн баталгаажуулалтын төлөвийг жагсаах:

```bash
mongolgpt mcp list
```

Хадгалсан итгэмжлэлийг устгах:

```bash
mongolgpt mcp logout my-oauth-server
```

`mcp auth` тушаал зөвшөөрөл олгох хуудас бүхий хөтөчийг нээнэ. Таныг зөвшөөрсний дараа MongolGPT токеныг `~/.local/share/mongolgpt/mcp-auth.json`-д найдвартай хадгална.

---

#### OAuth-г идэвхгүй болгох

Сервер автомат OAuth-ийн оронд API түлхүүр ашигладаг бол `oauth`-г `false` гэж тохируулж автомат OAuth-г идэвхгүй болгоно:

```json title="mongolgpt.json" {7}
{
  "mcp": {
    "my-api-key-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": false,
      "headers": {
        "Authorization": "Bearer {env:MY_API_KEY}"
      }
    }
  }
}
```

---

#### OAuth тохиргооны сонголтууд

| Сонголт        | Төрөл           | Тодорхойлолт                                                                                |
| -------------- | --------------- | ------------------------------------------------------------------------------------------- |
| `oauth`        | Объект \| худал | OAuth тохиргооны объект эсвэл OAuth автомат илрүүлэлтийг идэвхгүй болгохын тулд `false`.    |
| `clientId`     | Мөр             | OAuth үйлчлүүлэгч ID. Хэрэв оруулаагүй бол динамик үйлчлүүлэгчийн бүртгэлийг оролдох болно. |
| `clientSecret` | Мөр             | Зөвшөөрлийн сервер шаардлагатай бол OAuth үйлчлүүлэгчийн нууц.                              |
| `scope`        | Мөр             | OAuth зөвшөөрөл авах үед хүсэх эрхүүд.                                                        |

#### Дибаг хийх

Алсын MCP серверийн баталгаажуулалт амжилтгүй болбол дараах тушаалаар асуудлыг оношилж болно.

```bash
# OAuth дэмждэг бүх серверийн auth төлөвийг харна
mongolgpt mcp auth list

# Сонгосон серверийн холболт болон OAuth урсгалыг оношлоно
mongolgpt mcp debug my-oauth-server
```

`mcp debug` тушаал одоогийн баталгаажуулалтын төлөвийг харуулж, HTTP холболтыг шалган, OAuth илрүүлэх урсгалыг ажиллуулна.

## Удирдах

Таны MCP нь суурилуулсан хэрэгслүүдийн хажуугаар MongolGPT-д хэрэгсэл хэлбэрээр байдаг. Тиймээс та бусад хэрэгслийн нэгэн адил MongolGPT тохиргоогоор дамжуулан тэдгээрийг удирдах боломжтой.

---

### Глобал

Энэ нь серверүүдийг глобал түвшинд идэвхжүүлэх эсвэл идэвхгүй болгох боломжтой гэсэн үг.

```json title="mongolgpt.json" {14}
{
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp-foo": false
  }
}
```

Мөн тохирох бүх MCP серверийг идэвхгүй болгохын тулд glob загвар ашиглаж болно.

```json title="mongolgpt.json" {14}
{
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp*": false
  }
}
```

Энд тохирох бүх MCP серверийг идэвхгүй болгохын тулд `my-mcp*` glob загвар ашиглаж байна.

---

### Агент тус бүрээр

Олон MCP сервертэй бол тодорхой серверийг зөвхөн нэг агент дээр идэвхжүүлж, глобал түвшинд идэвхгүй байлгаж болно. Үүнийг хийхийн тулд:

1. Үүнийг глобал түвшинд хэрэгсэл болгон идэвхгүй болгоно.
2. [Агентын тохиргоонд](../agents#хэрэгсэл-хуучирсан) MCP серверийн хэрэгслийг идэвхжүүлнэ.

```json title="mongolgpt.json" {11, 14-18}
{
  "mcp": {
    "my-mcp": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command"],
      "enabled": true
    }
  },
  "tools": {
    "my-mcp*": false
  },
  "agent": {
    "my-agent": {
      "tools": {
        "my-mcp*": true
      }
    }
  }
}
```

---

#### Glob загвар

Glob загвар нь энгийн тэмдэгт тааруулах дүрэм ашигладаг:

- `*` нь тэг буюу түүнээс олон тэмдэгттэй таарна (жишээ нь, `"my-mcp*"` нь `my-mcp_search`, `my-mcp_list` зэрэгтэй таарна)
- `?` нь яг нэг тэмдэгттэй таарна
- Бусад бүх тэмдэгт шууд утгаараа таарна

:::note
MCP серверийн хэрэгслүүд серверийн нэрээр эхэлсэн байдлаар бүртгэгддэг тул тухайн серверийн бүх хэрэгслийг идэвхгүй болгохын тулд дараахыг ашиглана уу:

```
"mymcpservername_*": false
```

:::

## Жишээ

Доор түгээмэл MCP серверүүдийг тохируулах жишээг үзүүлэв. Бусад серверийг баримтжуулах бол PR илгээж болно.

---

### Харуул

Sentry төсөл болон асуудлуудтайгаа ажиллахын тулд [Sentry MCP сервер](https://mcp.sentry.dev)-ийг нэмнэ үү.

```json title="mongolgpt.json" {4-8}
{
  "mcp": {
    "sentry": {
      "type": "remote",
      "url": "https://mcp.sentry.dev/mcp",
      "oauth": {}
    }
  }
}
```

Тохиргоог нэмсний дараа Sentry-д баталгаажуулна уу:

```bash
mongolgpt mcp auth sentry
```

Энэ нь OAuth урсгалыг дуусгах хөтчийн цонхыг нээж, MongolGPT-г таны Sentry бүртгэлтэй холбоно.

Баталгаажуулсны дараа хүсэлтдээ Sentry хэрэгслийг ашиглан асуудал, төсөл болон алдааны өгөгдлийг асууж болно.

```txt "use sentry"
Миний төслийн хамгийн сүүлийн шийдэгдээгүй issue-үүдийг харуул. sentry ашигла
```

### Контекст7

Баримт бичгээс хайлт хийхийн тулд [Context7 MCP сервер](https://github.com/upstash/context7)-ийг нэмнэ үү.

```json title="mongolgpt.json" {4-7}
{
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp"
    }
  }
}
```

Хэрэв та үнэгүй бүртгэл үүсгэсэн бол API түлхүүр ашиглан илүү өндөр хэрэглээний хязгаар авах боломжтой.

```json title="mongolgpt.json" {7-9}
{
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}"
      }
    }
  }
}
```

Энд `CONTEXT7_API_KEY` орчны хувьсагчийг тохируулсан гэж үзэв.

Context7 MCP серверийг ашиглахын тулд хүсэлтдээ `context7 ашигла` гэж нэмнэ үү.

```txt "use context7"
JSON API хариуг таван минут cache хийх Cloudflare Worker script тохируул. context7 ашигла
```

Эсвэл та [AGENTS.md](../rules/)-д ийм зүйл нэмж болно.

```md title="AGENTS.md"
Баримт бичиг хайх шаардлагатай үед `context7` хэрэгслүүдийг ашигла.
```

### Греп Версел

[Grep, Vercel](https://grep.app) MCP серверийг нэмээд GitHub дээрх кодын хэсгүүдээс хайлт хийнэ үү.

```json title="mongolgpt.json" {4-7}
{
  "mcp": {
    "gh_grep": {
      "type": "remote",
      "url": "https://mcp.grep.app"
    }
  }
}
```

MCP серверээ `gh_grep` гэж нэрлэсэн тул хүсэлтдээ `gh_grep хэрэгслийг ашигла` гэж нэмнэ үү.

```txt "gh_grep хэрэгслийг ашигла"
SST Astro бүрэлдэхүүнд захиалгат домэйн тохируулах зөв арга юу вэ? gh_grep хэрэгслийг ашигла
```

Эсвэл та [AGENTS.md](../rules/)-д ийм зүйл нэмж болно.

```md title="AGENTS.md"
Ямар нэг зүйлийг хэрхэн хийхээ мэдэхгүй байвал `gh_grep` ашиглан GitHub-аас кодын жишээ хай.
```

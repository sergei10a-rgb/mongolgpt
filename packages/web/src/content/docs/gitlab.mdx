MongolGPT-ийн release CLI нь Free Auto загварыг оролцуулан ашиглахын өмнө MongolGPT бүртгэл болон идэвхтэй ажлын орчин шаарддаг. GitLab-д зориулсан хуурамч component эсвэл GitLab Duo bot ашиглахгүй; албан ёсны CLI-г runner дээр ажиллуулна.

## Одоогоор дэмжих арга

Өөрийн удирддаг, хэрэглэгчийн home сангаа хадгалдаг GitLab runner ашиглана. Runner-ийн үйлдлийн системийн хэрэглэгчээр нэг удаа дараах командыг ажиллуулж, хөтчөөр нэвтрээд ажлын орчноо сонгоно:

```bash
mongolgpt account login
mongolgpt account status
```

Нэвтрэлтийн access болон refresh token нь тухайн хэрэглэгчийн MongolGPT өгөгдлийн санд үйлдлийн системийн нууцлалын сангаар шифрлэгдэн хадгалагдана. Token эсвэл өгөгдлийн санг repository, artifact, cache руу хуулж болохгүй.

:::caution
Шинэ container үүсгээд устгадаг shared/ephemeral runner-д зориулсан non-interactive service account нэвтрэлт хараахан release болоогүй. Тийм runner дээр account gate-ийг тойрох, token database-ийг CI secret болгон хуулах зааврыг MongolGPT дэмжихгүй.
:::

## GitLab CI

Provider-ийн API түлхүүр болон prompt-оо GitLab-ийн **Settings > CI/CD > Variables** хэсэгт masked, шаардлагатай бол protected хувьсагчаар хадгална. Жишээлбэл, `ANTHROPIC_API_KEY` болон `MONGOLGPT_PROMPT` хувьсагч үүсгэнэ.

Өөрийн удирддаг shell runner-ийн `.gitlab-ci.yml` файлд:

```yaml title=".gitlab-ci.yml"
mongolgpt:
  tags: [mongolgpt]
  script:
    - mongolgpt account status
    - mongolgpt run "$MONGOLGPT_PROMPT"
```

Runner дээр MongolGPT суулгаагүй бол администратор нь албан ёсны суулгах скриптийг нэг удаа ажиллуулна:

```bash
curl -fsSL https://raw.githubusercontent.com/sergei10a-rgb/mongolgpt/main/install | bash
```

`mongolgpt run` нь runner-ийн checkout хийсэн репозиторт ажиллана. Загвар болон provider-ийг `mongolgpt.json` тохиргоонд заана. CI job-д өөрчлөлт commit, push хийх шаардлагатай бол GitLab token болон repository permission-ийг тусад нь тохируулж, push хийх алхмыг workflow-д ил тод нэмнэ.

Дэлгэрэнгүйг [GitLab CI/CD баримт](https://docs.gitlab.com/ci/) болон [MongolGPT repository](https://github.com/sergei10a-rgb/mongolgpt)-оос үзнэ үү.

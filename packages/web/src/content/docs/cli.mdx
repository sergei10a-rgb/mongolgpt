CLI-г [GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ээс суулгасны дараа хувилбараа шалгана.

```bash
mongolgpt --version
```

## Түргэн эхлэх

MongolGPT CLI-г аргументгүй ажиллуулахад [TUI](../tui) нээгдэнэ.

```bash
mongolgpt
```

Нэг удаагийн ажлыг интерактив интерфэйсгүй ажиллуулах бол `run` командыг ашиглана.

```bash
mongolgpt run "Энэ төслийн унаж байгаа тестийг олж тайлбарла."
```

Үйлчилгээ үзүүлэгч холбож, загвар сонгох үндсэн дараалал:

```txt
/connect
/models
```

Командын тусламжийг аль ч түвшинд `--help` сонголтоор харж болно.

```bash
mongolgpt --help
mongolgpt run --help
```

### tui

MongolGPT терминалын хэрэглэгчийн интерфэйсийг эхлүүлнэ үү.


| <nobr><code>{"--model"}</code></nobr>       | `-m`   | `provider/model` хэлбэрийн загварын ID                             |
| <nobr><code>{"--agent"}</code></nobr>       |        | Ашиглах агент                                                      |

## Командууд

MongolGPT CLI нь мөн дараах тушаалуудтай.

---

### agent

MongolGPT-ийн агентуудыг удирдана.

```bash
mongolgpt agent [command]
```

---

#### `create`

Өөрчлөн тохируулсан шинэ агент үүсгэнэ үү.

```bash
mongolgpt agent create
```

Энэ команд тусгай системийн заавар, зөвшөөрлийн тохиргоо бүхий шинэ агент үүсгэхэд тусална. Зөвшөөрөөгүй бүх үйлдлийг шинээр үүссэн агентын тохиргоонд хориглоно.

#### Сонголтууд

| Туг                                         | Богино | Тодорхойлолт                                                                                                                                                                                                                                       |
| ------------------------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <nobr><code>{"--path"}</code></nobr>        |        | Агентын файлыг бичих лавлах; заагаагүй бол глобал эсвэл төслийн `.mongolgpt/agent` лавлахыг сонгохыг асууна                                                                                                                                        |
| <nobr><code>{"--description"}</code></nobr> |        | Агент юу хийх ёстой вэ                                                                                                                                                                                                                             |
| <nobr><code>{"--mode"}</code></nobr>        |        | Агент горим: `all`, `primary`, эсвэл `subagent`                                                                                                                                                                                                    |
| <nobr><code>{"--permissions"}</code></nobr> |        | Зөвшөөрөх үйлдлүүдийн таслалаар тусгаарласан жагсаалт (өгөгдмөл: бүгд). Боломжтой: `bash`, `read`, `edit`, `glob`, `grep`, `webfetch`, `task`, `todowrite`, `websearch`, `lsp`, `skill`. Жагсаалтад ороогүй үйлдлийг хориглоно. Өөр нэр: `--tools` |
| <nobr><code>{"--model"}</code></nobr>       | `-m`   | Ашиглах загвар, `provider/model` хэлбэр                                                                                                                                                                                                            |

`--path`, `--description`, `--mode`, `--permissions`-г бүгдийг нь дамжуулснаар командыг интерактив бус байдлаар ажиллуулна.

### attach

`serve` эсвэл `web` командаар эхлүүлсэн, ажиллаж буй MongolGPT серверт терминалыг холбоно.

```bash
mongolgpt attach [url]
```

Энэ нь алсын удирдлагатай TUI-г ашиглах боломжийг олгодог. Жишээ нь:

```bash
# Вэб болон мобайл хандалтын серверийг эхлүүлнэ
mongolgpt web --port 4096 --hostname 0.0.0.0

# Өөр терминалаас TUI-г ажиллаж буй серверт холбоно
mongolgpt attach http://10.20.30.40:4096
```

#### Сонголтууд

| Туг                                      | Богино | Тодорхойлолт                                                                                              |
| ---------------------------------------- | ------ | --------------------------------------------------------------------------------------------------------- |
| <nobr><code>{"--dir"}</code></nobr>      |        | TUI-г эхлүүлэх ажлын лавлах                                                                               |
| <nobr><code>{"--continue"}</code></nobr> | `-c`   | Сүүлийн сессийг үргэлжлүүлэх                                                                              |
| <nobr><code>{"--session"}</code></nobr>  | `-s`   | Үргэлжлүүлэхийн тулд сесс ID                                                                              |
| <nobr><code>{"--fork"}</code></nobr>     |        | `--continue` эсвэл `--session`-ээр үргэлжлүүлэх сессээс шинэ салаа үүсгэнэ                                |
| <nobr><code>{"--password"}</code></nobr> | `-p`   | HTTP суурь баталгаажуулалтын нууц үг (өгөгдмөл нь `MONGOLGPT_SERVER_PASSWORD`)                            |
| <nobr><code>{"--username"}</code></nobr> | `-u`   | HTTP суурь баталгаажуулалтын хэрэглэгчийн нэр (өгөгдмөл нь `MONGOLGPT_SERVER_USERNAME` эсвэл `mongolgpt`) |

### account

MongolGPT бүртгэл, Free Auto эрх, багц болон идэвхтэй ажлын орчноо удирдана. Free Auto нь төлбөртэй багц шаардахгүй боловч MongolGPT бүртгэлээр нэвтэрсэн байна.

```bash
mongolgpt account [command]
mongolgpt account login
mongolgpt account status
mongolgpt account open
mongolgpt account logout
```

Өөрийн API түлхүүртэй үйлчилгээ үзүүлэгч болон локал загвар нэмэх нь сонголттой бөгөөд `account login`-оос тусдаа урсгал юм. Дэлгэрэнгүйг [Бүртгэл, Free Auto ба багцууд](../account) хэсгээс үзнэ үү.

### providers

Өөрийн API түлхүүр, OAuth эрх болон үйлчилгээ үзүүлэгчийн баталгаажуулалтыг удирдана.

```bash
mongolgpt providers [command]
```

---

#### login

MongolGPT нь үйлчилгээ үзүүлэгчийн жагсаалтыг [Models.dev](https://models.dev)-ээс авдаг. Ашиглах үйлчилгээ үзүүлэгчийн API түлхүүр эсвэл OAuth эрхийг тохируулахдаа `mongolgpt providers login` ажиллуулна. Нэвтрэх мэдээллийг `~/.local/share/mongolgpt/auth.json` файлд хадгална.

```bash
mongolgpt providers login
```

MongolGPT эхлэхдээ нэвтрэх мэдээллийн файл, орчны хувьсагч болон төслийн `.env` файлд тодорхойлсон түлхүүрүүдийг ачаална.

##### Сонголтууд

| Туг                                      | Богино | Тодорхойлолт                                         |
| ---------------------------------------- | ------ | ---------------------------------------------------- |
| <nobr><code>{"--provider"}</code></nobr> | `-p`   | Нэвтрэх үйлчилгээ үзүүлэгчийн ID                     |
| <nobr><code>{"--method"}</code></nobr>   | `-m`   | Ашиглах нэвтрэх аргын шошго, аргын сонголтыг алгасах |

---

#### list

Итгэмжлэлийн файлд хадгалагдсан бүх баталгаажсан үйлчилгээ үзүүлэгчдийг жагсаана.

```bash
mongolgpt providers list
```

Эсвэл богино хувилбар.

```bash
mongolgpt providers ls
```

---

#### logout

Таныг итгэмжлэлийн файлаас устгаснаар үйлчилгээ үзүүлэгчээс гарна.

```bash
mongolgpt providers logout
```


### mcp

Загварын контекст протоколын серверүүдийг удирдах.

```bash
mongolgpt mcp [command]
```

---

#### add

Өөрийн тохиргоонд MCP сервер нэмнэ үү.

```bash
mongolgpt mcp add
```

Энэ тушаал нь таныг дотоод эсвэл алсын MCP сервер нэмэхэд чиглүүлэх болно.

---

#### list

Бүх тохируулсан MCP серверүүд болон тэдгээрийн холболтын статусыг жагсаа.

```bash
mongolgpt mcp list
```

Эсвэл богино хувилбарыг ашиглана уу.

```bash
mongolgpt mcp ls
```

---

#### auth

OAuth идэвхжүүлсэн MCP серверээр баталгаажуулна уу.

```bash
mongolgpt mcp auth [name]
```

Хэрэв та серверийн нэр өгөхгүй бол OAuth боломжтой серверүүдээс сонгохыг хүсэх болно.

Та мөн OAuth чадвартай серверүүд болон тэдгээрийн баталгаажуулалтын статусыг жагсааж болно.

```bash
mongolgpt mcp auth list
```

Эсвэл богино хувилбарыг ашиглана уу.

```bash
mongolgpt mcp auth ls
```

---

#### logout

MCP серверийн OAuth итгэмжлэлийг устгана уу.

```bash
mongolgpt mcp logout [name]
```

---

#### debug

MCP серверийн OAuth холболтын асуудлыг дибаг хийх.

```bash
mongolgpt mcp debug <name>
```

### models

Тохируулсан үйлчилгээ үзүүлэгчээс боломжтой бүх загваруудыг жагсаана уу.

```bash
mongolgpt models [provider]
```

Энэ тушаал нь тохируулсан үйлчилгээ үзүүлэгчдийн бүх загварыг `provider/model` хэлбэрээр харуулна.

Энэ нь [таны тохиргоо](../config/)-д яг ямар загварын нэрийг ашиглахыг олоход хэрэгтэй.

Үйлчилгээ үзүүлэгчийн ID-г нэмэлт аргументаар өгч, загварын жагсаалтыг тухайн үйлчилгээ үзүүлэгчээр шүүж болно.

```bash
mongolgpt models anthropic
```

#### Сонголтууд

| Туг                                     | Тодорхойлолт                                                                |
| --------------------------------------- | --------------------------------------------------------------------------- |
| <nobr><code>{"--refresh"}</code></nobr> | models.dev сайтаас загварын кэшийг шинэчилнэ                                |
| <nobr><code>{"--verbose"}</code></nobr> | Илүү дэлгэрэнгүй загвар гаралтыг ашиглах (зардал гэх мэт мета өгөгдөл орно) |

`--refresh` тугийг ашиглан кэштэй загварын жагсаалтыг шинэчилнэ үү. Энэ нь үйлчилгээ үзүүлэгчид шинэ загвар нэмэгдсэн бөгөөд та тэдгээрийг MongolGPT дээр харахыг хүсвэл хэрэг болно.

```bash
mongolgpt models --refresh
```

### run

Хүсэлтийг шууд дамжуулж MongolGPT-г интерактив бус горимд ажиллуулна.

```bash
mongolgpt run [message..]
```

Энэ нь скрипт бичих, автоматжуулалт эсвэл TUI-г бүрэн эхлүүлэхгүйгээр хурдан хариулт авахыг хүссэн үед хэрэгтэй. Жишээ нь.

```bash "mongolgpt run"
mongolgpt run Go хэлэнд context хэрхэн ашигладгийг тайлбарла
```

Мөн ажиллаж буй `mongolgpt serve` серверт холбож, команд ажиллуулах бүрд MCP серверүүдийг дахин ачаалахаас зайлсхийж болно.

```bash
# Нэг терминалд дэлгэцгүй серверийг эхлүүлнэ
mongolgpt serve

# Өөр терминалаас серверт холбогдох команд ажиллуулна
mongolgpt run --attach http://localhost:4096 "JavaScript-ийн async/await-ийг тайлбарла"
```

### serve

API-д хандахын тулд толгойгүй MongolGPT сервер ажиллуулна уу. Бүрэн HTTP интерфэйсийг [серверийн баримт бичгээс](../server) үзнэ үү.

```bash
mongolgpt serve
```

Энэ нь TUI интерфэйсгүйгээр mongolgpt функцэд API хандалтыг хангадаг HTTP серверийг эхлүүлнэ. HTTP үндсэн баталгаажуулалтыг идэвхжүүлэхийн тулд `MONGOLGPT_SERVER_PASSWORD`-г тохируулна уу (хэрэглэгчийн нэр нь `mongolgpt`).

#### Сонголтууд

| Туг                                         | Тодорхойлолт                                       |
| ------------------------------------------- | -------------------------------------------------- |
| <nobr><code>{"--port"}</code></nobr>        | Сонсох порт                                        |
| <nobr><code>{"--hostname"}</code></nobr>    | Сонсох хостын нэр                                  |
| <nobr><code>{"--mdns"}</code></nobr>        | mDNS илрүүлэлтийг идэвхжүүлэх                      |
| <nobr><code>{"--mdns-domain"}</code></nobr> | Захиалгат mDNS домэйн нэр                          |
| <nobr><code>{"--cors"}</code></nobr>        | CORS \| зөвшөөрөх нэмэлт хөтчийн гарал үүсэл(үүд). |

### stats

MongolGPT сессийн токен ашиглалт болон зардлын статистикийг харуул.

```bash
mongolgpt stats
```

#### Сонголтууд

| Туг                                     | Тодорхойлолт                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| <nobr><code>{"--days"}</code></nobr>    | Сүүлийн N өдрийн статистикийг харуулах (бүх цаг үед)                                                               |
| <nobr><code>{"--tools"}</code></nobr>   | Харуулах хэрэгслийн тоо (бүгд)                                                                                     |
| <nobr><code>{"--models"}</code></nobr>  | Загварын ашиглалтын задаргааг харуулах (өгөгдмөлөөр нуугдсан). Шилдэг N \|-г харуулахын тулд дугаарыг дамжуулаарай |
| <nobr><code>{"--project"}</code></nobr> | Төслөөр шүүх (бүх төсөл, хоосон мөр: одоогийн төсөл)                                                               |

### export

Сеанс өгөгдлийг JSON хэлбэрээр экспортлох.

```bash
mongolgpt export [sessionID]
```

Хэрэв та ID сессийг өгөхгүй бол боломжтой сешнүүдээс сонгохыг танаас хүсэх болно.

#### Сонголтууд

| Туг                                      | Тодорхойлолт                             |
| ---------------------------------------- | ---------------------------------------- |
| <nobr><code>{"--sanitize"}</code></nobr> | Эмзэг хуулбар/файлын өгөгдлийг засварлах |

### import

JSON файлаас сессийн өгөгдөл импортлоно.

```bash
mongolgpt import <file>
```

Одоогийн нээлтийн тохиргоонд нийтийн сесс хуваалцах сервер дэмжигдээгүй тул локал экспортын файл ашиглана.

```bash
mongolgpt import session.json
```

### web

Вэб интерфэйстэй толгойгүй MongolGPT серверийг эхлүүл.

```bash
mongolgpt web
```

Энэ нь HTTP серверийг эхлүүлж, вэб интерфэйсээр дамжуулан MongolGPT руу хандах вэб хөтчийг нээнэ. HTTP үндсэн баталгаажуулалтыг идэвхжүүлэхийн тулд `MONGOLGPT_SERVER_PASSWORD`-г тохируулна уу (хэрэглэгчийн нэр нь `mongolgpt`).

#### Сонголтууд

| Туг                                         | Тодорхойлолт                                       |
| ------------------------------------------- | -------------------------------------------------- |
| <nobr><code>{"--port"}</code></nobr>        | Сонсох порт                                        |
| <nobr><code>{"--hostname"}</code></nobr>    | Сонсох хостын нэр                                  |
| <nobr><code>{"--mdns"}</code></nobr>        | mDNS илрүүлэлтийг идэвхжүүлэх                      |
| <nobr><code>{"--mdns-domain"}</code></nobr> | Захиалгат mDNS домэйн нэр                          |
| <nobr><code>{"--cors"}</code></nobr>        | CORS \| зөвшөөрөх нэмэлт хөтчийн гарал үүсэл(үүд). |

### acp

ACP (Agent Client Protocol) серверийг эхлүүлнэ үү. Энэ нь агент болон клиент хоорондын протоколын сервер юм.

```bash
mongolgpt acp
```

Энэ тушаал нь nd-JSON ашиглан stdin/stdout-ээр холбогддог ACP серверийг эхлүүлнэ.

#### Сонголтууд

| Туг                                         | Тодорхойлолт                                       |
| ------------------------------------------- | -------------------------------------------------- |
| <nobr><code>{"--cwd"}</code></nobr>         | Ажлын лавлах                                       |
| <nobr><code>{"--port"}</code></nobr>        | Сонсох порт                                        |
| <nobr><code>{"--hostname"}</code></nobr>    | Сонсох хостын нэр                                  |
| <nobr><code>{"--mdns"}</code></nobr>        | mDNS илрүүлэлтийг идэвхжүүлэх                      |
| <nobr><code>{"--mdns-domain"}</code></nobr> | Захиалгат mDNS домэйн нэр                          |
| <nobr><code>{"--cors"}</code></nobr>        | CORS \| зөвшөөрөх нэмэлт хөтчийн гарал үүсэл(үүд). |

### `plugin`


```bash
mongolgpt plug <module>
```

#### Сонголтууд

| Туг                                    | Богино | Тодорхойлолт                           |
| -------------------------------------- | ------ | -------------------------------------- |
| <nobr><code>{"--global"}</code></nobr> | `-g`   | Глобал тохиргоонд суулгана уу          |
| <nobr><code>{"--force"}</code></nobr>  | `-f`   | Одоо байгаа залгаасын хувилбарыг солих |

### uninstall


#### Сонголтууд

| Туг                                         | Богино | Тодорхойлолт                                        |
| ------------------------------------------- | ------ | --------------------------------------------------- |
| <nobr><code>{"--keep-config"}</code></nobr> | `-c`   | Тохиргооны файлуудыг хадгалах                       |
| <nobr><code>{"--keep-data"}</code></nobr>   | `-d`   | Сеансын өгөгдөл болон агшин зуурын зургийг хадгалах |
| <nobr><code>{"--dry-run"}</code></nobr>     |        | Устгахгүйгээр юу устгахыг харуулах                  |
| <nobr><code>{"--force"}</code></nobr>       | `-f`   | Баталгаажуулах сануулгыг алгасах                    |

### upgrade

mongolgpt-г хамгийн сүүлийн хувилбар эсвэл тодорхой хувилбар руу шинэчилнэ.

```bash
mongolgpt upgrade [target]
```

Хамгийн сүүлийн хувилбар руу шинэчлэхийн тулд.

```bash
mongolgpt upgrade
```

Тодорхой хувилбар руу шинэчлэхийн тулд.

```bash
mongolgpt upgrade v0.1.48
```

#### Сонголтууд

| Туг                                    | Богино | Тодорхойлолт                                       |
| -------------------------------------- | ------ | -------------------------------------------------- |
| <nobr><code>{"--method"}</code></nobr> | `-m`   | Суулгах арга: `curl`, `npm`, `pnpm`, `bun`, `brew` |

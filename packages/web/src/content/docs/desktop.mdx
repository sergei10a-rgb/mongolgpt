MongolGPT Desktop нь локал файл, Git, terminal, MCP, skill болон plugin-тэй ажиллах үндсэн клиент юм. Вэб клиентээс
ялгаатай нь таны сонгосон төслийн хавтаст зөвшөөрлийн хүрээнд шууд ажиллана.

:::caution[Хөгжүүлэлтийн үйлчилгээ]
`*.dev.mgpt.mn` нэвтрэлт болон Free Auto нь туршилтын орчин. Production нээлт зарлагдахаас өмнө бодит төлбөрийн мэдээлэл
бүү оруул. Өөрийн API түлхүүр болон локал загварыг ашиглах боломж нь MongolGPT-ийн багцаас тусдаа.
:::

## Суулгах

Windows-ийн суулгагчийг зөвхөн [MongolGPT Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ээс татна.
Файлын нэр, checksum болон SmartScreen анхааруулгыг [суулгах гарын авлагаар](./install) шалгана.

Одоогийн албан ёсны Windows файлын нэр:

```text
mongolgpt-desktop-win-x64.exe
```

## Анхны нээлт

1. MongolGPT-ийг нээнэ.
2. Интерфэйс Монгол хэлээр нээгдсэн эсэхийг шалгана. Өмнөх туршилтын тохиргоо хадгалагдсан бол **Тохиргоо → Хэл**
   хэсгээс **Монгол** сонгож програмыг дахин нээнэ.
3. **Нээлттэй төсөл** товчоор ажиллах хавтсаа сонгоно.
4. Төслийн файлуудыг унших, terminal ажиллуулах болон өөрчлөлт бичих зөвшөөрлийг хүсэлт бүрээр нь хянана.
5. Нууц түлхүүр, `.env` болон credential файлыг model руу илгээхээс өмнө зөвшөөрлийн дэлгэцийг шалгана.

## MongolGPT бүртгэлээр нэвтрэх

Удирдлагатай Free Auto эсвэл багц ашиглах үед **Тохиргоо → Бүртгэл → Нэвтрэх**-ийг сонгоно. Системийн хөтөч GitHub
эсвэл Google OAuth хуудсыг нээж, зөвшөөрсний дараа програм руу буцаана. Нэвтрэлтийн урсгалын одоогийн төлөв болон багцын
хязгаарыг [бүртгэлийн заавраас](./account) харна уу.

Нэвтрэлт дуусахгүй бол:

1. Хөтөч дээрх callback хаяг `auth.mgpt.mn` эсвэл хөгжүүлэлтийн үед `auth.dev.mgpt.mn` мөн эсэхийг шалгана.
2. VPN, proxy, firewall нь callback болон `app.mgpt.mn` хаягийг хаагаагүй эсэхийг шалгана.
3. Хуучин dev build ашиглаж байгаа бол хамгийн сүүлийн Release рүү шинэчилнэ.
4. [Нэвтрэлт болон холболтын алдаа оношлох](./troubleshooting) зааврыг ашиглана.

## Өөрийн API түлхүүр холбох

MongolGPT бүртгэлгүй эсвэл удирдлагатай багцаас тусдаа өөрийн provider ашиглаж болно.

1. **Тохиргоо → Үйлчилгээ үзүүлэгчид** хэсгийг нээнэ.
2. OpenRouter, NVIDIA NIM, OpenAI-compatible эсвэл ашиглах provider-оо сонгоно.
3. API түлхүүрээ зөвхөн MongolGPT-ийн credential талбарт оруулна.
4. Model-оо сонгоод шинэ сессээр богино хүсэлт туршина.

Provider бүрийн endpoint, model ID болон аюулгүй хадгалалтын мэдээллийг [үйлчилгээ үзүүлэгчдийн заавраас](./providers)
харна уу.

## Ollama эсвэл LM Studio холбох

Локал model server-ээ эхлүүлсний дараа OpenAI-compatible endpoint эсвэл тухайн provider-ийн сонголтоор холбоно. Жишээ
endpoint-ууд:

```text
http://127.0.0.1:11434
http://127.0.0.1:1234/v1
```

`0.0.0.0` дээр нээлттэй, нууцлалгүй endpoint-ийг нийтийн сүлжээнд бүү ажиллуул. Model харагдахгүй бол server-ийн model
list endpoint ажиллаж байгаа эсэх, firewall болон context хэмжээний тохиргоог шалгана. Дэлгэрэнгүйг
[Ollama](./providers#ollama) болон [LM Studio](./providers#lm-studio)-ийн хэсгээс харна уу.

## Төсөл ба зөвшөөрөл

- Нэг сессийг нэг төслийн root-той ажиллуулна.
- Git diff-ийг өөрчлөлт батлахаас өмнө хянана.
- Shell command, файл устгах, сүлжээ ашиглах болон repository-оос гадуур бичих хүсэлтийг тусад нь зөвшөөрнө.
- MCP, skill эсвэл plugin нэмэхдээ publisher, эх код, command болон шаардах environment variable-ийг шалгана.
- Танихгүй интеграцид API түлхүүрээ шууд дамжуулахгүй.

MCP болон өргөтгөлийн дэлгэрэнгүй: [MCP серверүүд](./mcp-servers), [агентын ур чадвар](./skills),
[plugin-ууд](./plugins).

## Шинэчлэх

Шинэ хувилбарын мэдэгдэл гарвал Release-ийн хувилбар, checksum болон changelog-ийг шалгаад шинэчилнэ. Auto-update ажиллахгүй
эсвэл суулгагчийн гарын үсэг өөрчлөгдвөл хуучин хувилбарыг устгалгүйгээр шинэ файлыг ажиллуулахгүй, эхлээд
[GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-тэй тулгана.

## Асуудал гарвал

Дараах мэдээллийг нууц түлхүүргүйгээр тэмдэглээд [алдаа оношлох зааврыг](./troubleshooting#ширээний-програм) ашиглана:

- MongolGPT хувилбар;
- Windows хувилбар ба архитектур;
- нээсэн төслийн төрөл;
- алдаа гарсан яг үйлдэл;
- Монгол алдааны бүтэн текст;
- log-ийн credential агуулаагүй хэсэг.

UI хоосон, icon эсвэл брэнд буруу, хэл дахин англи болдог, login callback тасардаг зэрэг асуудлыг Release-ийн issue-д
дахин гаргах алхамтай нь мэдээлнэ.

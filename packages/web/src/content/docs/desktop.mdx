MongolGPT Desktop нь дотоод файл, Git, терминал, MCP, агентын ур чадвар болон залгаастай ажиллах үндсэн програм юм. Вэб хувилбараас
ялгаатай нь таны сонгосон төслийн хавтаст зөвшөөрлийн хүрээнд шууд ажиллана.

:::caution[Хөгжүүлэлтийн үйлчилгээ]
`*.dev.mgpt.mn` нэвтрэлт болон Free Auto нь туршилтын орчин. Үйлдвэрлэлийн нээлт зарлагдахаас өмнө бодит төлбөрийн мэдээлэл
бүү оруул. Өөрийн API түлхүүр болон локал загварыг ашиглах боломж нь MongolGPT-ийн багцаас тусдаа.
:::

## Суулгах

Windows-ийн суулгагчийг зөвхөн [MongolGPT Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ээс татна.
Файлын нэр, checksum болон SmartScreen анхааруулгыг [суулгах гарын авлагаар](../install) шалгана.

Одоогийн албан ёсны Windows файлын нэр:

```text
mongolgpt-desktop-win-x64.exe
```

## Анхны нээлт

1. MongolGPT-ийг нээнэ.
2. Интерфэйс Монгол хэлээр нээгдсэн эсэхийг шалгана. Өмнөх туршилтын тохиргоо хадгалагдсан бол **Тохиргоо → Хэл**
   хэсгээс **Монгол** сонгож програмыг дахин нээнэ.
3. **Нээлттэй төсөл** товчоор ажиллах хавтсаа сонгоно.
4. Төслийн файлуудыг унших, терминал ажиллуулах болон өөрчлөлт бичих зөвшөөрлийг хүсэлт бүрээр нь хянана.
5. Нууц түлхүүр, `.env` болон нэвтрэх мэдээллийн файлыг загвар руу илгээхээс өмнө зөвшөөрлийн дэлгэцийг шалгана.

## MongolGPT бүртгэлээр нэвтрэх

Удирдлагатай Free Auto эсвэл багц ашиглах үед **Тохиргоо → Бүртгэл → Нэвтрэх**-ийг сонгоно. Системийн хөтөч GitHub
эсвэл Google OAuth хуудсыг нээж, зөвшөөрсний дараа програм руу буцаана. Нэвтрэлтийн урсгалын одоогийн төлөв болон багцын
хязгаарыг [бүртгэлийн заавраас](../account) харна уу.

Нэвтрэлт дуусахгүй бол:

1. Хөтөч дээрх буцах дуудлагын хаяг `auth.mgpt.mn` эсвэл хөгжүүлэлтийн үед `auth.dev.mgpt.mn` мөн эсэхийг шалгана.
2. VPN, прокси, firewall нь буцах дуудлага болон `app.mgpt.mn` хаягийг хаагаагүй эсэхийг шалгана.
3. Хуучин хөгжүүлэлтийн бүтээлт ашиглаж байгаа бол хамгийн сүүлийн хувилбар руу шинэчилнэ.
4. [Нэвтрэлт болон холболтын алдаа оношлох](../troubleshooting) зааврыг ашиглана.

## Өөрийн API түлхүүр холбох

MongolGPT бүртгэлгүй эсвэл удирдлагатай багцаас тусдаа өөрийн үйлчилгээ үзүүлэгчийг ашиглаж болно.

1. **Тохиргоо → Үйлчилгээ үзүүлэгчид** хэсгийг нээнэ.
2. OpenRouter, NVIDIA NIM, OpenAI-compatible эсвэл ашиглах үйлчилгээ үзүүлэгчээ сонгоно.
3. API түлхүүрээ зөвхөн MongolGPT-ийн нэвтрэх мэдээллийн талбарт оруулна.
4. Загвараа сонгоод шинэ сессээр богино хүсэлт туршина.

Үйлчилгээ үзүүлэгч бүрийн төгсгөлийн цэг, загварын ID болон аюулгүй хадгалалтын мэдээллийг [үйлчилгээ үзүүлэгчдийн заавраас](../providers)
харна уу.

## Ollama эсвэл LM Studio холбох

Дотоод загварын серверээ эхлүүлсний дараа OpenAI-compatible төгсгөлийн цэг эсвэл тухайн үйлчилгээ үзүүлэгчийн сонголтоор холбоно. Жишээ
төгсгөлийн цэгүүд:

```text
http://127.0.0.1:11434
http://127.0.0.1:1234/v1
```

`0.0.0.0` дээр нээлттэй, нууцлалгүй төгсгөлийн цэгийг нийтийн сүлжээнд бүү ажиллуул. Загвар харагдахгүй бол серверийн загвар
жагсаалтын төгсгөлийн цэг ажиллаж байгаа эсэх, firewall болон контекстийн хэмжээний тохиргоог шалгана. Дэлгэрэнгүйг
[Ollama](../providers#ollama) болон [LM Studio](../providers#lm-studio)-ийн хэсгээс харна уу.

## Төсөл ба зөвшөөрөл

- Нэг сессийг нэг төслийн root-той ажиллуулна.
- Git diff-ийг өөрчлөлт батлахаас өмнө хянана.
- Shell тушаал, файл устгах, сүлжээ ашиглах болон репозиторийн гадна бичих хүсэлтийг тусад нь зөвшөөрнө.
- MCP сервер, агентын ур чадвар эсвэл залгаас нэмэхдээ нийтлэгч, эх код, команд болон шаардах орчны хувьсагчийг шалгана.
- Танихгүй интеграцид API түлхүүрээ шууд дамжуулахгүй.

MCP болон өргөтгөлийн дэлгэрэнгүй: [MCP серверүүд](../mcp-servers), [агентын ур чадвар](../skills),
[залгаасууд](../plugins).

## Шинэчлэх

Шинэ хувилбарын мэдэгдэл гарвал хувилбарын дугаар, checksum болон өөрчлөлтийн бүртгэлийг шалгаад шинэчилнэ. Автоматаар шинэчлэх ажиллагаа ажиллахгүй
эсвэл суулгагчийн гарын үсэг өөрчлөгдвөл хуучин хувилбарыг устгалгүйгээр шинэ файлыг ажиллуулахгүй, эхлээд
[GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-тэй тулгана.

## Асуудал гарвал

Дараах мэдээллийг нууц түлхүүргүйгээр тэмдэглээд [алдаа оношлох зааврыг](../troubleshooting#ширээний-програм) ашиглана:

- MongolGPT хувилбар;
- Windows хувилбар ба архитектур;
- нээсэн төслийн төрөл;
- алдаа гарсан яг үйлдэл;
- Монгол алдааны бүтэн текст;
- бүртгэлийн нэвтрэх мэдээлэл агуулаагүй хэсэг.

Интерфэйс хоосон, дүрс эсвэл брэнд буруу, хэл дахин англи болдог, нэвтрэх буцах дуудлага тасардаг зэрэг асуудлыг хувилбарын асуудлын бүртгэлд
дахин гаргах алхамтай нь мэдээлнэ.

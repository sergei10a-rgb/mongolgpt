Админ орчин нь хэрэглэгчийн өдөр тутмын chat орчин биш. Зөвхөн эрх олгогдсон оператор нэвтэрч системийн төлөв, хэрэглэгч, billing болон audit мэдээллийг шалгана.

## Нэвтрэлт ба эрх

Admin domain нь Cloudflare Access болон MFA хамгаалалттай байх ёстой. Үүний дараа application-level RBAC нь admin subject, role, permission-ийг дахин шалгана. Нэг операторт шаардлагагүй өргөн эрх олгохгүй. Admin credential, Access token, session screenshot-ийг нийтэд бүү хуваалц.

## Одоогоор хийж болох зүйлс

Одоогийн хэрэгжилтэд эрхтэй admin хэрэглэгчид хэрэглэгчийн жагсаалт, хэрэглэгчийн төлөв, suspend/reactivate, billing/usage-ийн унших мэдээлэл, system health болон audit log-ийг шалгах боломжтой. Payment, subscription event, quota settlement болон provider-ийн төлөвийг audit trail-тай тулгаж үзнэ.

## Одоогийн хязгаарлалт

Дараахыг бүрэн ажилладаг admin mutation гэж бүү зарла:

- admin UI-гаас plan CRUD болон бүх төлөвлөгөөний лимитийг шууд өөрчлөх;
- subscription-ийг дур мэдэн шилжүүлэх эсвэл засах;
- QPay/Bonum refund-г админ товчоор гүйцэтгэх;
- provider health муудсан үед provider-ийг бүх орчноос шууд засах/унтраах;
- хэрэглэгч бүрийн revenue болон gross margin-ийг бүрэн operational dashboard-аар харах.

Эдгээр нь одоогоор унших, configuration эсвэл операторын хяналт шаардсан хэсэг байж болно. Хэрэгжээгүй үйлдлийг UI-д амжилттай болсон мэт харуулах ёсгүй.

## Төлбөр ба хэрэглээний хяналт

Төлбөрийн event-ийг invoice, amount, currency, provider reference болон idempotency бүртгэлтэй тулгана. Subscription идэвхжсэн эсэхийг зөвхөн баталгаатай webhook/queue үр дүнгээр шалгана. [Төлбөр, төлөвлөгөө ба хэрэглээ](./billing) болон [Cloudflare байршуулалт](./deployment)-ын sandbox/production ялгааг дагана.

## Audit ба incident ажиллагаа

Admin-ийн унших болон өөрчлөх үйлдэл audit log-д үлдэх ёстой. Suspicious login, credential leak, quota abuse, webhook зөрүү илэрвэл хэрэглэгчийг suspend хийх, provider key rotate/revoke хийх, event-ийг дахин давхар боловсруулахгүйгээр reconciliation хийх дарааллыг баримтална.

Системийн алдааг [алдаа оношлох](./troubleshooting), backup/restore асуудлыг [backup ба сэргээх](./backup-restore), deploy болон rollback-ийг [Cloudflare байршуулалт](./deployment) хуудаснаас үзнэ үү. Production төлбөр, database migration, credential өөрчлөлт нь тусдаа зөвшөөрөл болон preflight шаарддаг.

MongolGPT-ийн Вэб, ширээний програм болон CLI нь нэг бүртгэл, ажлын талбар, хэрэглээний эрхийг хуваалцах бүтэцтэй. Удирдлагатай загвар ашиглахад бүртгэлээр нэвтэрнэ. Өөрийн API түлхүүр болон локал загварын эрх нь үүнээс тусдаа байна.

:::caution[Одоогийн төлөв]
Нэгдсэн нэвтрэлт, Free Auto, хэрэглээний хязгаар, хэрэглээний бүртгэл болон QPay/Bonum төлбөрийн код хөгжүүлэлтийн орчинд туршигдаж байна. Үйлдвэрлэлийн үйлчилгээ, бодит төлбөр болон эцсийн үнэ албан ёсны хувилбарт идэвхжтэл бодит төлбөрийн мэдээлэл бүү оруул. `*.dev.mgpt.mn` хаяг нь туршилтын орчин бөгөөд үйлдвэрлэлийн үйлчилгээ биш.
:::

## Нэвтрэх

- **Вэб:** MongolGPT-ийн нэвтрэх дэлгэцээс Google эсвэл GitHub OAuth ашиглана.
- **Ширээний програм:** системийн хөтөч нээгдэж, зөвшөөрсний дараа MongolGPT програм руу буцна.
- **CLI:** хөтөч эсвэл төхөөрөмжийн кодоор нэвтэрнэ.

```bash
mongolgpt account login
```

Хөтөч автоматаар нээгдэх боломжгүй бол зөвшөөрлийн холбоосыг өөрөө нээхийн тулд:

```bash
mongolgpt account login --no-browser
```

CLI холбоосыг хэвлээд тухайн төхөөрөмжийн `127.0.0.1` буцах хаягт хариу хүлээнэ. Алсын SSH эсвэл контейнер орчинд ажиллуулж байгаа бол буцах хаягийн портыг аюулгүй дамжуулсан эсэхээ шалгана; буцах URL, зөвшөөрлийн код эсвэл нэвтрэх токеныг өөр хүнд илгээхгүй.

Нэвтэрсэн байгууллага, ажлын талбаруудаа шалгах:

```bash
mongolgpt account orgs
mongolgpt account switch
mongolgpt account open
```

CLI болон ширээний програм нь токеныг эх кодын тохиргоонд бичихгүй. Үйлдлийн системийн хамгаалалттай нууц мэдээллийн санд хадгалж, хугацаа дуусахад баталгаажсан нэвтрэлтийн үйлчилгээгээр шинэчилнэ.

## MongolGPT Free Auto

MongolGPT Free Auto нь бодлогоор зөвшөөрсөн боломжтой загварыг автоматаар сонгоно. Энэ горим:

- зөвхөн нэвтэрсэн MongolGPT бүртгэлд ажиллана;
- хүсэлт, токен, зардал болон зэрэгцээ ажиллагааны хязгаарыг мөрдөнө;
- үйлчилгээ үзүүлэгчийн эрүүл мэнд, хүсэлтийн давтамжийн хязгаар болон зардлын хамгаалалтаар чиглэлээ өөрчилж болно;
- туршилтын эсвэл хувь хүний үнэгүй API эрхийг нийтийн хэрэглэгчдэд дахин борлуулах серверийн суурь болгон ашиглахгүй;
- үүрд хязгааргүй, тогтмол нэг загвартай байна гэсэн амлалт биш.

Хязгаарт хүрвэл клиент дахин ашиглах хугацаа болон багцын хуудсыг Монгол хэлээр харуулна.

## Basic, Pro, Max

Basic, Pro, Max багцын хэрэглээний хязгаар, загвар ашиглах эрх, хүсэлтийн хязгаар болон зардлын хатуу хязгаарыг серверийн тохиргоогоор удирдана. Үнэ, татвар, буцаалт болон хүчинтэй нөхцөлийг код доторх хуучрах хүснэгтээр биш, нээлтийн үед бүртгэлийн самбар болон албан ёсны үйлчилгээний нөхцөлөөр харуулна.

Төлбөрийн урсгал QPay болон Bonum-д зориулагдсан. Төлбөр хүлээн авах эрх, вебхүүк болон тооцоо тулгалт үйлдвэрлэлийн орчинд идэвхжээгүй үед төлбөрийн товч ажиллаж байгаа мэт харагдах ёсгүй.

## Өөрийн үйлчилгээ үзүүлэгч

MongolGPT бүртгэлтэй байсан ч өөрийн загварыг сонгож болно:

- OpenRouter, OpenAI, Anthropic, Google болон бусад үйлчилгээ үзүүлэгчийн өөрийн API түлхүүр;
- өөрийн API түлхүүртэй NVIDIA NIM;
- OpenAI-тэй нийцтэй хувийн төгсгөлийн цэг;
- ширээний програм эсвэл CLI дээр Ollama, LM Studio зэрэг локал загвар.

```txt
/connect
/models
```

BYOK түлхүүрийг MongolGPT-ийн эх кодын удирдлага, бүртгэл эсвэл хэрэглээний шинжилгээнд бичихгүй. Локал загварын төгсгөлийн цэгийг Вэбээс ашиглахдаа хамгаалалттай ширээний програмын локал холбогч шаардлагатай; нийтийн Вэб програм хэрэглэгчийн `localhost` руу шууд хандахгүй.

## Үйлдвэрлэлийн орчинд бэлэн эсэхийг таних

Удирдлагатай үйлчилгээ үйлдвэрлэлийн орчинд нээгдсэн гэж дараах бүх нөхцөл зэрэг биелсэн үед үзнэ:

1. Албан ёсны хувилбарын тэмдэглэлд нээлтийн төлөв, үнэ, хэрэглээний хязгаар болон нөхцөл нийтлэгдсэн.
2. `mgpt.mn`, `app.mgpt.mn` болон нэвтрэлт/API-ийн хаягууд хүчинтэй TLS-тэй, төлөвийн шалгалт нь зөв JSON бүтэц буцааж байгаа.
3. Ширээний програм болон CLI-ийн үйлдвэрлэлийн сувгийн OAuth нэвтрэлт ажиллаж байгаа.
4. QPay/Bonum-ийн үйлдвэрлэлийн төлбөр хүлээн авах эрх идэвхжиж, туршилтын төлбөрийн тооцоо тулгалт баталгаажсан.

Эдгээрээс өмнө Free Auto болон төлбөртэй багцыг зөвхөн хөгжүүлэлт, туршилтын орчинд ашиглана.

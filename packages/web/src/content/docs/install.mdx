MongolGPT-ийн албан ёсны Desktop суулгагч, CLI архив болон checksum файлыг
[GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ээс татна. CLI-г мөн албан ёсны
[`mongolgpt` npm багцаар](https://www.npmjs.com/package/mongolgpt) суулгаж болно. Танихгүй домэйн, зар сурталчилгааны
татах товч эсвэл гуравдагч талын толин сайтаас файл бүү ажиллуул.

## Windows-ийн ширээний програм

1. [MongolGPT Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ийг нээнэ.
2. Хамгийн сүүлийн тогтвортой хувилбарыг сонгоно.
3. `mongolgpt-desktop-win-x64.exe` файл байвал татаж ажиллуулна.
4. Суулгагчийн харуулах бүтээгдэхүүний нэр болон publisher мэдээллийг шалгана.
5. Суулгасны дараа **MongolGPT**-ийг нээж төслийн хавтсаа сонгоно.

Анхны нээлт, нэвтрэлт, үйлчилгээ үзүүлэгч болон дотоод загварын тохиргоог [ширээний програмын заавраас](../desktop) үргэлжлүүлнэ.

:::caution[Windows SmartScreen]
Хувилбарын тайлбарт гарын үсэггүй хөгжүүлэлтийн бүтээлт гэж тодорхой тэмдэглэсэн үед Windows SmartScreen анхааруулж болно.
Файлын URL, хувилбар болон checksum тохирохгүй бол хамгаалалтыг алгасалгүй файлыг устгана.
:::

## CLI суулгах

### npm багцаар суулгах

Node.js 20 буюу түүнээс шинэ хувилбар суусан бол npm платформдоо тохирох MongolGPT ажиллуулах файлыг автоматаар сонгоно.

```bash
npm install --global mongolgpt
mongolgpt --version
```

`postinstall` скрипт ажиллаагүй гэсэн Монгол алдаа гарвал `--ignore-scripts` тохиргоо ашиглаагүй эсэхээ шалгаад дахин суулгана.

```bash
npm uninstall --global mongolgpt
npm install --global mongolgpt --ignore-scripts=false
```

Байгууллагын аюулгүй байдлын бодлого суулгалтын скриптийг хориглодог бол уг хамгаалалтыг дур мэдэн тойрохгүй. Доорх GitHub
Release архиваас тохирох файлаа татаж checksum-ийг тулгана.

### Release архиваар суулгах

Releases хуудаснаас үйлдлийн систем, процессортоо тохирох архивыг сонгоно.

| Орчин               | Файлын нэрийн эхлэл      |
| ------------------- | ------------------------ |
| Windows x64         | `mongolgpt-windows-x64`  |
| macOS Apple Silicon | `mongolgpt-darwin-arm64` |
| macOS Intel         | `mongolgpt-darwin-x64`   |
| Linux x64           | `mongolgpt-linux-x64`    |
| Linux ARM64         | `mongolgpt-linux-arm64`  |

Архивыг задалсны дараа хувилбарыг шалгана.

```bash
mongolgpt --version
```

Windows PowerShell дээр тухайн хавтсаас шууд ажиллуулах бол:

```powershell
.\mongolgpt.exe --version
```

macOS болон Linux дээр ажиллуулах эрх шаардлагатай бол:

```bash
chmod +x mongolgpt
./mongolgpt --version
```

Командыг дурын хавтсаас ашиглахын тулд executable файлыг хэрэглэгчийн `PATH`-д бүртгэлтэй хавтас руу байрлуулна.
CLI-ийн бүх команд, нэвтрэлт болон төслийн жишээг [CLI лавлагаанаас](../cli) харна уу.

## Checksum шалгах

Хувилбарт checksum файл нийтлэгдсэн бол татсан файлын SHA-256 утгыг заавал тулгана.

Windows PowerShell:

```powershell
Get-FileHash .\mongolgpt-desktop-win-x64.exe -Algorithm SHA256
```

macOS эсвэл Linux:

```bash
shasum -a 256 ./mongolgpt
```

Гарсан утга хувилбарын checksum-тэй тэмдэгт бүрээрээ таарах ёстой. Таарахгүй бол файлыг ажиллуулахгүй.

## Эх кодоос ажиллуулах

Энэ арга нь MongolGPT хөгжүүлэх эсвэл тухайн платформын бэлэн файл нийтлэгдээгүй үед зориулагдана. Эхлэхээсээ өмнө Bun болон Git-ийг суулгана уу.

```bash
git clone https://github.com/sergei10a-rgb/mongolgpt
cd mongolgpt
bun install
bun run dev
```

Windows-ийн ширээний програмыг хөгжүүлэлтийн горимоор нээх:

```bash
bun run dev:desktop
```

Суулгагч үүсгэх:

```powershell
$env:MONGOLGPT_CHANNEL="prod"
bun --cwd packages/desktop run package:win
```

Үүссэн файлууд `packages/desktop/dist/` хавтаст байрлана. Эх кодоос үүсгэсэн бүтээлт нь албан ёсны хувилбартай адил
гарын үсэг, update сувагтай гэж үзэж болохгүй.

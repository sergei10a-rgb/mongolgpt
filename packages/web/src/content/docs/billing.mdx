## Төлөвлөгөө ба хязгаар

MongolGPT нь Free, Basic, Pro, Max гэсэн төлөвлөгөөний ойлголттой. Токен, зардал, гулсах болон долоо хоногийн хэрэглээний хязгаарыг серверийн тохиргоо, захиалгын төлөвөөс хамаарч хүсэлт бүрийн өмнө шалгана. Хязгаарт хүрвэл систем хүсэлтийг аюулгүйгээр хааж зогсоох бөгөөд үйлчилгээ үзүүлэгч солих замаар төлбөрийн хязгаарыг тойрох ёсгүй.

Төлөвлөгөөний бүх хязгаарыг хэрэглэгч өөрөө админы интерфэйсээс дур мэдэн өөрчилдөг гэж бүү ойлгоорой. Одоогийн хэрэгжилтэд хязгаарын үндсэн утгууд байршуулалтын тохиргоотой холбоотой; админ дээр төлөвлөгөө үүсгэх, унших, шинэчлэх, устгах ажиллагаа болон захиалгын бүх өөрчлөлт бүрэн нээгдээгүй байж болно.

## Free Auto ба үйлчилгээ үзүүлэгчийн өртөг

Free Auto нь нэвтэрсэн хэрэглэгч, хүсэлт бүрийн хязгаар, долоо хоногийн токен болон хэрэглээний хязгаарын бүртгэл ашиглана. MongolGPT-ийн суулгалттай дагалддаг үнэгүй чиглэл үндсэн route хэвээр бөгөөд OpenRouter, NVIDIA NIM-ийг тохируулсан үед нэмэлт нөөц route болгон ашиглана. Үйлчилгээ үзүүлэгч рүү дахин оролдох эсвэл нөөц үйлчилгээ рүү шилжих ажиллагаа зөвхөн зөвшөөрсөн түр зуурын алдаанд хязгаарлагдана. Эдгээр чиглэлийг үйлдвэрлэлийн орчинд ашиглах эрх, хүсэлтийн давтамжийн хязгаар болон бэлэн байдлыг бодитоор шалгаж байж идэвхжүүлнэ. Интерфэйс дээр үйлчилгээ үзүүлэгч харагдаж байгаа нь дахин борлуулах эрх эсвэл үйлдвэрлэлийн зөвшөөрөл байна гэсэн үг биш.

BYOK ашиглавал хэрэглэгч өөрийн үйлчилгээ үзүүлэгчийн нэвтрэх мэдээллийг холбож болно. Түлхүүр хадгалалт, үйлчилгээ үзүүлэгчийн тохиргооны дэлгэрэнгүйг [үйлчилгээ үзүүлэгчдийн заавраас](../providers) үзнэ үү.

## QPay ба Bonum

QPay болон Bonum төлбөрийн урсгалд нэхэмжлэл үүсгэх, буцах дуудлага болон вебхүүкийн гарын үсэг, дүнг шалгах, нэхэмжлэл ба төлбөрийг холбох, давхар үйл явдлаас хамгаалах давтагдашгүй боловсруулалт, хугацаа дуусалт, тооцоо тулгалт хэрэгжинэ. Амжилттай төлбөр захиалга болон хэрэглээний эрхтэй холбогдоно.

### Туршилтын орчин

Эхний туршилтыг туршилтын төлбөр хүлээн авагчаар хийнэ. Туршилтын үйл явдлыг бодит мөнгөний төлбөр гэж тооцохгүй. Туршилтын буцах дуудлагыг үйлдвэрлэлийн төгсгөлийн цэг рүү илгээхгүй, туршилтын нэвтрэх мэдээллийг бодит нэвтрэх мэдээлэлтэй хольж болохгүй.

### Үйлдвэрлэлийн орчин

Бодит төлбөрийн үйлчилгээ үзүүлэгч нь үйлдвэрлэлийн төлбөр хүлээн авах эрх, нэвтрэх мэдээлэл, вебхүүкийн нууц, домэйн/TLS, тооцоо тулгалт болон хяналт бэлэн болсон үед л идэвхжинэ. Үйлдвэрлэлийн бодит төлбөрийг зөвшөөрөлгүйгээр идэвхжүүлэхгүй. [Cloudflare байршуулалт](../deployment)-ын урьдчилсан шалгалт болон төлбөрийн орчны тохиргоог заавал дагана.

### Төлбөр буцаах

`payments.refund` эрхтэй админ баталгаажсан QPay subscription төлбөрийг админы самбараас бүтнээр буцааж болно. Буцаах дүн, валют, үйлчилгээ үзүүлэгч болон төлбөрийн дугаарыг браузераас хүлээн авахгүй; сервер хадгалсан нэхэмжлэхээсээ өөрөө гаргана. Админ Монгол тайлбар оруулж, төлөвлөгөө болон үлдсэн хэрэглээний эрх цуцлагдахыг тусад нь баталгаажуулна. Хүсэлт, үр дүн, татгалзсан болон алдаатай оролдлого бүр аудитын мөртэй байна.

QPay-ийн албан ёсны Merchant V2 API нь картын гүйлгээний бүтэн буцаалтыг дэмждэг. Нэг буцаалтын мөнгө хөдөлгөх хүсэлтийг сүлжээний алдааны дараа автоматаар давтахгүй. Амжилтын HTTP хариуг дангаар нотолгоо болгохгүй бөгөөд `POST /v2/payment/check`-ийн `REFUNDED` төлөв, төлбөрийн дугаар, дүн, валютыг хадгалсан нэхэмжлэхтэй тулгаж байж дотоод буцаалтыг баталгаажуулна.

Үр дүн тодорхойгүй бол админы ижил мөрийн `QPay буцаалтыг шалгах` үйлдэл зөвхөн QPay-ийн төлвийг уншиж баталгаажуулна. QPay буцаалт аль хэдийн батлагдсан ч дотоод дараалал тасарсан бол `Буцаалтын төлөв сэргээх` үйлдэл баталгаажсан үйл явдлыг дахин queue-д оруулна. Аль аль нь QPay руу хоёр дахь мөнгө буцаах хүсэлт илгээхгүй.

Bonum web нэхэмжлэхийн settled төлбөрийг буцаах нийтийн мерчант API албан ёсоор баталгаажаагүй тул MongolGPT автоматаар мөнгө хөдөлгөхгүй. Ийм тохиолдлыг Bonum мерчантын дэмжлэг болон аудитын мөртэй операторын журмаар шийднэ. QPay-ийн дэлгэрэнгүйг [Merchant V2 баримт](https://developer.qpay.mn/docs/merchant?version=2.0.0), Bonum-ийн нийтэд нээлттэй боломжийг [Gateway APIs баримт](https://psp.bonum.mn/bonum-gateway-apis.html)-аас шалгаж болно.

Админы самбараас төлөвлөгөө дур мэдэн өөрчлөх болон захиалгын амьдралын мөчлөгийн бүх өөрчлөлт бүрэн хэрэгжсэн гэж бүү үз. Төлбөрийн маргаан, тооцоо тулгалтын зөрүүг аудитын мөртэй операторын журмаар шийднэ.

## Хэрэглээгээ шалгах

Хэрэглээ нь үйлчилгээ үзүүлэгч, загвар, токен, зардал болон сессийн мета өгөгдөлтэй бүртгэгдэнэ. Хэрэглэгчийн харах дэлгэцийн боломж нь тухайн серверт байршуулсан орчноос хамаарна. Хязгаар гэнэт дуусвал төлөвлөгөө, үйлчилгээ үзүүлэгчийн түлхүүр, хэрэглээний хязгаар шинэчлэгдэх хугацаа болон [алдаа оношлох зааврыг](../troubleshooting) шалгана уу.

## Аюулгүй байдлын анхааруулга

QPay/Bonum-ийн буцах дуудлагыг зөвхөн үйлчилгээ үзүүлэгчийн баталгаатай гарын үсэг, нэхэмжлэл, дүн, валют, лавлах дугаартай тулгаж хүлээн авна. Дэлгэцийн зураг эсвэл хэрэглэгчийн “төлсөн” гэсэн мэдэгдлийг захиалга идэвхжүүлэх нотолгоо гэж бүү ашигла. Төлбөрийн нэвтрэх мэдээлэл, вебхүүкийн нууц, API түлхүүрийг бүртгэл болон асуудлын хүсэлтэд бүү нийтэл.

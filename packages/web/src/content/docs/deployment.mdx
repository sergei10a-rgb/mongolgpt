MongolGPT-ийн веб бүтээгдэхүүний байршуулалтын үндсэн платформ нь **Cloudflare**. Vercel болон Supabase нь нээлтийн архитектурын сонголт биш.

OpenRouter, NVIDIA NIM, Bonum болон QPay нь хиймэл оюуны загвар, төлбөрийн гадаад API болохоос MongolGPT-ийг байршуулах платформ биш.

:::caution
Байршуулсан орчны үндсэн өгөгдөл D1-д, хэрэглээний хязгаар болон хүсэлтийн давтамжийн хязгаар нь SQLite-д тулгуурласан Durable Objects-д, өндөр ачааллын хэрэглээний бичилт нь Queues-д хадгалагдана. Үйлдвэрлэлийн байршуулалт нээлттэй боловч OAuth, загварын үйлчилгээ үзүүлэгч болон домэйны бодит нууц утгыг тохируулж, `deploy:preflight` болон суурь ажиллагааны шалгалтыг заавал давуулна.
:::

## Үйлчилгээний хаягууд

Үйлдвэрлэлийн домэйныг `mgpt.mn` гэж үзвэл:

| Үйлчилгээ                      | Хаяг                        |
| ------------------------------ | --------------------------- |
| Бүртгэл ба удирдлагын самбар   | `https://mgpt.mn`           |
| Вэб апп                        | `https://app.mgpt.mn`       |
| Монгол баримт бичиг            | `https://docs.mgpt.mn/docs` |
| OAuth үйлчилгээ                | `https://auth.mgpt.mn`      |
| QPay + Bonum төлбөр            | `https://pay.mgpt.mn`       |
| Админ удирдлага                | `https://admin.mgpt.mn`     |
| Синхрончлолын API (сонголттой) | `https://api.mgpt.mn`       |

`dev` орчинд үйлчилгээний дэд домэйн ба үндсэн домэйны хооронд `dev` нэмэгдэнэ. Жишээ нь `https://app.dev.mgpt.mn`.

`api.<domain>` нь үндсэн нээлтийн үйлчилгээ биш. Зөвхөн `MONGOLGPT_ENABLE_SYNC_SERVICE=true` үед нэмэлт синхрончлолын үйлчилгээтэй хамт байршуулна.

## Cloudflare бүтэц

| Хэсэг                                      | Cloudflare үйлчилгээ                        |
| ------------------------------------------ | ------------------------------------------- |
| Баримт бичиг                               | Astro Worker                                |
| Вэб апп                                    | Static Assets / Worker                      |
| Бүртгэлийн самбар ба Free Auto гарц        | SolidStart Worker                           |
| OAuth                                      | Worker + KV                                 |
| OAuth bot хамгаалалт                       | Cloudflare Turnstile + серверийн Siteverify |
| QPay + Bonum төлбөрийн гарц                | Worker + Queue + D1                         |
| Админ хамгаалалт                           | Cloudflare Access + MFA                     |
| Үндсэн өгөгдөл                             | D1                                          |
| Өдөр тутмын нөөц                           | D1 экспортын Workflow + нийтэд нээлтгүй R2  |
| Токены хэрэглээний хязгаар, атомик тоолуур | SQLite-д тулгуурласан Durable Objects       |
| Хэрэглээний өндөр ачааллын бичилт          | Queues + алдааны тусгай Queue + D1          |
| Бодит цагийн статистик                     | Cloudflare D1 + `stats.<domain>`            |
| Мэдээллийн захидлын бүртгэл                | Cloudflare D1                               |

## Байршуулахын өмнөх шалгалт

Нийтийн веб аппыг зөвхөн байршуулсан ажиллах орчин, бүртгэл болон баталгаажуулалтын үйлчилгээтэй хамт байршуулна. Репозиторийн үндсэн хавтаснаас локал урьдчилсан шалгалт ажиллуулах бол доорх нийтлэг утгаас гадна энэ хуудсын GitHub тохиргооны хүснэгтэд байгаа хөгжүүлэлтийн нэвтрэх мэдээллийг ижил нэртэй орчны хувьсагчаар аюулгүй оруулсан байна.

```powershell
$env:MONGOLGPT_DOMAIN="mgpt.mn"
$env:CLOUDFLARE_DEFAULT_ACCOUNT_ID="<account-id>"
$env:CLOUDFLARE_API_TOKEN="<api-token>"
$env:MONGOLGPT_ENABLE_HOSTED_SERVICES="true"
$env:MONGOLGPT_ENABLE_ADMIN="false"
$env:MONGOLGPT_PAYMENT_ENVIRONMENT="disabled"
bun run deploy:preflight -- dev
```

`MONGOLGPT_ENABLE_HOSTED_SERVICES=false` гэж бүтээсэн хувилбарыг `app.dev.mgpt.mn` дээр SaaS апп гэж нийтлэхгүй. Тэр хувилбар нь Desktop болон дотоод холбогчийн хөгжүүлэлтэд зориулагдсан бөгөөд бүртгэл, баталгаажуулалт, Free Auto API-гүй. Хөгжүүлэлтийн туршилтын орчныг GitHub-ийн **Cloudflare deploy** ажлын урсгалаар байршуулна.

Үйлдвэрлэлийн орчинд байршуулж эхлэхийн өмнө нэмэлт баталгаажуулалт заавал өгнө:

```powershell
$env:MONGOLGPT_PRODUCTION_CONFIRMATION="DEPLOY mgpt.mn"
bun run deploy:preflight -- production
```

## GitHub тохиргоо

Cloudflare-ийн удирдлагын самбар хэвийн болмогц GitHub репозиторийн **Тохиргоо (`Settings`)** → **Нууц утга ба хувьсагч (`Secrets and variables`)** → **Ажлын урсгал (`Actions`)** хэсэгт дараахыг тохируулна.

Репозиторийн түвшинд Cloudflare-ийн нийтлэг тохиргоог хадгална.

| Төрөл     | Нэр                             | Утга                                       |
| --------- | ------------------------------- | ------------------------------------------ |
| Хувьсагч  | `MONGOLGPT_DOMAIN`              | `mgpt.mn`                                  |
| Хувьсагч  | `CLOUDFLARE_DEFAULT_ACCOUNT_ID` | Cloudflare аккаунтын ID                    |
| Нууц утга | `CLOUDFLARE_API_TOKEN`          | Хамгийн бага шаардлагатай эрхтэй API токен |

### Cloudflare байршуулалтын токен

Cloudflare-ийн **Миний бүртгэл (`My Profile`) → API токен (`API Tokens`) → Токен үүсгэх (`Create Token`)** хэсэгт **Cloudflare Worker засах (`Edit Cloudflare Workers`)** загварыг сонгоно. Энэ загварын Worker script, KV хадгалалт, R2 хадгалалт, Worker route болон унших суурь эрхүүдийг хэвээр үлдээгээд дараах дөрвөн эрхийг нэмнэ.

| Хамрах хүрээ        | Үйлчилгээ    | Эрх            |
| ------------------- | ------------ | -------------- |
| Аккаунт (`Account`) | `D1`         | Засах (`Edit`) |
| Аккаунт (`Account`) | `Queues`     | Засах (`Edit`) |
| Аккаунт (`Account`) | `Containers` | Засах (`Edit`) |
| Бүс (`Zone`)        | `DNS`        | Засах (`Edit`) |

Аккаунтын нөөцөд MongolGPT байрлах ганц аккаунтыг, бүсийн нөөцөд зөвхөн `mgpt.mn`-ийг сонгоно. Токеныг `MongolGPT deploy` гэх мэт зориулалт нь ойлгомжтой нэрээр үүсгэж, утгыг репозиторийн `CLOUDFLARE_API_TOKEN` нууц утгад хадгална. IP шүүлтүүр тавих бол GitHub-hosted runner-ийн өөрчлөгддөг хаягийг зөвшөөрөх боломжгүй тул байршуулалт хаагдахыг тооцно.

Энэ нь Cloudflare Access болон D1 нөөцлөлтийн токен биш. Админы Access-д `CLOUDFLARE_ACCESS_API_TOKEN`, үйлдвэрлэлийн D1 экспортод `D1_BACKUP_API_TOKEN` гэсэн тусдаа хамгийн бага эрхтэй токен хэрэглэнэ. Эрхийн нэр өөрчлөгдсөн эсэхийг [Cloudflare-ийн токены эрхийн жагсаалт](https://developers.cloudflare.com/fundamentals/api/reference/permissions/), SST-ийн суурь шаардлагыг [SST Cloudflare credentials](https://sst.dev/docs/cloudflare/#credentials)-аас тулгаж шалгана.

`dev` болон `production` GitHub орчин тус бүрд өөрийн OAuth, сесс болон загварын нэвтрэх мэдээллийг хадгална.

| Төрөл     | Нэр                                                      | Утга                                                                                                  |
| --------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Хувьсагч  | `MONGOLGPT_AUTH_EMAIL_DOMAINS`                           | Хөгжүүлэлтийн орчинд зөвшөөрөх яг тохирох имэйл эсвэл домэйн; таслалаар тусгаарлана                   |
| Хувьсагч  | `GITHUB_CLIENT_ID_CONSOLE`                               | Тухайн орчны GitHub OAuth аппын клиент ID                                                             |
| Хувьсагч  | `GOOGLE_CLIENT_ID`                                       | Тухайн орчны Google Web OAuth клиент ID                                                               |
| Хувьсагч  | `MONGOLGPT_TURNSTILE_SITE_KEY`                           | Тухайн орчны Cloudflare Turnstile widget-ийн нийтэд нээлттэй site key                                 |
| Хувьсагч  | `MONGOLGPT_PAYMENT_PLAN_CATALOG`                         | Basic/Pro/Max багцын MNT үнэ, Монгол нэр бүхий JSON                                                   |
| Нууц утга | `GITHUB_CLIENT_SECRET_CONSOLE`                           | GitHub OAuth аппын нууц түлхүүр                                                                       |
| Нууц утга | `TURNSTILE_SECRET_KEY`                                   | Тухайн Turnstile widget-ийн сервер талд ашиглах нууц түлхүүр                                          |
| Нууц утга | `BYOK_CREDENTIALS_KEY_V1`                                | 32+ тэмдэгт тогтвортой CSPRNG түлхүүр; шинэчлэх хүртэл солихгүй                                       |
| Нууц утга | `D1_BACKUP_API_TOKEN`                                    | Үйлдвэрлэлийн орчинд заавал; зөвхөн тухайн аккаунтын D1 засах эрхтэй нөөцлөлт, экспортын токен        |
| Нууц утга | `MONGOLGPT_RUNTIME_SECRET`                               | 32+ тэмдэгт Cloudflare Sandbox-ийн аккаунт тусгаарлах нууц утга                                       |
| Нууц утга | `MONGOLGPT_RUNTIME_AUTH_SECRET`                          | 32+ тэмдэгт ажиллах орчны эрхийн баримтад гарын үсэг зурж шалгах нууц утга                            |
| Нууц утга | `MONGOLGPT_PLAN_LIMITS`                                  | Free/Basic/Pro/Max багц, токен, өртөг болон хүсэлтийн давтамжийн хязгаарын JSON                       |
| Нууц утга | `MONGOLGPT_GATEWAY_SESSION_SECRET`                       | 32+ тэмдэгт тусдаа CSPRNG сессийн нууц утга                                                           |
| Нууц утга | `MONGOLGPT_SMOKE_AUTH_COOKIE`                            | Тусгай Free хэрэглэгчийн `__Host-mongolgpt-auth=<утга>` OAuth сесс; зөвхөн deploy smoke-д ашиглана    |
| Нууц утга | `MONGOLGPT_GATEWAY_MODELS1`                              | Баталгаажсан Free Auto загвар ба үйлчилгээ үзүүлэгчийн JSON; үйлчилгээ үзүүлэгчийн түлхүүрийг агуулна |
| Нууц утга | `MONGOLGPT_GATEWAY_MODELS2`…`MONGOLGPT_GATEWAY_MODELS30` | `MONGOLGPT_GATEWAY_MODELS1`-д багтахгүй үед ашиглах JSON-ийн дараалсан сонголттой хэсгүүд             |

Шилжилтийн хугацаанд хуучин `ZEN_SESSION_SECRET`, `ZEN_MODELS1`…`ZEN_MODELS30` утгуудыг зөвхөн fallback-аар уншина. Шинэ нэр рүү ижил утгыг хуулж баталгаажуулах хүртэл session secret-ийг сольж болохгүй; шинэ тохиргоонд зөвхөн `MONGOLGPT_GATEWAY_*` нэр ашиглана.

`MONGOLGPT_SMOKE_AUTH_COOKIE`-г нэргүй эсвэл хиймэл нэвтрэлтийн замаар үүсгэхгүй. Тухайн орчны allowlist-д орсон, төлбөртэй багцгүй тусгай хэрэглэгчээр хэвийн GitHub эсвэл Google OAuth нэвтрэлт хийсний дараа browser developer tools-ийн **Application → Cookies** хэсгээс `__Host-mongolgpt-auth`-ийн утгыг авч, `__Host-mongolgpt-auth=<утга>` хэлбэрээр тухайн GitHub environment-ийн secret-д хадгална. `Path`, `Secure`, `HttpOnly`, `SameSite` зэрэг атрибут болон `Cookie:` толгойг хамт хуулж болохгүй. Нууц утгыг SST, Worker, browser E2E эсвэл artifact-д дамжуулахгүй; зөвхөн байршуулалтын өмнөх бүтцийн шалгалт болон байршуулалтын дараах authenticated smoke алхам уншина. Сесс хүчингүй болсон үед тусгай хэрэглэгчээр дахин OAuth нэвтэрч энэ secret-ийг шинэчилнэ.

`MONGOLGPT_PLAN_LIMITS` нь paid багц бүрд 7 хамгаалалтыг заавал тодорхойлно: 7 хоногийн өртөг, токен,
хүсэлт; сарын өртөг, токен, хүсэлт; мөн гулсах хугацааны өртөг. Өртгийн утга нь загвар нийлүүлэгчийн

### OAuth апп бүртгэх

Хөгжүүлэлт ба үйлдвэрлэлийн орчин тусдаа нэвтрэх мэдээлэл ашиглана. Ингэснээр туршилтын буцах дуудлага, зөвшөөрөгдсөн хэрэглэгч болон нууц түлхүүр үйлдвэрлэлийн нэвтрэлттэй холилдохгүй.

GitHub-ийн [OAuth App үүсгэх албан ёсны заавраар](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/creating-an-oauth-app)
**Settings → Developer settings → OAuth Apps → New OAuth App** хэсэгт хөгжүүлэлтийн апп үүсгэнэ.

| GitHub талбар                                        | Хөгжүүлэлтийн утга                         |
| ---------------------------------------------------- | ------------------------------------------ |
| Аппликэйшний нэр (`Application name`)                | `MongolGPT Dev`                            |
| Нүүр хуудасны URL (`Homepage URL`)                   | `https://app.dev.mgpt.mn`                  |
| Зөвшөөрлийн буцах URL (`Authorization callback URL`) | `https://auth.dev.mgpt.mn/github/callback` |

Үүссэн **Client ID**-г хөгжүүлэлтийн орчны `GITHUB_CLIENT_ID_CONSOLE` хувьсагчид, **Client secret**-ийг `GITHUB_CLIENT_SECRET_CONSOLE` нууц утгад хадгална. GitHub OAuth апп нэг буцах URL-тэй тул үйлдвэрлэлийн орчинд тусдаа `MongolGPT` апп үүсгэж `https://auth.mgpt.mn/github/callback` хаягийг ашиглана.

Google Cloud Console-ийн **APIs & Services → OAuth consent screen** хэсэгт зөвшөөрлийн дэлгэц болон хөгжүүлэлтийн туршилтын хэрэглэгчээ тохируулаад **Credentials → Create credentials → OAuth client ID → Web application** сонгоно. Google-ийн [веб серверийн OAuth зааврын](https://developers.google.com/identity/protocols/oauth2/web-server) дагуу буцах URI-ийн протокол, хост, зам болон төгсгөлийн ташуу зураас хүртэл яг таарах ёстой.

| Google талбар                                       | Хөгжүүлэлтийн утга                         |
| --------------------------------------------------- | ------------------------------------------ |
| Нэр (`Name`)                                        | `MongolGPT Dev`                            |
| Зөвшөөрөгдсөн буцах URI (`Authorized redirect URI`) | `https://auth.dev.mgpt.mn/google/callback` |

Үүссэн **Client ID**-г хөгжүүлэлтийн орчны `GOOGLE_CLIENT_ID` хувьсагчид хадгална. Одоогийн OpenID `form_post` урсгал клиент нууц утга ашигладаггүй тул Google-ийн клиент нууц утгыг репозитор эсвэл GitHub-д нэмэхгүй. Үйлдвэрлэлийн клиентэд `https://auth.mgpt.mn/google/callback` буцах URI-г ашиглана.

### Turnstile хамгаалалт бүртгэх

Cloudflare Dashboard-ийн **Turnstile → Add widget** хэсэгт үйлдвэрлэлийн widget үүсгэж, hostname-д зөвхөн `mgpt.mn`-ийг зөвшөөрнө. OAuth эхлэх `https://mgpt.mn/auth/authorize` хуудас site key-г browser-т ашиглана. Widget-ээс гарсан нэг удаагийн богино настай токен болон тогтсон OAuth хүсэлтийг form-ийн `POST` хүсэлтээр Auth Worker руу шууд илгээнэ. Auth Worker Cloudflare Siteverify-ээр токеныг шалгаад `action`, hostname, client, callback болон state бүгд зөв үед л OpenAuth урсгалыг эхлүүлнэ. Токен URL, browser history эсвэл access log-д орохгүй. `auth.<domain>/authorize` хаягт шууд `GET` хийх эсвэл токенгүй `POST` илгээвэл `403` хариу өгч хаана.

Үүссэн **Site key**-г үйлдвэрлэлийн GitHub орчны `MONGOLGPT_TURNSTILE_SITE_KEY` хувьсагчид, **Secret key**-г `TURNSTILE_SECRET_KEY` нууц утгад хадгална. Secret key-г source, browser bundle, лог эсвэл командын аргументад бичихгүй. `dev` байршуулалт болон автомат тест Cloudflare-ийн албан ёсны always-pass test key-г автоматаар ашиглана; production урьдчилсан шалгалт test key-г зориуд хориглож, бодит widget-ийн хоёр key дутуу бол байршуулалтыг зогсооно.

Web, Desktop болон CLI-ийн анхны нэвтрэлт бүгд browser OAuth ашигладаг тул энэ хамгаалалт гурван клиентэд ижил үйлчилнэ. Turnstile идэвхтэй орчинд шинэ OAuth урсгал бүр ижил хамгаалалтаар шалгагдана.

QPay + Bonum-ийн туршилтын төлбөрийг идэвхжүүлэх орчинд худалдааны байгууллагын дараах нууц утгуудыг нэмнэ.

| Төрөл     | Нэр                          | Утга                                          |
| --------- | ---------------------------- | --------------------------------------------- |
| Нууц утга | `QPAY_MERCHANT_ACCOUNT_ID`   | QPay туршилтын орчны худалдааны аккаунтын ID  |
| Нууц утга | `QPAY_CLIENT_ID`             | QPay туршилтын орчны клиентийн ID             |
| Нууц утга | `QPAY_CLIENT_SECRET`         | QPay туршилтын орчны клиентийн нууц түлхүүр   |
| Нууц утга | `QPAY_INVOICE_CODE`          | QPay туршилтын орчны нэхэмжлэхийн код         |
| Нууц утга | `BONUM_MERCHANT_ACCOUNT_ID`  | Bonum туршилтын орчны худалдааны аккаунтын ID |
| Нууц утга | `BONUM_APP_SECRET`           | Bonum туршилтын орчны аппын нууц түлхүүр      |
| Нууц утга | `BONUM_TERMINAL_ID`          | Bonum туршилтын орчны терминалын ID           |
| Нууц утга | `BONUM_WEBHOOK_CHECKSUM_KEY` | Bonum webhook гарын үсэг шалгах нууц түлхүүр  |

`MONGOLGPT_PAYMENT_PLAN_CATALOG` жишээ:

```json
{
  "basic": { "label": "Basic", "amount": 29900 },
  "pro": { "label": "Pro", "amount": 79900 },
  "max": { "label": "Max", "amount": 199900 }

```

Үнэ нь бүхэл MNT дүн байна. Энэ жишээг шууд үйлдвэрлэлийн үнэ гэж үзэхгүй; өртөг, хэрэглээний хязгаар болон нийт ашгийн хувийг судалгаагаар баталгаажуулсны дараа тохируулна.

### Төлбөрийн sandbox smoke шалгалт

QPay болон Bonum-ийн туршилтын худалдааны эрхийг авсны дараа нууц утгуудыг зөвхөн тухайн shell-ийн орчны хувьсагчид ачаална. Репозиторийн файл, командын аргумент эсвэл screenshot-д утгыг нь оруулахгүй. Дараа нь:

```powershell
$env:MONGOLGPT_PAYMENT_SANDBOX_ENVIRONMENT="sandbox"
$env:MONGOLGPT_PAYMENT_SANDBOX_PROVIDER="all"
$env:MONGOLGPT_PAYMENT_SANDBOX_CALLBACK_BASE_URL="https://pay.dev.mgpt.mn"
$env:MONGOLGPT_PAYMENT_SANDBOX_SMOKE_CONFIRM="RUN_SANDBOX_SMOKE"
bun --cwd packages/console/core run payment-sandbox-smoke
```

Шалгалт зөвхөн sandbox төгсгөлийн цэг ашиглаж 1 MNT дүнтэй нэхэмжлэх үүсгэнэ. QPay нэхэмжлэхийн `pending` төлвийг баталгаажуулаад амжилт, алдааны аль ч үед цуцална. Одоогийн Bonum gateway cancellation API өгөөгүй тул Bonum checkout-ийг төлөхгүй орхиж, таван минутын богино хугацаагаар автоматаар дуусгана. `production` орчин, production callback host эсвэл confirmation дутуу үед command сүлжээний үйлдэл хийхээс өмнө хаалттай зогсоно.

Админ орчныг идэвхжүүлэх байршуулалтын орчинд дараах хоёр нууц утгыг нэмнэ.

| Төрөл     | Нэр                                | Утга                                                    |
| --------- | ---------------------------------- | ------------------------------------------------------- |
| Нууц утга | `CLOUDFLARE_ACCESS_API_TOKEN`      | Зөвхөн Access апп үүсгэх тусгай Cloudflare API токен    |
| Нууц утга | `MONGOLGPT_ADMIN_BOOTSTRAP_EMAILS` | Админы зөвшөөрөгдсөн имэйлүүд; таслал эсвэл шинэ мөрөөр |

`CLOUDFLARE_ACCESS_API_TOKEN`-ийг Cloudflare-ийн **My Profile → API Tokens → Create Custom Token** хэсэгт дараах хамгийн бага эрхээр үүсгэнэ.

| Хамрах хүрээ        | Үйлчилгээ                                                 | Эрх            |
| ------------------- | --------------------------------------------------------- | -------------- |
| Аккаунт (`Account`) | `Access: Apps and Policies`                               | Засах (`Edit`) |
| Аккаунт (`Account`) | `Access: Organizations, Identity Providers, and Groups`   | Засах (`Edit`) |
| Нөөц (`Resources`)  | `Include` → MongolGPT байрлаж буй ганц Cloudflare аккаунт |                |

Бүсийн зөвшөөрөл, DNS ба Worker засах эрх, D1, R2 болон KV-ийн эрх энэ тусгай токенд хэрэггүй. Ерөнхий `CLOUDFLARE_API_TOKEN`-оос тусад нь хадгална. Access токеныг SST тохиргоо ажиллах үед л ашиглах бөгөөд админ Worker-т нөөц, орчны хувьсагч эсвэл нууц утга хэлбэрээр холбохгүй.

Cloudflare Zero Trust-ийг тухайн аккаунт дээр нэг удаа эхлүүлж, багийн домэйн болон дор хаяж нэг нэвтрэх арга эсвэл таних үйлчилгээ үзүүлэгчийг идэвхжүүлсэн байна. Үүний дараа кодоор удирдах дэд бүтэц (IaC) нь:

- байгууллагын одоогийн бүх тохиргоог GET хүсэлтээр авч хадгалан, Independent MFA-д TOTP, биометр болон аюулгүй байдлын түлхүүрийн аргыг давтан илгээхэд ижил үр дүнтэй PUT хүсэлтээр нэмнэ;
- нийтлэг MFA-г бусад аппад хүчээр шаардахгүй бөгөөд дэд бүтцийн багц устахад байгууллагын MFA-г автоматаар сулруулахгүй;
- `admin.<stage-domain>` өөрийн серверт байрлах Access апп үүсгэнэ;
- зөвхөн `MONGOLGPT_ADMIN_BOOTSTRAP_EMAILS`-ийн имэйлүүдийг allow хийнэ;
- апп болон бодлогын түвшинд Independent MFA шаардана;
- Access-ийн хүлээн авагч болон багийн домэйныг Cloudflare-аас автоматаар авч Worker-т холбоно;
- HttpOnly, SameSite Strict болон сессийг холбосон cookie хамгаалалтыг асаана.

`MONGOLGPT_ADMIN_ACCESS_TEAM_DOMAIN`, `MONGOLGPT_ADMIN_ACCESS_AUDIENCE`, `MONGOLGPT_ADMIN_MFA_ENFORCED` гэсэн гар тохиргоо ашиглахгүй. `everyone` болон `bypass` утгатай бодлого үүсгэхгүй.

Ажлын урсгал нууц утга шаарддаггүй баталгаажуулах ажлыг эхэлж ажиллуулаад, зөвхөн `main` хувилбар болон сонгосон GitHub орчинд байршуулалтын ажлыг нээнэ. Access токеныг зөвхөн админ идэвхтэй байршуулалтад, худалдааны байгууллагын нэвтрэх мэдээллийг зөвхөн төлбөр идэвхтэй байршуулалтын SST нууц утгын шинэчлэлд ашиглана. Байршуулах алхам эдгээр утгыг командын аргументад гаргалгүй, стандарт оролтоор тухайн SST орчны шифрлэгдсэн нууц утгын санд шинэчилсний дараа байршуулна. GitHub орчны байршуулалтын салбарын дүрмийг `main`-ээр хязгаарлана. Иймээс нууц утгыг репозиторийн файл, командын түүх эсвэл SST-ийн орлуулах утгад бичихгүй. `deploy:preflight` нь OAuth, сесс, багц ба хэрэглээний хязгаар, Free Auto JSON, QPay/Bonum каталог ба нэвтрэх мэдээлэл, Access-ийн байгууллага, нэвтрэх арга, аппын жагсаалтыг Cloudflare-ийн нөөц үүсгэхээс өмнө шалгана. Энэ нь өөрчлөлт хийдэггүй унших шалгалт тул токены засах эрхийг дангаар нотлохгүй. Байгууллагын MFA-г PUT хүсэлтээр шинэчлэх болон Access апп үүсгэх алхам нь байршуулалтын үед засах эрхийг бодитоор шалгаж, эрх дутуу бол ажиллагааг зогсооно.

NVIDIA API Catalog-ийн туршилтын төгсгөлийн цэг зөвхөн туршилт, үнэлгээнд зориулагдсан. Үйлдвэрлэлийн `MONGOLGPT_GATEWAY_MODELS` тохиргоонд `integrate.api.nvidia.com` ашиглах бол үйлдвэрлэлийн зориулалтын захиалга, лицензээ тусад нь баталгаажуулсны дараа тухайн үйлчилгээ үзүүлэгч дээр `productionUseApproved: true` гэж санаатай тэмдэглэнэ. Энэ баталгаа байхгүй үйлдвэрлэлийн байршуулалтыг урьдчилсан шалгалт зогсооно.

`D1_BACKUP_API_TOKEN`-ийг ерөнхий байршуулалтын токеноос тусад нь үүсгэнэ: **Account → D1 → Edit**. Нөөцийн хэсэгт зөвхөн MongolGPT байрлаж буй ганц аккаунтыг сонгоно. Бүс, DNS, Worker, R2 болон Access эрх нэмэхгүй. Токеныг GitHub-ийн `production` орчны нууц утгад хадгална. Байршуулах ажлын урсгал хөгжүүлэлтийн орчинд `MONGOLGPT_ENABLE_D1_BACKUPS=false`, үйлдвэрлэлийн орчинд `true` гэж автоматаар өгнө. Иймээс эхний хөгжүүлэлтийн туршилтад үйлдвэрлэлийн экспортын токен шаардахгүй; хөгжүүлэлтийн орчинд нөөцлөлтийг зориуд турших үед л тохиргоо болон тусдаа хөгжүүлэлтийн токеныг хамт асаана. Үйлдвэрлэлийн үйлчилгээ байршуулалт нь нөөцлөлтийн тохиргоо эсвэл токен дутуу бол алдаанд хаалттай зогсоно. Нөөцлөлт, хадгалалтын хугацаа, сэргээх ажиллагааг [Нөөцлөлт ба сэргээх](../backup-restore) гарын авлагаас харна уу.

`MONGOLGPT_RUNTIME_SECRET` болон `MONGOLGPT_RUNTIME_AUTH_SECRET` нь криптографын аюулгүй санамсаргүй үүсгүүрээр бий болгосон, хоорондоо ялгаатай хоёр тогтвортой нууц утга байна.
Эхнийх нь аккаунт бүрийн үүлэн тусгаарлагдсан орчны таних тэмдгийг салгана. Хоёр дахь нь удирдлагын үйлчилгээнээс олгосон ажиллах орчны богино настай эрхийн баримтад гарын үсэг зурж, Worker дээр шалгана. Аль нэгийг байршуулалт бүрд санамсаргүй сольж болохгүй. Соливол идэвхтэй сесс хүчингүй болох эсвэл өмнөх тусгаарлагдсан орчны таних тэмдгээс тасрах эрсдэлтэй. Ажлын урсгал `MONGOLGPT_RUNTIME_AUTH_SECRET`-ийг ажиллах орчны Worker болон SST-ийн `MongolGPTRuntimeAuthSecret` нөөцөд ижил утгаар холбож, урьдчилсан шалгалтаар хоёр тал зөрвөл байршуулалтыг зогсооно.

Хэрэглээний хязгаарын үйлчилгээний дотоод токеныг SST байршуулалтын үед автоматаар үүсгэнэ. Upstash болон PlanetScale-ийн нууц утга шаардлагагүй.

`Cloudflare deploy` ажлын урсгал нь урьдчилсан шалгалт, төрлийн шалгалт, баримт бичиг ба вэбийн бүтээлт, authenticated smoke identity шалгалт, SST байршуулалт, D1 өгөгдлийн шилжилт, нийтэд нээлттэй болон нэвтэрсэн ажиллагааны smoke шалгалт гэсэн дарааллаар ажиллана. Нэвтэрсэн шалгалт нь Free төлөвлөгөөтэй account ба workspace, богино наст runtime capability, host-only runtime cookie, project API болон `MongolGPT Free Auto` provider/model-ийг бодитоор батална. `payment_environment`-ийг эхлээд `disabled`, туршилтын худалдааны эрх бэлэн болсны дараа `sandbox` гэж сонгоно. Үйлдвэрлэлийн үед `DEPLOY <domain>` гэсэн байршуулалтын баталгаа заавал байна. Бодит мөнгөний `production` төлбөр сонгосон бол нэмэлтээр `ENABLE REAL PAYMENTS <domain>` гэсэн яг тохирох баталгаажуулалтгүй үед урьдчилсан шалгалт зогсоно.

`MONGOLGPT_ENABLE_ANALYTICS=true` бол зөвхөн `MONGOLGPT_ENABLE_HOSTED_SERVICES=true` үеийн байршуулалтад `https://stats.<domain>` бодит хэрэглээний статистикийн сайтыг Cloudflare D1-д тулгуурласан орчноор хамт гаргана.

Статистикийн сайтын мэдээллийн захидлын маягтын бүртгэлийг үндсэн D1 сангийн `newsletter_subscriber` хүснэгтэд хадгална. EmailOctopus-ийн нууц утга болон мэдээллийн захидлын тусдаа өгөгдлийн сан шаардахгүй.

Enterprise холбогдох маягтын хүсэлтийг `enterprise_inquiry` хүснэгтэд хадгална. Ингэснээр Salesforce, AWS SES эсвэл EmailOctopus түр тохируулаагүй үед ч хэрэглэгчийн хүсэлт алдагдахгүй.

## Бэлэн байдлын шалгалт

Hosted орчинд:

```txt
GET https://mgpt.mn/api/health
GET https://auth.mgpt.mn/health
GET https://runtime.mgpt.mn/global/health
GET https://pay.mgpt.mn/health
```

Үндсэн үйлчилгээ бэлэн үед `status` талбар `ok` байна. Төлбөр унтраалттай байршуулалтад төлбөрийн төлөв `disabled`, `sandbox` эсвэл `production` төлбөр асаалттай үед QPay, Bonum, багцын каталог, төлбөр баталгаажуулах болон цуцлах ажиллагаа бүгд бэлэн байж `ok` болно. Аль нэг нь дутуу бол `degraded` тул суурь ажиллагааны шалгалтыг амжилттай гэж үзэхгүй. Бэлэн байдлын төгсгөлийн цэг нууц утга, өгөгдлийн сангийн мэдээлэл, хувилбарын дотоод дугаар задруулахгүй.

GitHub-ийн байршуулалтын ажлын урсгал `MONGOLGPT_ENABLE_MONITORING=true` гэж Cloudflare-ийн үйлчилгээний автомат хяналтыг асаана. Cloudflare Cron таван минут тутам дээрх дөрвөн хаягийг шалгаж, зөвхөн үйлчилгээний нэр, HTTP төлөв, хариулах хугацаа, алдааны ерөнхий ангилал бүхий нотолгоог Cloudflare KV-д 20 минут хадгална. Хариуны агуулга, токен, хэрэглэгчийн мэдээллийг хадгалахгүй. Админ самбарын **Системийн бэлэн байдал** хэсэг 15 минутаас хуучин, буруу орчны эсвэл алдаатай нотолгоог `degraded` гэж харуулна. Үйлдвэрлэлийн hosted байршуулалт мониторинг унтраалттай бол урьдчилсан шалгалтаар хаагдана.

Үйлдвэрлэлийн hosted байршуулалт `MONGOLGPT_ENABLE_TURNSTILE=true`-гүй, бодит site key эсвэл secret key дутуу, эсвэл Cloudflare-ийн test key ашигласан бол урьдчилсан шалгалтаар хаагдана. Siteverify түр тасарвал OAuth эхлэлийг нээлттэй орхихгүй, Монгол тайлбартай түр алдааны хуудас харуулж хамгаалалттайгаар зогсооно.

## Буцаах

1. Асуудалтай байршуулалтаас өмнөх баталгаатай Git коммитыг сонгоно.
2. Тухайн коммитоос ижил орчин руу `bun sst deploy --stage=<stage>` ажиллуулна.
3. `bun run deploy:smoke -- <stage>` ажиллуулж бүх нийтэд нээлттэй URL-ийг шалгана.
4. Өгөгдлийн шилжилт орсон бол кодыг дангаар буцаахгүй. Шилжилт бүр урагш засах тусдаа өөрчлөлт эсвэл урьдчилан бэлтгэсэн сэргээх ажиллагаатай байна.

Үйлдвэрлэлийн орчны нөөц SST дээр хамгаалагдсан бөгөөд репозиторийг устгах эсвэл орчныг арилгах үйлдлээр санамсаргүй устахгүй.

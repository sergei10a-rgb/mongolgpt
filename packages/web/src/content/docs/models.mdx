MongolGPT нь **75+ LLM үйлчилгээ үзүүлэгчийг** дэмжихийн тулд [AI SDK](https://ai-sdk.dev/) болон [Models.dev](https://models.dev)-ийг ашигладаг бөгөөд локал загвар ажиллуулахыг мөн дэмждэг.

---

## Үйлчилгээ үзүүлэгчид

Ихэнх түгээмэл үйлчилгээ үзүүлэгчийг урьдчилан тохируулсан байдаг. Хэрэв та `/connect` тушаалаар үйлчилгээ үзүүлэгчийн нэвтрэх мэдээллийг нэмсэн бол MongolGPT-г эхлүүлэх үед тэдгээр нь бэлэн байна.

[Үйлчилгээ үзүүлэгчдийн](../providers) талаар дэлгэрэнгүй үзнэ үү.

---

## Загвар сонгох

Үйлчилгээ үзүүлэгчээ тохируулсны дараа та дараахийг бичээд хүссэн загвараа сонгох боломжтой.

```bash frame="none"
/models
```

---

## Санал болгож буй загварууд

Долоо хоног бүр шинэ загварууд гарч ирдэг маш олон загварууд байдаг.

:::tip
Бидний санал болгож буй загваруудын аль нэгийг ашиглах талаар бодож үзээрэй.
:::

Гэхдээ тэдгээрээс цөөн хэд нь л код үүсгэх болон хэрэгсэл дуудах боломжтой.

Тодорхой дараалалгүйгээр MongolGPT-тэй сайн ажилладаг хэд хэдэн загвар энд байна. (Энэ бол бүрэн жагсаалт биш бөгөөд заавал шинэчлэгдсэн байх албагүй):

- GPT 5.2
- GPT 5.1 Codex
- Claude Opus 4.5
- Claude Sonnet 4.5
- Minimax M2.1
- Gemini 3 Pro

## Өгөгдмөл загвар тохируулах

Эдгээрээс аль нэгийг өгөгдмөл загвараар тохируулахын тулд MongolGPT-ийн тохиргоонд `model` түлхүүрийг нэмнэ үү.

```json title="mongolgpt.json" {3}
{
  "model": "lmstudio/google/gemma-3n-e4b"
}
```

Бүтэн ID нь `provider_id/model_id` хэлбэртэй. Дээрх жишээнд `lmstudio` нь үйлчилгээ үзүүлэгчийн ID, `google/gemma-3n-e4b` нь загварын ID юм.

Хэрэв [захиалгат үйлчилгээ үзүүлэгч](../providers#захиалгат-үйлчилгээ-үзүүлэгч) тохируулсан бол `provider_id` нь тохиргооны `provider` хэсгийн түлхүүр, `model_id` нь `provider.models`-ийн түлхүүр байна.

## Загваруудыг тохируулах

Загварын тохиргоог глобал түвшинд өөрчилж болно.

```jsonc title="mongolgpt.jsonc" {7-12,19-24}
{
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "options": {
            "reasoningEffort": "high",
            "textVerbosity": "low",
            "reasoningSummary": "auto",
            "include": ["reasoning.encrypted_content"],
          },
        },
      },
    },
    "anthropic": {
      "models": {
        "claude-sonnet-4-5-20250929": {
          "options": {
            "thinking": {
              "type": "enabled",
              "budgetTokens": 16000,
            },
          },
        },
      },
    },
  },
}
```

Энд хоёр суурилагдсан загварт глобал тохиргоо хийж байна: `openai` үйлчилгээ үзүүлэгчээр хандах үеийн `gpt-5`, `anthropic` үйлчилгээ үзүүлэгчээр хандах үеийн `claude-sonnet-4-5-20250929`.
Суурилагдсан үйлчилгээ үзүүлэгч болон загварын нэрийг [Models.dev](https://models.dev)-ээс олж болно.

Эдгээр сонголтыг агент бүрд тусад нь өгч болно. Агентын тохиргоо глобал утгыг дарна. [Нэмэлт агентын сонголтыг](../agents/#нэмэлт) харна уу.

Та мөн суурилагдсан хувилбаруудыг өргөтгөх захиалгат хувилбар тодорхойлж болно. Ингэснээр давхардсан оруулга үүсгэлгүйгээр нэг загварын өөр тохиргоог ашиглана.

```jsonc title="mongolgpt.jsonc" {6-21}
{
  "provider": {
    "mongolgpt": {
      "models": {
        "gpt-5": {
          "variants": {
            "high": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
            "low": {
              "reasoningEffort": "low",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
          },
        },
      },
    },
  },
}
```

## Хувилбарууд

Олон загвар өөр өөр тохиргоотой хэд хэдэн хувилбарыг дэмждэг. MongolGPT түгээмэл үйлчилгээ үзүүлэгчдэд зориулсан өгөгдмөл хувилбаруудыг нийлүүлдэг.

### Суурилагдсан хувилбарууд

MongolGPT нь олон үйлчилгээ үзүүлэгчийн үндсэн хувилбаруудыг нийлүүлдэг:

**Anthropic**:

- `high` - Их хэмжээний reasoning төсөв (өгөгдмөл)
- `max` - Хамгийн их reasoning төсөв

**OpenAI**:

Загвараас хамааран өөр өөр байдаг боловч ойролцоогоор:

- `none` - Reasoning ашиглахгүй
- `minimal` - Reasoning хийх хамгийн бага хүчин чармайлт
- `low` - Reasoning хийх бага хүчин чармайлт
- `medium` - Reasoning хийх дунд зэргийн хүчин чармайлт
- `high` - Reasoning хийх их хүчин чармайлт
- `xhigh` - Reasoning хийх маш их хүчин чармайлт

**Google**:

- `low` - Бага хүчин чармайлт / токены төсөв
- `high` - Их хүчин чармайлт / токены төсөв

:::tip
Энэ нь бүрэн жагсаалт биш. Бусад олон үйлчилгээ үзүүлэгч мөн өгөгдмөл тохиргоотой.
:::

### Захиалгат хувилбарууд

Та одоо байгаа хувилбарыг дарж бичих эсвэл өөрийн хувилбарыг нэмж болно:

```jsonc title="mongolgpt.jsonc" {7-18}
{
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "variants": {
            "thinking": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
            },
            "fast": {
              "disabled": true,
            },
          },
        },
      },
    },
  },
}
```

### Циклийн хувилбарууд

Хувилбаруудын хооронд хурдан шилжихийн тулд `variant_cycle` түлхүүрийг ашиглана уу. [Дэлгэрэнгүй үзнэ үү](../keybinds).

## Загвар сонгох дараалал

MongolGPT эхлэх үед загварыг дараах дарааллаар сонгоно:

1. `--model` эсвэл `-m` тушаалын мөр. Формат нь тохиргооны файлтай адил байна: `provider_id/model_id`.

2. MongolGPT тохиргоон дахь загварын жагсаалт.

   ```json title="mongolgpt.json"
   {
     "model": "anthropic/claude-sonnet-4-20250514"
   }
   ```

   Энд байгаа формат нь `provider/model`.

3. Хамгийн сүүлд ашигласан загвар.

4. Системийн өгөгдмөл загвар.

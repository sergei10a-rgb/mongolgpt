MongolGPT-ийг байгууллагад нэвтрүүлэхдээ эхлээд жижиг баг, туршилтын репозитори, батлагдсан үйлчилгээ үзүүлэгчээр турш. Энэ хуудас нийтэд зарлаагүй удирдлагатай байгууллагын үйлчилгээ, үнэ, SLA амлахгүй; одоогийн нээлттэй эхийн хувилбарыг хянаж байршуулж буй багт зориулсан суурь заавар юм.

## Эхлэх шалгах хуудас

1. [GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ээс баталсан хувилбараа сонго.
2. Хоёртын файл болон ширээний суулгагчийг дотоод программ түгээх сувгаараа түгээ.
3. Ашиглах AI үйлчилгээ үзүүлэгч, загвар, бүс нутаг, хадгалалтын бодлогыг аюулгүй байдлын багаараа батлуул.
4. Төслийн `mongolgpt.json` файл дахь үйлчилгээ үзүүлэгч, зөвшөөрөл, бодлого, залгаас болон MCP хязгаарлалтыг Git-ийн хувилбарын бүртгэлд оруулна.
5. `/share`-ийг анхдагчаар идэвхгүй болго.
6. Нууц түлхүүрийг тохиргоо эсвэл Git-д хадгалахгүй, байгууллагын нууц удирдлагын систем ашигла.
7. Лог, сессийн хадгалалт, устгал, ослын хариу арга хэмжээний дотоод журмаа тогтоо.

```json title="mongolgpt.json"
{
  "share": "disabled",
  "permission": {
    "bash": "ask",
    "edit": "ask",
    "external_directory": "deny"
  }
}
```

## Өгөгдлийн урсгал

MongolGPT CLI сесс, лог, үйлчилгээ үзүүлэгчийн эрхийн мэдээллийг хэрэглэгчийн машинд хадгалж болно. Сануулга, сонгосон файлын агуулга, хэрэгслийн гаралт нь ашиглаж буй AI үйлчилгээ үзүүлэгч рүү хүсэлтээр илгээгдэнэ. Залгаас болон MCP сервер нэмбэл тэдгээр нь тусдаа өгөгдлийн урсгал үүсгэж болно.

Байгууллагын үнэлгээнд дараах талуудыг тус бүр шалгана.

- AI үйлчилгээ үзүүлэгчийн өгөгдөл хадгалах, сургалт, бүс нутаг, дэд гүйцэтгэгчийн бодлого
- OAuth болон API түлхүүрийн хамрах хүрээ, сэлгэлт, хүчингүй болголт
- Залгаас болон MCP серверийн эх код, нийтлэгч, сүлжээний хандалт
- Локал лог, сессийн хадгалах хугацаа болон нөөц хуулбар
- Зөвшөөрөл, бодлого, гадаад директорын дүрэм
- Хуваалцах болон алсын вэб серверийн тохиргоо

:::caution
"Локал клиент" гэдэг нь сануулга зөвхөн локалд үлдэнэ гэсэн үг биш. Сонгосон үйлчилгээ үзүүлэгчийн API руу илгээх агуулгыг үйлчилгээ үзүүлэгчийн нөхцөл, байгууллагын бодлоготой тулгаж шалга.
:::

## Хуваалцахыг хязгаарлах

MongolGPT-ийн нэгдсэн бүртгэлийн арын сервер хөгжүүлэлтийн орчинд байгаа ч нийтийн хуваалцах боломж үйлдвэрлэлийн орчинд идэвхжээгүй. Байгууллагын туршилт болон үйлдвэрлэлд нэвтрүүлэх үед хуваалцах боломжийг баталгаажтал идэвхгүй байлгана.

```json title="mongolgpt.json"
{
  "share": "disabled"
}
```

CLI/TUI, дотоод вэб, ширээний програм болон BYOK үйлчилгээ үзүүлэгч ашиглахад байгууллага өөрийн домэйн эсвэл байршуулалт тохируулах шаардлагагүй. Өөрийн Cloudflare орчинд байршуулж байгаа баг `.env.example` доторх URL-уудыг зөвхөн өөрийн эзэмшлийн URL-аар тохируулна. Нэвтрэлт, API, хуваалцах боломжийн бэлэн байдлын шалгалт, хандалтын хяналт болон аудит баталгаажаагүй орчинд `MONGOLGPT_ENABLE_HOSTED_SERVICES=false` хэвээр байна. [Хуваалцах боломжийн төлөв](../share)-ийг тусад нь шалга.

## Төвлөрсөн тохиргоо

Төслийн түвшний `mongolgpt.json`-ийг Git-ийн хувилбарын бүртгэлд оруулснаар багийн үйлчилгээ үзүүлэгч, зөвшөөрөл, бодлого, MCP болон залгаасын тохиргоог ижил байлгаж болно. Нууц утгыг `{env:VARIABLE_NAME}` хэлбэрийн орчны хувьсагчаар өгнө.

```json title="mongolgpt.json"
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}"
      }
    }
  },
  "share": "disabled"
}
```

Тохиргооны хүчин төгөлдөр утгыг хэрэглэгчийн машин дээр шалгана.

```bash
mongolgpt debug config
```

Тохиргооны эрэмбэ болон боломжтой түлхүүрүүдийг [тохиргооны лавлагаанаас](../config) үзнэ үү.

## Дотоод AI gateway

Байгууллагын AI гарц OpenAI-тай нийцтэй API өгдөг бол [захиалгат үйлчилгээ үзүүлэгч](../providers#захиалгат-үйлчилгээ-үзүүлэгч) хэлбэрээр тохируулж болно. `baseURL`, загварын ID, HTTP толгой хэсэг, гэрчилгээ болон проксийг тухайн гарцын албан ёсны утгаар тохируулна.

Бусад үйлчилгээ үзүүлэгчийг хязгаарлахдаа зөвхөн интерфэйсийн жагсаалт нуухад найдахгүй. Гадагш чиглэсэн firewall, прокси зөвшөөрлийн жагсаалт, үйлчилгээ үзүүлэгчийн бодлого, нууц түгээлтийг хамтад нь ашигла.

## SSO ба алсын хандалт

Нээлттэй эхийн CLI нь үйлчилгээ үзүүлэгч бүрийн дэмжсэн OAuth эсвэл API түлхүүрийн аргыг ашиглана. Байгууллагын SSO-г өөрийн вэб/урвуу прокси давхаргад нэмэх бол:

1. HTTPS болон байгууллагын IdP баталгаажуулалтыг тохируул.
2. Үндсэн MongolGPT серверт зөвхөн урвуу проксигоор хандахыг зөвшөөр.
3. `MONGOLGPT_SERVER_PASSWORD`-г нэмэлт хамгаалалт болгон ашигла.
4. Сессийн хугацаа, бүлгийн зөвшөөрөл, аудитын логийг турш.
5. Нэвтрэлтийг тойрч гарах локал болон сүлжээний чиглүүлэлт байхгүйг шалга.

Удирдлагатай SSO боломж байгаа мэтээр нийтэд зарлахын өмнө бодит байршуулалт, дэмжлэг хариуцах эзэн, SLA-г тусад нь баталгаажуулна.

## Хувийн npm registry

Хэрэв байгууллага npm dependency-г JFrog Artifactory, Nexus зэрэг хувийн registry-ээр дамжуулдаг бол эхлээд npm эрхээ тохируулна.

```bash
npm login --registry=https://your-company.jfrog.io/api/npm/npm-virtual/
```

Эсвэл `~/.npmrc`:

```ini title="~/.npmrc"
registry=https://your-company.jfrog.io/api/npm/npm-virtual/
//your-company.jfrog.io/api/npm/npm-virtual/:_authToken=${NPM_AUTH_TOKEN}
```

`NPM_AUTH_TOKEN`-ийг эх кодын хувилбарын бүртгэлд бүү оруул. Токены хамрах хүрээ болон хугацааг хамгийн бага шаардлагатай хэмжээнд тохируулна.

## Түгээмэл асуулт

<details>
<summary>MongolGPT код эсвэл сануулгыг хаашаа илгээдэг вэ?</summary>

Локал програм өөрөө сесс, лог хадгалж болно. AI хүсэлтэд багтсан сануулга, файл, хэрэгслийн гаралт нь сонгосон үйлчилгээ үзүүлэгч рүү илгээгдэнэ. Залгаас, MCP эсвэл хуваалцах боломж ашиглавал нэмэлт үйлчилгээ рүү өгөгдөл дамжиж болно.

</details>

<details>
<summary>Байгууллагын бүх хэрэглэгчид ижил тохиргоо ашиглаж болох уу?</summary>

Төслийн `mongolgpt.json`-ийг commit хийж суурь тохиргоог ижил байлгаж болно. Нууц утгыг орчны хувьсагч эсвэл нууц удирдлагын системээс өгнө. Үйлдлийн системийн түвшний удирдлагатай тохиргоо ашиглах бол тухайн платформ дээр туршиж, `mongolgpt debug config`-оор үр дүнг баталгаажуул.

</details>

<details>
<summary>Удирдлагатай байгууллагын үйлчилгээний үнэ, SLA хаана байна?</summary>

Энэ баримт бичиг удирдлагатай санал, үнэ, SLA зарлаагүй. Одоогийн боломжийг эх код болон хувилбарын тэмдэглэлээс шалгаж, шаардлагатай боломж эсвэл байршуулалтын асуултыг [GitHub Issues](https://github.com/sergei10a-rgb/mongolgpt/issues)-д нууц мэдээлэлгүйгээр оруулна.

</details>

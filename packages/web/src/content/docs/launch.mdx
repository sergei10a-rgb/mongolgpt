Энэ хуудас шинэ хэрэглэгчийг суулгалт, нэвтрэлт, загварын сонголт болон анхны сесс хүртэл нэг дарааллаар хөтөлнө. Нэг бүртгэлээр Web, Desktop, CLI-д нэвтрэх боловч локал файл, терминал болон Git-тэй ажиллахад Desktop эсвэл CLI ашиглана.

:::caution[Одоогийн үйлчилгээний төлөв]
`*.dev.mgpt.mn` нь хөгжүүлэлтийн туршилтын орчин. Үйлдвэрлэлийн нээлтийг албан ёсоор зарлахаас өмнө бодит төлбөрийн мэдээлэл бүү оруул. Free Auto нь тухайн орчинд загварын үйлчилгээ тохируулагдаж, эрүүл үед ажиллана; өөрийн API түлхүүр болон локал загвар тусдаа хэвээр байна.
:::

## 1. Ашиглах орчноо сонгох

| Хэрэгцээ                                               | Сонголт                                                                                               |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| Локал төсөл, файл, Git, терминалтай ажиллах            | [Windows Desktop](../desktop) эсвэл [CLI](../cli)                                                     |
| Суулгахгүйгээр бүртгэл, ажлын талбар, хэрэглээг шалгах | Үйлдвэрлэлийн нээлтийн дараа `https://app.mgpt.mn`; хөгжүүлэлтийн туршилтад `https://app.dev.mgpt.mn` |
| Тухайн компьютер дээр CLI-ийн локал вэб интерфэйс нээх | [`mongolgpt web`](../web#локал-вэб-интерфэйс)                                                         |

Нийтийн Web програм хэрэглэгчийн `localhost` эсвэл файлын системд шууд хүрэхгүй. Локал төсөл дээр агент ажиллуулах бол Desktop, CLI эсвэл хамгаалалттай локал холбогч ашиглана.

## 2. Суулгах

Windows Desktop болон CLI-ийн файлыг зөвхөн [MongolGPT GitHub Releases](https://github.com/sergei10a-rgb/mongolgpt/releases)-ээс авна. Файлын нэр, архитектур, checksum болон SmartScreen-ийн дэлгэрэнгүйг [суулгах гарын авлагаас](../install) шалгана.

CLI суусныг баталгаажуулах:

```bash
mongolgpt --version
```

## 3. MongolGPT бүртгэлээр нэвтрэх

- **Web:** MongolGPT-ийн нэвтрэх хуудаснаас GitHub эсвэл Google-ийг сонгоно.
- **Desktop:** **Тохиргоо → Бүртгэл → Нэвтрэх**-ийг сонгоно.
- **CLI:** дараах командыг ажиллуулна.

```bash
mongolgpt account login
```

Хөтөч автоматаар нээгдэхгүй бол:

```bash
mongolgpt account login --no-browser
```

Зөвшөөрөл дууссаны дараа CLI/програм дахь бүртгэлийн нэр, ажлын талбар болон багцын төлөвийг шалгана. Хөтөч `127.0.0.1 refused`, буцах дуудлагын давталт эсвэл `unknown browser state` алдаа үзүүлбэл хуучин tab-ийг дахин ачаалахгүй, [нэвтрэлтийн сэргээх алхмуудыг](../troubleshooting#mongolgpt-бүртгэлийн-oauth-нэвтрэлт-дуусахгүй) дагана.

## 4. Загварын эх үүсвэрээ сонгох

Нэвтэрсэн бүртгэлд Free Auto нээлттэй байвал MongolGPT боломжтой үнэгүй загварыг бодлогоор сонгоно. Нээлтгүй эсвэл хязгаарт хүрсэн бол хэрэглэгчид бодит төлөв, дахин ашиглах хугацаа болон дараагийн сонголтыг харуулна.

Өөрийн эх үүсвэр ашиглах бол:

- OpenRouter, NVIDIA NIM эсвэл өөр үйлчилгээ үзүүлэгчийн API түлхүүр;
- OpenAI-тэй нийцсэн хувийн төгсгөлийн цэг;
- Desktop/CLI дээр Ollama эсвэл LM Studio.

```text
/connect
/models
```

Тохиргооны утга, түлхүүрийн хадгалалт болон локал загварын алхмыг [үйлчилгээ үзүүлэгчдийн заавраас](../providers) харна уу.

## 5. Анхны сессээ шалгах

1. Туршилтын жижиг репозитор эсвэл нууц мэдээлэлгүй хавтас нээнэ.
2. Боломжтой загвараа сонгоно.
3. Эхлээд унших, тайлбарлах богино хүсэлт өгнө.
4. Файл бичих эсвэл команд ажиллуулах зөвшөөрөл бүрийг уншина.
5. Өөрчлөлтийн diff болон тестийн үр дүнг хүлээн авахаасаа өмнө шалгана.

```text
Энэ төслийн бүтцийг өөрчлөлт хийхгүйгээр тайлбарла.
```

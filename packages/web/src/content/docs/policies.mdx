---
title: Бодлогууд
description: MongolGPT аль тохируулсан нөөцүүдийг ашиглаж болохыг хянах.
---

Бодлого нь MongolGPT нэртэй нөөц дээр үйлдэл хийхийг зөвшөөрөх эсэхийг хянадаг. Энэ нь туршилтын боломж бөгөөд `mongolgpt.json` дахь `experimental.policies` массиваар тохируулна.

Бодлого нь [зөвшөөрлөөс](../permissions) тусдаа. Зөвшөөрөл нь сессийн үеэр ямар хэрэгсэл ашиглаж болохыг хянадаг бол бодлого нь MongolGPT-ийн үйлчилгээ үзүүлэгч зэрэг нөөцийг ашиглахыг зөвшөөрөх эсэхийг хянадаг.

---

## Тохиргоо

Бодлогын дүрэм бүр гурван талбартай:

- `effect` - `"allow"` эсвэл `"deny"`.
- `action` - Хянах үйлдэл.
- `resource` - Дүрэмд хамаарах нөөцийн ID эсвэл орлуулагчийн загвар.

Жишээ нь, `openai` үйлчилгээ үзүүлэгчийг хориглох:

```json title="mongolgpt.json"
{
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "openai"
      }
    ]
  }
}
```

Бодлогоор хориглосон үйлчилгээ үзүүлэгч нь итгэмжлэлтэй, зөв тохируулсан байсан ч загвар сонгох болон ашиглахад боломжгүй байна.

---

## Боломжтой бодлого

MongolGPT одоогоор нэг бодлогын үйлдлийг дэмждэг:

| Үйлдэл | Нөөц | Тодорхойлолт |
| -------------- | ----------------------------- | ------------------------------------- |
| `provider.use` | Үйлчилгээ үзүүлэгчийн ID, жишээ нь `openai` | LLM үйлчилгээ үзүүлэгчийг ашиглахыг зөвшөөрөх эсвэл хориглох. |

Цаашид өөр үйлдлүүдийг нэмэх боломжтой.

---

## Тохирох

`resource` талбар нь орлуулагч тэмдэгт дэмждэг. `*` нь тэг буюу түүнээс олон тэмдэгттэй, `?` нь нэг тэмдэгттэй таарна.

```json title="mongolgpt.json"
{
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "company-*"
      }
    ]
  }
}
```

Энэ нь `company-us`, `company-eu` зэрэг үйлчилгээ үзүүлэгчийг хориглоно.

---

## Дүрэм

Олон дүрэм таарвал хамгийн сүүлд таарсан дүрэм үйлчилнэ. Өргөн хүрээтэй дүрмийг эхэлж, илүү тодорхой үл хамаарах дүрмийг дараа нь байрлуулна.

Жишээлбэл, зөвхөн Anthropic-г зөвшөөрөх:

```json title="mongolgpt.json"
{
  "experimental": {
    "policies": [
      {
        "effect": "deny",
        "action": "provider.use",
        "resource": "*"
      },
      {
        "effect": "allow",
        "action": "provider.use",
        "resource": "anthropic"
      }
    ]
  }
}
```

Үйлчилгээ үзүүлэгчтэй таарах бодлого байхгүй бол тухайн үйлчилгээ үзүүлэгчийг өгөгдмөлөөр ашиглахыг зөвшөөрнө.

Бодлогыг глобал болон төслийн тохиргоонд тохируулж болно. Хоёр байршлын бодлого ижил үйлчилгээ үзүүлэгчтэй таарвал глобал бодлого нь төслийн бодлогоос давуу үйлчилнэ. Ингэснээр глобал түвшинд хориглосон үйлчилгээ үзүүлэгчийг репозиторт дахин идэвхжүүлэхээс сэргийлнэ.

---

## Үйлчилгээ үзүүлэгчдийн жагсаалт

Үйлчилгээ үзүүлэгчийн хандалтыг хянахдаа хуучин `disabled_providers` болон `enabled_providers` тохиргооны оронд бодлого ашиглана уу.

`disabled_providers`-г солихын тулд:

```json title="mongolgpt.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "openai" },
      { "effect": "deny", "action": "provider.use", "resource": "google" }
    ]
  }
}
```

`enabled_providers`-г орлуулахын тулд эхлээд бүх үйлчилгээ үзүүлэгчийг хориглоод, дараа нь сонгосон үйлчилгээ үзүүлэгчийг зөвшөөрнө үү:

```json title="mongolgpt.json"
{
  "experimental": {
    "policies": [
      { "effect": "deny", "action": "provider.use", "resource": "*" },
      { "effect": "allow", "action": "provider.use", "resource": "anthropic" },
      { "effect": "allow", "action": "provider.use", "resource": "openai" }
    ]
  }
}
```

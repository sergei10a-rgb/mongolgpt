---
title: Зөвшөөрөл
description: Ямар үйлдлийг гүйцэтгэхийн тулд зөвшөөрөл шаардлагатайг хянах.
---

MongolGPT нь `permission` тохиргоог ашиглан өгөгдсөн үйлдлийг автоматаар гүйцэтгэх, танд сануулах эсвэл хаагдах эсэхийг шийддэг.

`v1.1.1`-ийн байдлаар, хуучин `tools` логикийн тохиргоо хуучирсан бөгөөд `permission`-д нэгтгэгдсэн. Хуучин `tools` тохиргоог буцаан нийцүүлэхийн тулд дэмжсэн хэвээр байна.

---

## Үйлдэл

Зөвшөөрлийн дүрэм бүр нь дараахь зүйлийг шийддэг.

- `"allow"` - зөвшөөрөлгүйгээр ажиллуулах
- `"ask"` — зөвшөөрөл авах хүсэлт
- `"deny"` — үйлдлийг хаах

---

## Тохиргоо

Та зөвшөөрлийг дэлхий даяар (`*`-тай) тохируулж, тусгай хэрэгслийг хүчингүй болгож болно.

```json title="mongolgpt.json"
{
  "permission": {
    "*": "ask",
    "bash": "allow",
    "edit": "deny"
  }
}
```

Та мөн бүх зөвшөөрлийг нэг дор тохируулж болно:

```json title="mongolgpt.json"
{
  "permission": "allow"
}
```

---

## Нарийвчилсан дүрэм (объектын синтакс)

Ихэнх зөвшөөрөлд хэрэгслийн оролтоос хамаарч өөр өөр үйлдэл хийх объект ашиглаж болно.

```json title="mongolgpt.json"
{
  "permission": {
    "bash": {
      "*": "ask",
      "git *": "allow",
      "npm *": "allow",
      "rm *": "deny",
      "grep *": "allow"
    },
    "edit": {
      "*": "deny",
      "packages/web/src/content/docs/*.mdx": "allow"
    }
  }
}
```

Дүрмүүдийг загварын тохирлоор үнэлдэг ба **хамгийн сүүлд тохирсон дүрэм ялна**. Нийтлэг загвар бол catch-all `"*"` дүрмийг эхлээд, дараа нь илүү тодорхой дүрмийг тавих явдал юм.

### Орлуулагч тэмдэг

Зөвшөөрлийн загвар нь энгийн орлуулагдах тэмдэгтийг ашиглана:

- `*` нь ямар ч тэмдэгтийн тэг буюу түүнээс олон давталттай таарна
- `?` нь яг нэг тэмдэгттэй таарна
- Бусад бүх тэмдэгт шууд утгаараа таарна

### Гэрийн лавлахын товчлол

Загварын эхэнд `~` эсвэл `$HOME` ашиглан гэрийн лавлахыг зааж болно. Энэ нь ялангуяа [`external_directory`](#гадаад-лавлахууд) дүрэмд хэрэгтэй.

- `~/projects/*` -> `/Users/username/projects/*`
- `$HOME/projects/*` -> `/Users/username/projects/*`
- `~` -> `/Users/username`

### Гадаад лавлахууд

`external_directory` нь эхлүүлсэн ажлын лавлахын гаднах замд хүрэх хэрэгслийн дуудлагыг зөвшөөрнө. Энэ нь оролтдоо зам авдаг аливаа хэрэгсэлд хамаарна (жишээ нь `read`, `edit`, `glob`, `grep` болон олон `bash` тушаал).

Гэрийн лавлахын товчлол (`~/...` гэх мэт) нь зөвхөн загварыг хэрхэн бичихэд нөлөөлнө. Энэ нь замыг одоогийн ажлын талбарын доторх болгохгүй тул ажлын лавлахаас гадуурх замыг `external_directory`-ээр зөвшөөрөх ёстой.

Жишээлбэл, энэ нь `~/projects/personal/` доорх бүх зүйлд хандах боломжийг олгоно:

```json title="mongolgpt.json"
{
  "permission": {
    "external_directory": {
      "~/projects/personal/**": "allow"
    }
  }
}
```

Зөвшөөрсөн гадаад лавлах нь ажлын талбарын өгөгдмөл permission-ийг өвлөнө. [`read` анхдагчаар `allow`](#өгөгдмөл) тул тусад нь override хийгээгүй бол тухайн замыг уншиж чадна. Уншихыг зөвшөөрөөд `edit`-ийг хориглох зэрэг нарийвчилсан дүрэм нэмж болно:

```json title="mongolgpt.json"
{
  "permission": {
    "external_directory": {
      "~/projects/personal/**": "allow"
    },
    "edit": {
      "~/projects/personal/**": "deny"
    }
  }
}
```

Жагсаалтыг итгэмжлэгдсэн замууд дээр төвлөрүүлж, бусад хэрэгсэлд шаардлагатай бол нэмэлт дүрмүүдийг зөвшөөрөх эсвэл үгүйсгэх (жишээ нь `bash`).

---

## Боломжтой зөвшөөрөл

MongolGPT-ийн зөвшөөрлийг хэрэгслийн нэр болон хэд хэдэн хамгаалалтын дүрэм тодорхойлно:

- `read` — файл унших (файлын замд таарна)
- `edit` — файлын бүх өөрчлөлт (`edit`, `write`, `patch` хамарна)
- `glob` — файлын загвараар хайх (glob загварт таарна)
- `grep` — агуулгын хайлт (regex загварт таарч байна)
- `bash` — бүрхүүлийн команд ажиллуулах (`git status --porcelain` зэрэг задалсан командтай таарна)
- `task` — дэд агент ажиллуулах (дэд агентын төрөлд таарна)
- `skill` — ур чадвар ачаалж байна (ур чадварын нэрэнд таарч байна)
- `lsp` — LSP хүсэлт илгээх (одоогоор нарийн тааруулалтгүй)
- `question` — ажиллах явцад хэрэглэгчээс асуулт асуух
- `webfetch` — URL татах (URL-д таарна)
- `websearch` — вэбээс хайх (асуулгад таарна)
- `external_directory` — хэрэгсэл төслийн ажлын лавлахаас гаднах замд хүрэхэд идэвхжинэ
- `doom_loop` — нэг хэрэгслийг ижил оролтоор 3 удаа дараалан дуудах үед идэвхжинэ.

---

## Өгөгдмөл

Хэрэв та юу ч заагаагүй бол MongolGPT зөвшөөрөгдсөн өгөгдмөлөөс эхэлнэ:

- Ихэнх зөвшөөрлүүд өгөгдмөлөөр `"allow"` байна.
- `doom_loop` болон `external_directory` анхдагч нь `"ask"`.
- `read` нь `"allow"` боловч `.env` файлууд нь анхдагчаар татгалзсан байна:

```json title="mongolgpt.json"
{
  "permission": {
    "read": {
      "*": "allow",
      "*.env": "deny",
      "*.env.*": "deny",
      "*.env.example": "allow"
    }
  }
}
```

---

## “Асуу” хэрхэн ажилладаг вэ

MongolGPT зөвшөөрөл хүсэхэд UI гурван сонголт санал болгоно:

- `once` - зөвхөн энэ хүсэлтийг зөвшөөрнө
- `always` - санал болгож буй загварт тохирсон ирээдүйн хүсэлтийг батлах (одоогийн MongolGPT сессийн үлдсэн хугацаанд)
- `reject` - хүсэлтийг үгүйсгэх

`always` сонголтын үед зөвшөөрөгдөх файлын загваруудын багцыг тухайн хэрэгсэл өгнө (жишээ нь, `bash` зөвшөөрөл нь `git status*` зэрэг аюулгүй командын угтварыг зөвшөөрнө).

## Агентууд

Агент бүр зөвшөөрлийг тусгайлан өөрчлөх тохиргоотой байж болно. Агентын дүрэм глобал тохиргооноос давуу үйлчилнэ. [Агентын зөвшөөрлийн тохиргоог](../agents#зөвшөөрөл) харна уу.

:::note
Загвар тааруулалтын жишээг [Нарийвчилсан дүрэм](#нарийвчилсан-дүрэм-объектын-синтакс) хэсгээс харна уу.
:::

```json title="mongolgpt.json"
{
  "permission": {
    "bash": {
      "*": "ask",
      "git *": "allow",
      "git commit *": "deny",
      "git push *": "deny",
      "grep *": "allow"
    }
  },
  "agent": {
    "build": {
      "permission": {
        "bash": {
          "*": "ask",
          "git *": "allow",
          "git commit *": "ask",
          "git push *": "deny",
          "grep *": "allow"
        }
      }
    }
  }
}
```

Та мөн Markdown-д агентийн зөвшөөрлийг тохируулах боломжтой:

```markdown title="~/.config/mongolgpt/agents/review.md"
---
description: Код өөрчлөхгүйгээр хянах
mode: subagent
permission:
  edit: deny
  bash: ask
  webfetch: deny
---

Зөвхөн кодыг шинжилж, өөрчлөлт санал болго.
```

:::tip
Аргументтай командуудад тохирох загвар ашиглана уу. `"grep *"` нь `grep pattern file.txt`-г зөвшөөрдөг бол `"grep"` ганцаараа үүнийг хориглох болно. `git status` гэх мэт тушаалууд нь анхдагч үйлдлийн хувьд ажилладаг боловч аргумент дамжуулагдах үед тодорхой зөвшөөрөл (`"git status *"` гэх мэт) шаарддаг.
:::

MongolGPT нь файл унших, код өөрчлөх, shell тушаал ажиллуулах, сүлжээнд хандах чадвартай coding agent. Иймээс зөвшөөрлийн дэлгэц, тусгаарласан орчин, нууц түлхүүрийн хамгаалалтыг хамтад нь ашиглана.

:::caution[Зөвшөөрөл нь sandbox биш]
Desktop болон CLI-ийн зөвшөөрлийн цонх нь agent ямар үйлдэл хийх гэж байгааг харуулж, хэрэглэгчээр батлуулах хамгаалалт. Энэ нь үйлдлийн системийн түвшний тусгаарлалт биш. Танихгүй код, залгаас эсвэл MCP сервер туршихдаа тусдаа хэрэглэгч, container эсвэл VM ашиглана.
:::

## Дотоод төсөл дээр ажиллах

- Ажиллуулахын өмнө зөв репозитор, branch болон working tree сонгогдсон эсэхийг шалгана.
- Файл устгах, репозиторийн гадна бичих, package суулгах, сүлжээ ашиглах болон destructive Git тушаалыг тус бүрээр нь хянана.
- `.env`, SSH түлхүүр, cloud credential, browser profile, password manager болон үйлдвэрлэлийн өгөгдлийг төслийн хавтаст бүү хуул.
- Agent-ийн гаргасан diff, тестийн үр дүн, migration болон deploy тушаалыг өөрөө хянасны дараа commit эсвэл publish хийнэ.
- Өндөр эрсдэлтэй ажлыг үндсэн компьютер дээр шууд ажиллуулахгүй; хамгийн бага эрхтэй тусгаарласан орчин ашиглана.

Зөвшөөрлийн дүрмийг [зөвшөөрөл](../permissions), байгууллагын бодлогыг [бодлого](../policies)-оос тохируулна.

## Нууц түлхүүр ба нэвтрэлт

- OAuth нэвтрэлтийг зөвхөн `mgpt.mn`, `auth.mgpt.mn` болон туршилтын үед `*.dev.mgpt.mn` хаягтай тулгаж зөвшөөрнө.
- API түлхүүрийг chat, prompt, issue, screenshot, terminal history эсвэл Git-д бүү оруул.
- BYOK түлхүүрийг **Тохиргоо → Үйлчилгээ үзүүлэгчид** хэсгээр нэмнэ. Байршуулсан түлхүүр ажлын орчин болон provider-ийн хүрээнд шифрлэгдэнэ.
- Local provider ашиглахдаа `127.0.0.1`-д сонсгоно. Баталгаажуулалтгүй Ollama, LM Studio эсвэл OpenAI-compatible endpoint-ийг нийтийн сүлжээнд бүү нээ.
- Түлхүүр алдагдсан гэж сэжиглэвэл эх үйлчилгээ үзүүлэгч дээр нь шууд хүчингүй болгож, MongolGPT-ээс устгаад шинэ түлхүүр үүсгэнэ.

Өгөгдөл хаана хадгалагддагийг [нууцлал](../privacy), provider бүрийн тохиргоог [үйлчилгээ үзүүлэгчид](../providers)-ээс үзнэ үү.

## MCP, ур чадвар ба залгаас

MCP сервер, агентын ур чадвар болон JavaScript/TypeScript залгаас нь MongolGPT процессын эрхээр код ажиллуулах эсвэл гаднын үйлчилгээ рүү өгөгдөл илгээж болно.

1. Нийтлэгч, эх код, package нэр, install script болон шаардах орчны хувьсагчийг шалгана.
2. Интеграцийн командыг эхлээд `mongolgpt compat import plan`-аар төлөвлөж, бичих файлын diff-ийг хянана.
3. Нууц түлхүүрийг импортын файлд хадгалахгүй; шаардлагатай бол тусдаа secret store эсвэл орчны хувьсагчаар өгнө.
4. MCP серверт зөвхөн шаардлагатай хавтас, host болон tool-ийн эрх өгнө.
5. Шинэчлэлтийн дараа package version, lockfile болон шинээр нэмэгдсэн эрхийг дахин шалгана.

Дэмждэг форматын яг хязгаарыг [экосистемийн compatibility matrix](../ecosystem#нийцлийн-матриц)-аас харна уу.

## Local server ба attach

`mongolgpt serve` эсвэл `mongolgpt web` ажиллуулахдаа нууц үггүй серверийг LAN эсвэл интернетэд бүү нээ.

```powershell
$env:MONGOLGPT_SERVER_PASSWORD = "урт-санамсаргүй-нууц"
mongolgpt serve --hostname 127.0.0.1
```

- Өгөгдмөлөөр loopback хаяг ашиглана.
- `0.0.0.0` сонговол firewall, TLS reverse proxy болон хандалтын бодлогыг тусад нь тохируулна.
- `--cors`-д wildcard биш, яг ашиглах origin-оо өгнө.
- Attach хийхээс өмнө URL, TLS certificate болон серверийн эзэмшигчийг шалгана.

## Вэб ба байршуулсан ажиллах орчин

Вэб апп таны компьютерийн local filesystem-д шууд хүрэхгүй. Local төсөлтэй ажиллахад Desktop/CLI local bridge ашиглана. Cloud project-ийн agent execution нь тусгаарласан ажиллах орчин, богино хугацаатай capability, нөөцийн хязгаар, cleanup болон audit шаарддаг; backend бэлэн бус үед UI нь local файлд хүрсэн мэт дүр үзүүлэх ёсгүй.

`app.mgpt.mn` нь static app, account/API нь үндсэн console, agent runtime нь тусдаа origin дээр ажиллана. Нэвтрэх cookie болон runtime capability-г өөр domain, extension эсвэл гуравдагч талын script-д дамжуулахгүй.

## Сэжигтэй үйлдэл илэрвэл

1. Agent-ийн ажиллагааг зогсоож, Desktop/CLI болон холбоотой local server-ийг хаана.
2. MongolGPT аккаунтаас гарч, provider болон Git hosting token-оо хүчингүй болгоно.
3. Working tree, Git history, audit log болон provider usage-ийг шалгана.
4. Нууц түлхүүр орсон commit-ийг зөвхөн устгаад орхихгүй; түлхүүрийг заавал солино.
5. Үйлдвэрлэлийн нөлөөтэй бол [Cloudflare тасалдсан үеийн заавар](../deployment#cloudflare-тасалдсан-үед)-ыг дагана.

## Аюулгүй байдлын асуудал мэдэгдэх

Эмзэг байдлын дэлгэрэнгүй, exploit эсвэл нууц мэдээллийг public issue-д бүү нийтэл. [GitHub Security Advisory](https://github.com/sergei10a-rgb/mongolgpt/security/advisories/new)-ийн **Report a vulnerability** сувгаар хувилбар, нөлөө, дахин гаргах хамгийн бага алхам болон санал болгож буй хамгаалалтыг нууцаар илгээнэ.

Нарийн төвөгтэй, олон алхамт даалгаврыг бие даан гүйцэтгүүлэхийн тулд шинэ agent ажиллуул.

Task tool-ийг ашиглахдаа ямар төрлийн agent ашиглахаа сонгохын тулд subagent_type parameter-ийг заавал өгнө.

Task tool-ийг ашиглаж БОЛОХГҮЙ үе:
- Тодорхой файлын замыг уншихыг хүсэж байвал тохирох файлыг хурдан олохын тулд Task tool-ийн оронд Read эсвэл Glob tool ашигла
- "class Foo" гэх мэт тодорхой class definition хайж байвал тохирох хэсгийг хурдан олохын тулд Grep tool ашигла
- Тодорхой нэг файл эсвэл 2-3 файлын багц дотор код хайж байвал тохирох хэсгийг хурдан олохын тулд Task tool-ийн оронд Read tool ашигла
- Боломжтой agent-уудаас аль нь ч даалгаварт тохирохгүй бол бусад tool-ийг шууд ашигла


Хэрэглэх тэмдэглэл:
1. Гүйцэтгэлийг нэмэгдүүлэхийн тулд боломжтой бүх үед олон agent-ийг зэрэг ажиллуул; үүний тулд нэг message дотор олон tool use өг
2. Ажлыг agent-д даалгасны дараа тэр ажлыг өөрөө давхар бүү хий. Давхцахгүй ажлуудаа үргэлжлүүл эсвэл үр дүнг хүлээ. Background task-ийн үр дүн бэлэн болоход танд автоматаар мэдэгдэнэ.
3. Agent дуусахдаа танд нэг message буцаана. Agent-ийн буцаасан үр дүн хэрэглэгчид харагдахгүй. Үр дүнг хэрэглэгчид харуулахын тулд үр дүнгийн товч хураангуйг текст message-ээр хэрэглэгчид илгээ. Гаралт нь тухайн subagent session-ийг дараа үргэлжлүүлэхэд дахин ашиглаж болох task_id агуулна.
4. Ижил subagent session-ийг өмнөх message болон tool output-тай нь үргэлжлүүлэх task_id өгөөгүй бол agent invocation бүр шинэ context-оос эхэлнэ. Шинээр эхлүүлэхдээ agent бие даан гүйцэтгэх даалгаврын маш дэлгэрэнгүй тайлбарыг prompt-д оруулж, эцсийн бөгөөд цорын ганц message-дээ яг ямар мэдээлэл буцаахыг тодорхой заа.
5. Agent-ийн гаралтад ерөнхийдөө итгэж болно
6. Agent хэрэглэгчийн санааг мэдэхгүй тул түүнээс код бичихийг хүсэж байна уу эсвэл зөвхөн судалгаа (хайлт, файл унших, web fetch гэх мэт) хийхийг хүсэж байна уу гэдгээ тодорхой хэл. Боломжтой бол ажлаа хэрхэн шалгахыг нь мөн хэл (жишээлбэл, холбогдох test command).
7. Agent-ийн description-д proactive ашиглах ёстой гэж дурдсан бол хэрэглэгч заавал дахин хүсэхийг хүлээлгүйгээр түүнийг ашиглахыг боломжийн хэмжээнд хичээ. Өөрийн дүгнэлтийг ашигла.

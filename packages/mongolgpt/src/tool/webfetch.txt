- Заасан URL-ээс агуулга татна.
- URL болон сонголттой format-ийг оролт болгон авна.
- URL-ийн агуулгыг татаж, хүссэн format руу хөрвүүлнэ (анхдагч нь markdown).
- Агуулгыг заасан format-аар буцаана.
- Вэбийн агуулгыг татаж шинжлэх шаардлагатай үед энэ хэрэгслийг ашигла.

Хэрэглээний тэмдэглэл:
  - ЧУХАЛ: Хэрэв өөр хэрэгсэл вэбийг илүү сайн татах боломжтой, тухайн даалгаварт илүү тохиромжтой эсвэл хязгаарлалт багатай бол энэ хэрэгслийн оронд тэр хэрэгслийг ашиглахыг урьтал болго.
  - URL нь бүрэн хэлбэртэй, хүчинтэй URL байх ёстой.
  - HTTP URL-ийг автоматаар HTTPS болгож шинэчилнэ.
  - Format-ийн сонголт: "markdown" (анхдагч), "text" эсвэл "html".
  - Энэ хэрэгсэл зөвхөн унших зориулалттай бөгөөд ямар ч файл өөрчлөхгүй.
  - Агуулга маш том бол үр дүнг хураангуйлж болно.

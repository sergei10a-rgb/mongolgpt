- Ямар ч хэмжээтэй кодын сантай ажиллах хурдан файлын pattern тааруулах хэрэгсэл.
- `"**/*.js"` эсвэл `"src/**/*.ts"` зэрэг glob pattern дэмжинэ.
- Таарсан file path-уудыг буцаана.
- Нэрийн pattern-аар файл олох шаардлагатай үед энэ хэрэгслийг ашигла.
- Олон удаагийн glob болон grep шаардаж болзошгүй нээлттэй хайлт хийж байгаа бол оронд нь Task tool ашигла.
- Нэг хариултад олон хэрэгслийг зэрэг дуудах боломжтой. Хэрэг болж болох олон хайлтыг урьдчилан нэг багцаар хийх нь үргэлж дээр.

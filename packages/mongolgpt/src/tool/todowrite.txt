Одоогийн coding session-д зориулсан бүтэцтэй task list үүсгэж, хөтөл. Явцыг бүртгэж, олон алхамт ажлыг зохион байгуулж, status-ийг хэрэглэгчид харуулна.

## Хэзээ ашиглах
Дараах үед proactive ашигла:
- Даалгавар 3 ба түүнээс олон тусдаа алхам эсвэл үйлдэл шаардах үед (нэг утгын алхамд зориулсан ердөө 3 tool call биш)
- Ажил энгийн бус бөгөөд төлөвлөлтөөс ашиг хүртэх үед
- Хэрэглэгч олон даалгавар (дугаарласан эсвэл таслалаар тусгаарласан) өгсөн, эсвэл todo list илэрхий хүссэн үед
- Шинэ заавар ирэхэд түүнийг todo болгон бүртгэ
- Даалгавар эхлэхдээ ажиллахаас өмнө `in_progress` гэж тэмдэглэ (нэг удаад зөвхөн нэг)
- Даалгавар дуусахдаа `completed` гэж тэмдэглээд ажлын явцад илэрсэн follow-up-уудыг нэм

## Хэзээ ашиглахгүй
Дараах үед алгас:
- Ажил нэг, энгийн даалгавар (эсвэл 3-аас цөөн жижиг алхам) байх үед
- Хүсэлт зөвхөн мэдээллийн эсвэл харилцан ярианы шинжтэй үед
- Явц бүртгэх нь зохион байгуулалтын ямар ч үнэ цэн нэмэхгүй үед

## Төлөвүүд
- `pending` - эхлээгүй
- `in_progress` - идэвхтэй ажиллаж байгаа (нэг удаад яг НЭГ)
- `completed` - амжилттай дууссан
- `cancelled` - цаашид шаардлагагүй болсон

## Дүрмүүд
- Status-ийг бодит цагт шинэчил; completion-уудыг багцлан бүү шинэчил
- Шаардлагатай verification-ийг оролцуулан шаардсан ажил бодитоор дууссаны дараа л `completed` гэж тэмдэглэ. Зөвхөн хийх санаанд үндэслэж хэзээ ч бүү тэмдэглэ.
- Ажил үлдсэн хугацаанд яг нэг `in_progress` байлга
- Blocked эсвэл хэсэгчлэн дууссан бол `in_progress` хэвээр үлдээгээд blocker-ийг тайлбарласан follow-up todo нэм
- Хэрэглэгчийн өгсөн command-уудыг үгчлэн хэвээр хадгал (flags, args, order)
- Item бүр тодорхой, хэрэгжүүлэх боломжтой байх ёстой; том ажлыг жижиг алхмуудад хуваа

## Жишээнүүд

- "Add a dark mode toggle and run the tests" -> олон алхамт feature + илэрхий verification
- "Rename getCwd -> getCurrentWorkingDirectory across the repo" -> grep 8 файл дахь 15 давхцлыг илрүүлнэ
- "Implement registration, catalog, cart, checkout" -> олон нарийн төвөгтэй feature

Алгасах:
- "How do I print Hello World in Python?" -> мэдээллийн хүсэлт
- "Add a comment to calculateTotal" -> нэг энгийн засвар
- "Run npm install and tell me what happened" -> нэг command

Эргэлзэж байвал ашигла.

Кодын ухаалаг боломжуудыг ашиглахын тулд Language Server Protocol (LSP) серверүүдтэй харилцана.

Дэмждэг үйлдлүүд:
- goToDefinition: Symbol хаана тодорхойлогдсоныг олно.
- findReferences: Symbol-ийн бүх лавлагааг олно.
- hover: Symbol дээр хулгана аваачих мэдээлэл (баримт бичиг, type info)-г авна.
- documentSymbol: Баримтад байгаа бүх symbol (function, class, variable)-ийг авна.
- workspaceSymbol: Query string-тэй таарах төслийн хэмжээндэх symbol-уудыг жагсаана.
- goToImplementation: Interface эсвэл abstract method-ийн хэрэгжүүлэлтүүдийг олно.
- prepareCallHierarchy: Байрлал дээрх call hierarchy item (function/method)-ийг авна.
- incomingCalls: Тухайн байрлал дахь function-ийг дууддаг бүх function/method-ийг олно.
- outgoingCalls: Тухайн function-аас дуудагддаг бүх function/method-ийг олно.

Бүх үйлдэлд дараах зүйл шаардлагатай:
- filePath: Үйлдэл хийх файл.
- line: Мөрийн дугаар (editor-т харагддаг шиг 1-ээс эхэлнэ).
- character: Тэмдэгтийн offset (1-ээс эхэлнэ).

workspaceSymbol мөн дараахыг авна:
- query: Symbol-ийг шүүх query string. Хоосон string нь бүх symbol-ийг хүснэ.

workspaceSymbol-ийн хувьд filePath-ийг LSP workspace/symbol хүсэлтэд илгээхгүй. MongolGPT үүнийг тохирох LSP серверийг сонгож эхлүүлэхэд ашиглана.

Тэмдэглэл: LSP серверүүдийг файлын төрөл бүрд тохируулсан байх ёстой. Ямар ч сервер боломжгүй бол алдаа буцаана.

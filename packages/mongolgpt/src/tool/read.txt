Локал файлын системээс файл эсвэл хавтас уншина. Зам байхгүй бол алдаа буцаана.

Хэрэглээ:
- `filePath` параметр нь абсолют зам байх ёстой.
- Анхдагч байдлаар энэ хэрэгсэл файлын эхнээс 2000 хүртэл мөр буцаана.
- `offset` параметр нь уншиж эхлэх мөрийн дугаар байна (1-ээс эхэлнэ).
- Дараагийн хэсгүүдийг уншихын тулд илүү их `offset`-тойгоор энэ хэрэгслийг дахин дууд.
- Том файл эсвэл урт мөртэй файл дотроос тодорхой агуулга олохдоо `grep` хэрэгслийг ашигла.
- Зөв файлын замаа мэдэхгүй байвал файлын нэрийг `glob` загвараар хайхдаа `glob` хэрэгслийг ашигла.
- Агуулгыг мөр бүрийн өмнө `<line>: <content>` хэлбэрийн мөрийн дугаартайгаар буцаана. Жишээ нь файл `"foo\n"` агуулж байвал `1: foo\n` гэж авна. Хавтасны хувьд оруулгуудыг мөрийн дугааргүйгээр нэг мөрөнд нэгээр буцааж, дэд хавтасны төгсгөлд `/` нэмнэ.
- 2000 тэмдэгтээс урт мөрийг тасална.
- Олон файл унших шаардлагатай бөгөөд замууд нь тодорхой бол энэ хэрэгслийг зэрэгцээ дууд.
- Жижиг, давтагдсан хэсгийг (30 мөрийн хэсэг) олон дахин бүү унш. Илүү их контекст хэрэгтэй бол том цонхоор унш.
- Энэ хэрэгсэл image файл болон PDF уншиж, файлын attachment болгон буцааж чадна.

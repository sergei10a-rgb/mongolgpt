- Ямар ч хэмжээтэй кодын сантай ажиллах хурдан агуулга хайх хэрэгсэл.
- Regular expression ашиглан файлын агуулгаас хайна.
- Supports full regex syntax (eg. "log.*Error", "function\s+\w+", etc.)
- `include` parameter-аар pattern-д тохирох файлуудыг шүүнэ (жишээ нь `"*.js"`, `"*.{ts,tsx}"`).
- Таарсан мөрүүдийн file path болон мөрийн дугаарыг буцаана.
- Тодорхой pattern агуулсан файлуудыг олох шаардлагатай үед энэ хэрэгслийг ашигла.
- Таарсан үр дүнгийн тоог тодорхойлох/тоолох шаардлагатай бол Bash tool ашиглан `rg` (ripgrep)-ийг шууд ажиллуул. `grep`-ийг БҮҮ ашигла.
- Олон удаагийн glob болон grep шаардаж болзошгүй нээлттэй хайлт хийж байгаа бол оронд нь Task tool ашигла.

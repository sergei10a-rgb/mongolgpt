# Git болон GitHub
- Хэрэглэгч тодорхой хүссэн үед л commit, amend, push эсвэл PR үүсгэ.
- Commit хийхийн өмнө `git status`, `git diff`, `git log --oneline -10`-ийг шалга; зөвхөн зорьсон файлуудаа stage хийж, нууц мэдээллийг хэзээ ч commit бүү хий.
- Репогийн хэв маягт тохирсон товч commit message бич.
- Хэрэглэгч тодорхой хүсээгүй бол git config шинэчлэх, hook алгасах, interactive `-i` ашиглах, force-push хийх эсвэл хоосон commit үүсгэхгүй.
- Commit бүтэлгүйтэх эсвэл hook татгалзвал асуудлыг засаж шинэ commit үүсгэ; бүтэлгүй commit-ийг amend бүү хий.
- PR үүсгэхийн өмнө status, diff, remote tracking, сүүлийн commit-ууд болон base branch-тай харьцуулсан diff-ийг шалга.
- Зөвхөн хамгийн сүүлийн commit бус, PR-д орох бүх commit-ийг хянан үз.
- PR, issue, check, release зэрэг GitHub-ийн ажлуудад `gh` ашигла; дуусмагц PR URL-ийг буцаа.

Файл дотор яг тохирох string-ийг орлуулна.

Хэрэглээ:
- Засвар хийхээсээ өмнө ярианы явцад `Read` tool-ийг дор хаяж нэг удаа заавал ашигла. Файлыг уншаагүй байхад засварлавал энэ хэрэгсэл алдаа гаргана.
- `Read` tool-ийн үр дүнгээс текст засахдаа мөрийн дугаарын prefix-ийн ДАРАА харагдаж буй яг ижил indentation (tab/space)-ийг хадгал. Мөрийн дугаарын prefix нь: мөрийн дугаар + хоёр цэг + зай (жишээ нь `1: `). Тэр зайны дараах бүх зүйл нь тааруулах файлын бодит агуулга юм. Мөрийн дугаарын prefix-ийн аль ч хэсгийг oldString эсвэл newString-д хэзээ ч бүү оруул.
- Кодын санд байгаа файлыг засварлахыг үргэлж урьтал болго. Хэрэглэгчийн шаардлагаар зайлшгүй хэрэгтэй биш л бол шинэ файл хэзээ ч бүү бич.
- Хэрэглэгч тодорхой хүсээгүй бол emoji бүү ашигла. Хүсээгүй тохиолдолд файлд emoji нэмэхээс зайлсхий.
- Файл дотроос `oldString` олдохгүй бол edit нь "oldString not found in content" алдаатайгаар БҮТЭЛГҮЙ болно.
- `oldString` олон удаа олдвол edit нь "Found multiple matches for oldString. Provide more surrounding lines in oldString to identify the correct match." алдаатайгаар БҮТЭЛГҮЙ болно. Илүү их орчны мөр оруулсан том string ашиглан яг нэг тааруулалт тодорхойлох эсвэл бүх тохиолдлыг өөрчлөхийн тулд `replaceAll` ашигла.
- Файлын хэмжээнд string орлуулах болон нэр солихдоо `replaceAll` ашигла. Жишээлбэл хувьсагчийн нэр солиход энэ parameter хэрэг болно.

Хэрэглээ:
- Өгсөн замд файл байвал энэ хэрэгсэл тухайн файлыг дарж бичнэ.
- Хэрэв энэ нь өмнө байгаа файл бол эхлээд `Read` tool-ээр агуулгыг нь заавал уншина. Эхлээд уншаагүй бол энэ хэрэгсэл алдаа гаргана.

- Баримт бичгийн файл (`*.md`) эсвэл README файлыг урьдчилан санаачилж хэзээ ч бүү үүсгэ. Хэрэглэгч тодорхой хүссэн тохиолдолд л баримт бичгийн файл үүсгэ.
- Хэрэглэгч тодорхой хүсээгүй бол emoji бүү ашигла. Хүсээгүй тохиолдолд файлд emoji бичихээс зайлсхий.

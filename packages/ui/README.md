# @mongolgpt/ui

MongolGPT-ийн SolidJS компонент, theme, icon, font болон stylesheet-ийн дотоод design-system package.

```bash
npm install @mongolgpt/ui
```

```tsx
import { Button } from "@mongolgpt/ui/button"
import "@mongolgpt/ui/styles"

export function SaveButton() {
  return <Button>Хадгалах</Button>
}
```

Энэ package нь `solid-js` дээр тулгуурладаг. Нийтийн API-г semver дүрмээр хувилбарлана.
